# مفتاح تجربة SafeKit المجانية لمدة شهر {#safekit-one-month-free-trial-key}

## استلم عبر البريد الإلكتروني مفتاح ترخيص SafeKit مجانيًا لمدة شهر لأنظمة Windows أو Linux {#receive-a-free-safekit-one-month-license-key-by-email-for-windows-or-linux}

يتيح لك مفتاح الترخيص هذا استخدام جميع ميزات SafeKit: موازنة أحمال الشبكة والنسخ المتماثل في الوقت الفعلي والتحويل التلقائي عند التعطل. بعد انتهاء التجربة، يمكنك استبداله بمفتاح ترخيص دائم دون الحاجة إلى إزالة تثبيت المنتج.

بعد استلام ملف `license.txt` عبر البريد الإلكتروني، انسخه إلى الموقع التالي على كل عقدة في المجموعة:

* Windows: `C:/safekit/conf/license.txt`
* Linux: `/opt/safekit/conf/license.txt`
