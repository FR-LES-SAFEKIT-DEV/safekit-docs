### Example with the SafeKit clustering software {#example-with-the-safekit-clustering-software}

For example, with the SafeKit clustering software, you can implement load balancing for IIS and mirroring for Microsoft SQL Server.

To do this, deploy a <span class="notranslate farm-term" translate="no">farm</span> module for IIS and a mirror module for Microsoft SQL Server. Each module is configured with its own virtual IP address and its own restart scripts.

The two modules can be deployed on a single cluster of two servers, where IIS and Microsoft SQL Server both run. Alternatively, the two modules can be deployed on two separate clusters with different servers.

With the SafeKit clustering software, deploying on the same servers or on different servers works in exactly the same way.

### High availability and scalability solution {#high-availability-and-scalability-solution}

The SafeKit clustering software provides a simple high availability and scalability solution for critical web and database applications.

Network load balancing, real-time data mirroring and application failover are managed consistently in a single product.

Unlike hardware clustering, the SafeKit clustering software does not require shared disks, replicated SANs, hardware load balancers, or Enterprise editions of operating systems or databases.
