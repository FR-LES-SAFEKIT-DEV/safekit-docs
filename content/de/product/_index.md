# SafeKit: All-in-One-Software für Hochverfügbarkeit und Anwendungsclustering ohne SAN {#safekit-all-in-one-sanless-high-availability--application-clustering-software}

## Was ist SafeKit? {#what-is-safekit}

**SafeKit** ist **eine All-in-One-Hochverfügbarkeitssoftware**. Sie kombiniert **hostbasierte Echtzeit-Replikation**, **automatisches Failover** und **Lastausgleich** in einem einzigen Produkt, sodass Ihre Anwendung in etwa einer Minute ohne Datenverlust auf einem zweiten Server neu gestartet wird.

SafeKit synchronisiert Daten zwischen Standardservern, sodass Sie keinen teuren Shared Storage (SAN) oder spezielle IT-Kenntnisse benötigen. Es bietet eine einfache und kostengünstige Möglichkeit, **Unternehmensdatenbanken** (wie SQL Server), **kritische Sicherheitssysteme** (wie die Milestone XProtect Videomanagement-Software) und **SCADA-Industriesteuerungssoftware** (wie Siemens Anwendungen) sowohl unter Windows als auch unter Linux zu schützen.


SafeKit schützt Ihre Anwendungen vor:

* **Hardwareausfälle:** SafeKit deckt auch den Ausfall eines gesamten Serverraums ab.
* **Softwarefehler:** SafeKit erkennt einen kritischen Prozess, der abstürzt oder einfriert, und startet ihn automatisch neu.
* **Menschliche Fehler:** Eine einfache Konfiguration und eine einzige Webkonsole reduzieren das Fehlerrisiko.
