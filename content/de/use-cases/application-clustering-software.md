# OEM-Hochverfügbarkeit: SafeKit-Clustering in Ihre Software einbetten {#oem-high-availability-embedding-safekit-clustering-into-your-software}

## Der OEM-Anwendungsfall für Hochverfügbarkeit {#the-oem-high-availability-use-case}

### Eine reine Softwarelösung für Hochverfügbarkeit {#a-software-only-high-availability-solution}

SafeKit ist nicht von spezifischer Hardware abhängig. Es funktioniert mit jedem physischen oder virtuellen Server.


![Anwendungscluster-Software mit SafeKit](/wp-content/uploads/2023/02/application-clustering-software-3.png "w:250")


### Einfache und kostengünstige Anwendungsclustering-Software für Softwareanbieter {#simple-and-economical-application-clustering-software-for-a-software-publisher}

Immer mehr Softwareanbieter bieten SafeKit als OEM-Hochverfügbarkeitsoption in ihrem Katalog an. Sie entscheiden sich für SafeKit, weil es sich um eine einfache und kostengünstige Software für das Anwendungsclustering handelt.

Wenn Sie ein Softwareanbieter sind und ein Anwendungsclustering benötigen, das sich einfach in Ihre eigene Software einbetten lässt, treten Sie unserem OEM-Programm bei. Sie können SafeKit mit Ihrem Softwareangebot bündeln. Ihre Anwendung muss nicht geändert werden.

### Anwendungsclustering mit Echtzeit-Replikation, Lastausgleich und Failover {#application-clustering-with-real-time-replication-load-balancing-and-failover}

Die SafeKit-Software bietet zwei generische Module für das Anwendungs-Clustering: das Mirror-Modul und das <span class="notranslate farm-term" translate="no">Farm</span>-Modul.

Das [Mirror-Modul](/de/architectures/file-replication-byte-level-with-failover-mirror-cluster/) implementiert die Dateireplikation in Echtzeit und das Anwendungs-Failover. Es eignet sich für Anwendungen mit einer Datenbank.

Das [<span class="notranslate farm-term" translate="no">Farm</span>-Modul](/de/architectures/network-load-balancing-cluster/) implementiert die Netzwerklastverteilung und die Anwendungsfailover. Es ist für Anwendungen mit Webdiensten geeignet.

Sie können auch beide Module kombinieren.
