# OEM-Hochverfügbarkeit: Einbettung SafeKit -Clustering in Ihre Software {#oem-high-availability-embedding-safekit-clustering-into-your-software}

## Der OEM-Anwendungsfall für hohe Verfügbarkeit {#the-oem-high-availability-use-case}

### Eine rein softwarebasierte Hochverfügbarkeitslösung {#a-software-only-high-availability-solution}

SafeKit ist unabhängig von der Hardware und funktioniert mit allen physischen und virtuellen Servern.


![ Anwendungsclustering-Software mit SafeKit ](/wp-content/uploads/2023/02/application-clustering-software-3.png "w:250")


### Einfache und kostengünstige Software zur Anwendungsclusterung für einen Softwarehersteller {#simple-and-economical-application-clustering-software-for-a-software-publisher}

Immer mehr Softwarehersteller integrieren SafeKit als OEM-Hochverfügbarkeitsoption in ihren Katalog. SafeKit wurde gewählt, da es sich um eine einfache und kostengünstige Software für Anwendungsclustering handelt. 

Sind Sie Softwarehersteller und suchen nach einer Anwendungsclustering-Lösung, die sich einfach in Ihre Software integrieren lässt? Dann nutzen Sie unser OEM-Angebot. Sie können SafeKit in Ihr Softwareangebot einbinden. Die Lösung erfordert keine Anpassungen an Ihrer Anwendung.

### Anwendungsclustering mit Echtzeitreplikation, Lastausgleich und Failover {#application-clustering-with-real-time-replication-load-balancing-and-failover}

Die Software SafeKit bietet zwei generische Module für das Anwendungsclustering an: das Modul mirror und das Modul <span class="notranslate farm-term" translate="no">farm</span> .

Das Modul [ mirror ](/de/product/#safekit-mirror-cluster) implementiert Dateireplikation in Echtzeit und Anwendungs-Failover. Es eignet sich für Anwendungen mit einer Datenbank.

Das Modul [ <span class="notranslate farm-term" translate="no">farm</span> ](/de/product/#safekit-farm-cluster) implementiert Netzwerklastausgleich und Anwendungsausfallsicherung. Es eignet sich für Anwendungen mit Webdiensten.

Und Sie können die Module kombinieren.
