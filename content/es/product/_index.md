# SafeKit: Software de alta disponibilidad SANless y clustering de aplicaciones todo en uno {#safekit-all-in-one-sanless-high-availability--application-clustering-software}

## ¿Qué es SafeKit? {#what-is-safekit}

**SafeKit** es **software de alta disponibilidad todo en uno**. Combina la **replicación basada en host** en tiempo real, la **conmutación por error** automática y el **equilibrio de carga** en un solo paquete, para que la aplicación se reinicie en un segundo servidor en aproximadamente un minuto y sin pérdida de datos.

Al sincronizar los datos entre servidores estándar, **SafeKit** elimina la necesidad de costosos sistemas de almacenamiento compartido (SAN) o de conocimientos informáticos especializados, proporcionando una forma sencilla y rentable de proteger **bases de datos empresariales** (como SQL Server), **sistemas de seguridad críticos** (como el software de gestión de vídeo Milestone XProtect) y **software de control industrial SCADA** (como las aplicaciones de Siemens) tanto en entornos Windows como Linux.


SafeKit protege sus aplicaciones frente a:

* **fallos de hardware**, incluido el fallo completo de una sala de servidores
* **fallos de software**, como el bloqueo o la interrupción de procesos críticos, que se detectan y reinician automáticamente
* **errores humanos**, que se reducen gracias a una configuración sencilla y una única consola web
