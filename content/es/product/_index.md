# SafeKit: software todo en uno de alta disponibilidad y clúster de aplicaciones sin SAN {#safekit-all-in-one-sanless-high-availability--application-clustering-software}

## ¿Qué es SafeKit? {#what-is-safekit}

**SafeKit** es **un software de alta disponibilidad todo en uno**. Combina **la replicación basada en host** en tiempo real, **la conmutación por error automática** y **el equilibrio de carga** en un solo producto, por lo que su aplicación se reinicia en un segundo servidor en aproximadamente un minuto sin pérdida de datos.

SafeKit sincroniza los datos entre servidores estándar, por lo que no necesita costosos sistemas de almacenamiento compartido (SAN) ni conocimientos informáticos especializados. Ofrece una forma sencilla y rentable de proteger **bases de datos empresariales** (como SQL Server), **sistemas de seguridad críticos** (como el software de gestión de vídeo Milestone XProtect) y **software de control industrial SCADA** (como las aplicaciones Siemens) tanto en Windows como en Linux.


SafeKit protege sus aplicaciones contra:

* **Fallos de hardware:** SafeKit también cubre la pérdida de una sala de servidores completa.
* **Fallos de software:** SafeKit detecta un proceso crítico que se bloquea o se congela y lo reinicia automáticamente.
* **Errores humanos:** una configuración sencilla y una única consola web reducen el riesgo de cometer errores.
