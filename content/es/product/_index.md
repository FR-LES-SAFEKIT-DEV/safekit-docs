# SafeKit: Software todo en uno de alta disponibilidad y clúster de aplicaciones sin SAN {#safekit-all-in-one-sanless-high-availability--application-clustering-software}

## ¿Qué es SafeKit? {#what-is-safekit}

**SafeKit** es **un software de alta disponibilidad todo en uno**. Combina **la replicación basada en host** en tiempo real, **la conmutación por error automática** y **el equilibrio de carga** en un solo paquete, por lo que su aplicación se reinicia en un segundo servidor en aproximadamente un minuto sin pérdida de datos.

Al sincronizar los datos entre servidores estándar, **SafeKit** elimina la necesidad de costosos almacenamientos compartidos (SAN) o conocimientos especializados de TI, proporcionando una forma sencilla y rentable de proteger **bases de datos empresariales** (como SQL Server), **sistemas de seguridad críticos** (como el software de gestión de vídeo Milestone XProtect) y **software de control industrial SCADA** (como las aplicaciones Siemens) en entornos Windows y Linux.


SafeKit protege sus aplicaciones contra:

* **Averías de hardware**, incluida la avería total de una sala de ordenadores
* **Fallos de software**, como el bloqueo o la congelación de un proceso crítico. SafeKit detecta el fallo y reinicia el proceso automáticamente
* **Errores humanos**, que se reducen con una configuración sencilla y una única consola web
