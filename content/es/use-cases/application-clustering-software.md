# Alta disponibilidad OEM: Integración de la agrupación en clúster SafeKit en su software {#oem-high-availability-embedding-safekit-clustering-into-your-software}

## El caso de uso de alta disponibilidad OEM {#the-oem-high-availability-use-case}

### Una solución de alta disponibilidad solo por software {#a-software-only-high-availability-solution}

SafeKit no depende de un hardware específico. Funciona con cualquier servidor físico o virtual.


![Software de agrupación de aplicaciones con SafeKit](/wp-content/uploads/2023/02/application-clustering-software-3.png "w:250")


### Software de agrupación de aplicaciones sencillo y rentable para proveedores de software {#simple-and-economical-application-clustering-software-for-a-software-publisher}

Cada vez más proveedores de software ofrecen SafeKit como una opción OEM de alta disponibilidad en su catálogo. Eligen SafeKit porque es un software de clúster de aplicaciones sencillo y rentable.

Si usted es un proveedor de software y necesita un clúster de aplicaciones que sea fácil de integrar en su propio software, únase a nuestro programa OEM. Puede incluir SafeKit con su oferta de software. Su aplicación no necesita ninguna modificación.

### Agrupación de aplicaciones con replicación en tiempo real, equilibrio de carga y conmutación por error {#application-clustering-with-real-time-replication-load-balancing-and-failover}

El software SafeKit ofrece dos módulos genéricos para la agrupación de aplicaciones: el módulo mirror y el módulo <span class="notranslate farm-term" translate="no">farm</span>.

El [módulo mirror](/es/architectures/file-replication-byte-level-with-failover-mirror-cluster/) implementa la replicación de archivos en tiempo real y la conmutación por error de aplicaciones. Es adecuado para aplicaciones con una base de datos.

El [módulo <span class="notranslate farm-term" translate="no">farm</span>](/es/architectures/network-load-balancing-cluster/) implementa el equilibrio de carga de red y la conmutación por error de aplicaciones. Es adecuado para aplicaciones con servicios web.

También puede combinar ambos módulos.
