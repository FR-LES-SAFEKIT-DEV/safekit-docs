# Alta disponibilidad OEM: Integración de la agrupación en clústeres SafeKit en su software {#oem-high-availability-embedding-safekit-clustering-into-your-software}

## Caso de uso de alta disponibilidad del fabricante de equipos originales (OEM) {#the-oem-high-availability-use-case}

### Una solución de alta disponibilidad basada únicamente en software {#a-software-only-high-availability-solution}

SafeKit es independiente del hardware y funciona con cualquier servidor físico o virtual.


Software de agrupación de aplicaciones ![ con SafeKit ](/wp-content/uploads/2023/02/application-clustering-software-3.png "w:250")


### Software de agrupación de aplicaciones simple y económico para un editor de software {#simple-and-economical-application-clustering-software-for-a-software-publisher}

Cada vez más editores de software integran SafeKit como una opción OEM de alta disponibilidad en su catálogo. Se elige SafeKit por ser un software de agrupación de aplicaciones sencillo y económico. 

Si eres editor de software y buscas una solución de agrupación de aplicaciones fácil de integrar en tu propio software, puedes aprovechar nuestra oferta OEM. Podrás incluir SafeKit en tu oferta de software. Además, la solución no requiere ninguna modificación de tu aplicación.

### Agrupación de aplicaciones con replicación en tiempo real, equilibrio de carga y conmutación por error {#application-clustering-with-real-time-replication-load-balancing-and-failover}

El software SafeKit ofrece dos módulos genéricos para la agrupación de aplicaciones: el módulo mirror y el módulo <span class="notranslate farm-term" translate="no">farm</span> .

Los módulos [ mirror ](/es/product/#safekit-mirror-cluster) implementan la replicación de archivos en tiempo real y la conmutación por error de aplicaciones. Son adecuados para aplicaciones con base de datos.

Los módulos [ <span class="notranslate farm-term" translate="no">farm</span> ](/es/product/#safekit-farm-cluster) implementan el balanceo de carga de red y la conmutación por error de aplicaciones. Son adecuados para aplicaciones con servicios web.

Y puedes combinar los módulos.
