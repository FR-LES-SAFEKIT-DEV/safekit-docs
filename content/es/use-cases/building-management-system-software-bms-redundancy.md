# Alta disponibilidad y redundancia para sistemas de gestión de edificios (BMS) {#high-availability-and-redundancy-for-building-management-systems-bms}

##  ¿Qué es un sistema de gestión de edificios (BMS)? {#what-is-a-building-management-system-bms}

Un sistema de gestión de edificios (BMS) proporciona un control automático y centralizado de los servicios del edificio: calefacción, ventilación y aire acondicionado (HVAC), distribución de energía, iluminación y más.

Un sistema de gestión de edificios aumenta la seguridad de los ocupantes del edificio. También reduce el consumo de energía y disminuye los costes de funcionamiento y mantenimiento.

##  ¿Por qué es fundamental el software BMS? {#why-a-bms-software-is-critical}

El software BMS controla los sistemas de seguridad contra incendios, los paneles de distribución eléctrica, el consumo de agua, los sistemas de aire acondicionado y la iluminación.

La seguridad de los ocupantes del edificio depende directamente del correcto funcionamiento del software del BMS.

Por eso, el sistema debe estar siempre disponible. Los operadores del edificio deben reaccionar de inmediato ante el más mínimo incidente.
