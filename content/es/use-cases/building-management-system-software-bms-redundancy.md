# Alta disponibilidad y redundancia para sistemas de gestión de edificios (BMS) {#high-availability-and-redundancy-for-building-management-systems-bms}

##  ¿Qué es un sistema de gestión de edificios (BMS)? {#what-is-a-building-management-system-bms}

Un sistema de gestión de edificios (BMS) proporciona el control centralizado y automático de los sistemas de climatización (calefacción, ventilación y aire acondicionado), electricidad, iluminación, etc., del edificio.

Un sistema de gestión de edificios aumenta la seguridad de los residentes, reduce el consumo de energía y disminuye los costes de funcionamiento y mantenimiento.

##  ¿Por qué es fundamental un software BMS? {#why-a-bms-software-is-critical}

Un software BMS controla el sistema contra incendios, los paneles de distribución eléctrica, el consumo de agua, los sistemas de aire acondicionado y el control de la iluminación.

La seguridad de las personas en el edificio está directamente relacionada con la correcta ejecución del software del sistema de gestión de edificios (BMS).

Por eso, el sistema debe estar siempre disponible para los operadores de edificios, quienes deben reaccionar de inmediato ante el más mínimo incidente.
