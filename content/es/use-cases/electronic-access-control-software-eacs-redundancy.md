# Alta disponibilidad y redundancia para el software de control de acceso electrónico (EACS) {#high-availability-and-redundancy-for-electronic-access-control-software-eacs}

##  ¿Qué es un sistema electrónico de control de acceso (EACS)? {#what-is-an-electronic-access-control-system-eacs}

Un sistema electrónico de control de acceso consiste en dispositivos de hardware que controlan la entrada a locales privados.

Los robos y los allanamientos de morada son delitos comunes en las empresas. Por eso, los sistemas electrónicos de control de acceso se utilizan ampliamente.

##  ¿Por qué es fundamental el software EACS? {#why-an-eacs-software-is-critical}

El software EACS gestiona los dispositivos de hardware. Deniega la entrada a personas no autorizadas y activa una alarma cuando un intruso irrumpe.

La seguridad de las personas depende directamente del correcto funcionamiento del software EACS.

Los agentes de seguridad deben reaccionar de inmediato ante el más mínimo incidente. Por lo tanto, el sistema debe estar siempre a su disposición.
