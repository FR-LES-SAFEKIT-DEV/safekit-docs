# Alta disponibilidad y redundancia para software de control de acceso electrónico (EACS) {#high-availability-and-redundancy-for-electronic-access-control-software-eacs}

##  ¿Qué es un sistema electrónico de control de acceso (EACS)? {#what-is-an-electronic-access-control-system-eacs}

Los sistemas de control de acceso electrónico constan de dispositivos de hardware que controlan la entrada a cualquier propiedad privada.

Los robos y allanamientos son delitos comunes en los entornos empresariales. Por ello, los sistemas de control de acceso electrónico se utilizan ampliamente.

##  ¿Por qué es fundamental un software EACS? {#why-an-eacs-software-is-critical}

El software EACS gestiona los dispositivos de hardware y deniega el acceso a usuarios no autorizados o activa las alarmas en caso de intrusión por parte de ladrones o delincuentes.

La seguridad de las personas está directamente relacionada con la correcta ejecución del software EACS.

Y por eso el sistema debe estar siempre disponible para los agentes de seguridad, quienes deben reaccionar de inmediato ante el más mínimo incidente.
