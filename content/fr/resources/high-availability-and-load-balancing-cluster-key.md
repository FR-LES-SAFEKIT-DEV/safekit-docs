# Clé d’essai gratuite SafeKit d’un mois {#safekit-one-month-free-trial-key}

## Recevez par e-mail une clé de licence SafeKit gratuite d’un mois pour Windows ou Linux {#receive-a-free-safekit-one-month-license-key-by-email-for-windows-or-linux}

Cette clé de licence donne accès à toutes les fonctionnalités de SafeKit : équilibrage de charge réseau, réplication en temps réel et basculement. À la fin de l’essai, vous pouvez la remplacer par une clé de licence permanente sans désinstaller le produit.

Lorsque vous recevez le fichier `license.txt` par e-mail, copiez-le à l’emplacement suivant sur chaque nœud du cluster :

* Windows : `C:/safekit/conf/license.txt`
* Linux : `/opt/safekit/conf/license.txt`
