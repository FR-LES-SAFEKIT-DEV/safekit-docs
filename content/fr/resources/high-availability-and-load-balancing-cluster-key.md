# Clé SafeKit Cluster : essai d’un mois pour la haute disponibilité sous Windows et Linux

## Recevez par e-mail une clé d'essai d'un mois de SafeKit pour Windows ou Linux

Cliquez sur le bouton "Recevoir une clé d'un mois >". Remplissez le formulaire, donnez votre adresse e-mail et soumettez le formulaire pour recevoir une clé d'essai d'un mois.

[ Recevoir une clé d'un mois > ](<https://safekit.eviden.com/fr/resources/safekit-free-trial-licence-key-high-availability/>)

Cette clé de licence vous permet de tester toutes les fonctionnalités du logiciel SafeKit : partage de charge réseau, réplication temps réel et reprise sur panne. Elle pourra être remplacée par une clé permanente sans avoir à désinstaller le produit.

Si vous n'avez pas encore téléchargé le produit, vous pouvez accéder au [téléchargement du logiciel de clustering SafeKit ici](</fr/resources/safekit-free-trial/>).
