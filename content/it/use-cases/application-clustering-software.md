# Alta disponibilità OEM: integrazione del clustering SafeKit nel software {#oem-high-availability-embedding-safekit-clustering-into-your-software}

## Il caso d’uso OEM per l’alta disponibilità {#the-oem-high-availability-use-case}

### Una soluzione di alta disponibilità basata esclusivamente su software {#a-software-only-high-availability-solution}

SafeKit non dipende da hardware specifico. Funziona con qualsiasi server fisico o virtuale.


![Software di clustering delle applicazioni con SafeKit](/wp-content/uploads/2023/02/application-clustering-software-3.png "w:250")


### Software di clustering delle applicazioni semplice ed economico per i fornitori di software {#simple-and-economical-application-clustering-software-for-a-software-publisher}

Sempre più fornitori di software offrono SafeKit come opzione OEM ad alta disponibilità nel loro catalogo. Scelgono SafeKit perché è un software di clustering di applicazioni semplice ed economico.

Se sei un fornitore di software e hai bisogno di un clustering di applicazioni facile da integrare nel tuo software, unisciti al nostro programma OEM. Puoi includere SafeKit nella tua offerta software. La tua applicazione non necessita di alcuna modifica.

### Clustering delle applicazioni con replica in tempo reale, bilanciamento del carico e failover {#application-clustering-with-real-time-replication-load-balancing-and-failover}

Il software SafeKit offre due moduli generici per il clustering delle applicazioni: il modulo mirror e il modulo <span class="notranslate farm-term" translate="no">farm</span>.

Il [modulo mirror](/it/architectures/file-replication-byte-level-with-failover-mirror-cluster/) implementa la replica dei file in tempo reale e il failover delle applicazioni. È adatto per applicazioni con un database.

Il [modulo <span class="notranslate farm-term" translate="no">farm</span>](/it/architectures/network-load-balancing-cluster/) implementa il bilanciamento del carico di rete e il failover delle applicazioni. È adatto per applicazioni con servizi web.

È possibile combinare entrambi i moduli.
