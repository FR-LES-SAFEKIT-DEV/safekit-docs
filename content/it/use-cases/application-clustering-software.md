# Alta disponibilità OEM: Integrazione del clustering SafeKit nel software {#oem-high-availability-embedding-safekit-clustering-into-your-software}

## Il caso d'uso ad alta disponibilità OEM {#the-oem-high-availability-use-case}

### Una soluzione di alta disponibilità esclusivamente software {#a-software-only-high-availability-solution}

SafeKit è indipendente dall'hardware e funziona con qualsiasi server fisico o virtuale.

### Software di clustering per applicazioni semplice ed economico per un editore di software {#simple-and-economical-application-clustering-software-for-a-software-publisher}

Un numero crescente di produttori di software sta integrando SafeKit come opzione OEM di alta disponibilità nel proprio catalogo. SafeKit è stato scelto perché si tratta di un software di clustering di applicazioni semplice ed economico. 

Se sei uno sviluppatore di software e cerchi una soluzione di clustering per applicazioni facile da integrare nel tuo software, puoi approfittare della nostra offerta OEM. Potrai includere SafeKit nella tua offerta software senza dover modificare la tua applicazione.

### Clustering di applicazioni con replica in tempo reale, bilanciamento del carico e failover {#application-clustering-with-real-time-replication-load-balancing-and-failover}

Il software SafeKit offre due moduli generici per il clustering delle applicazioni: il modulo mirror e il modulo <span class="notranslate farm-term" translate="no">farm</span> .

Il modulo [ mirror ](/it/product/#safekit-mirror-cluster) implementa la replica dei file in tempo reale e il failover delle applicazioni. È adatto per applicazioni con un database.

Il modulo [ <span class="notranslate farm-term" translate="no">farm</span> ](/it/product/#safekit-farm-cluster) implementa il bilanciamento del carico di rete e il failover delle applicazioni. È adatto per applicazioni con servizi web.

E si possono combinare i moduli.
