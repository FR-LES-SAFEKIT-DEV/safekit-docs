# Elevata disponibilità e ridondanza per i sistemi di gestione degli edifici (BMS) {#high-availability-and-redundancy-for-building-management-systems-bms}

##  Che cos'è un sistema di gestione degli edifici (BMS)? {#what-is-a-building-management-system-bms}

Un sistema di gestione degli edifici (BMS) consente il controllo centralizzato automatico degli impianti HVAC (riscaldamento, ventilazione e condizionamento dell'aria), elettrici, di illuminazione...

Un sistema di gestione degli edifici aumenta la sicurezza per i residenti, riduce il consumo energetico e diminuisce i costi di gestione e manutenzione.

##  Perché un software BMS è fondamentale? {#why-a-bms-software-is-critical}

Un software BMS controlla il sistema antincendio, i quadri di distribuzione elettrica, il consumo idrico, i sistemi di condizionamento dell'aria e l'illuminazione.

La sicurezza delle persone all'interno dell'edificio è direttamente collegata alla corretta esecuzione del software BMS.

Ed è per questo che il sistema deve essere sempre disponibile per i gestori degli edifici, che devono reagire immediatamente al minimo incidente.
