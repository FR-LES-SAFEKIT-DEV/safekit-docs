# SafeKit：SAN 不要のオールインワン高可用性ソフトウェア {#safekit-all-in-one-high-availability-software-without-a-san}

## SafeKit とは？ {#what-is-safekit}

**SafeKit** は、**オールインワンの高可用性ソフトウェア**です。**リアルタイムのホストベースレプリケーション**、**自動フェイルオーバー**、**ロードバランシング**を単一の製品に統合しているため、データ損失なしに約 1 分で 2 台目のサーバーでアプリケーションを再起動できます。

SafeKit は標準的なサーバー間でデータを同期するため、高価な共有ストレージ（SAN）や専門的な IT スキルは必要ありません。Windows と Linux 両方で、**エンタープライズデータベース**（SQL Server など）、**重要なセキュリティシステム**（Milestone XProtect ビデオ管理ソフトウェアなど）、**SCADA 産業用制御ソフトウェア**（Siemens アプリケーションなど）を保護するための、シンプルで費用対効果の高い方法を提供します。


SafeKit は、お客様のアプリケーションを以下から保護します：

* **ハードウェア障害：** SafeKit は、サーバー室全体の損失にも対応します。
* **ソフトウェア障害：** SafeKit は、クラッシュまたはフリーズしたクリティカルプロセスを検出し、自動的に再起動します。
* **ヒューマンエラー：** シンプルな設定と単一のウェブコンソールで、ミスによるリスクを軽減します。
