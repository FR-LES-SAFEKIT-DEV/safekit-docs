# SafeKit AIとサポート {#safekit-ai--support}

## 無料AIレベル1サポート {#ai-support}

**🤖 お気に入りの LLM と一緒にSafeKitを使用してください**

  1. Claude、ChatGPT、GitHub Copilot、またはその他のLLMなどのAIアシスタントを起動します。
  2. [ llms.txt ](</llms.txt>)の内容をチャットに貼り付けてください。
  3. LLMがSafeKit知識ベースを正しく処理したことを確認するには、 `What is the default value of maxloop in SafeKit?`に質問してください。
  4. 正解は`3`です。
  5. 次のような質問をすることができます。 
     * 販売および販売前の質問
     * 段階的なインストール手順
     * 設定およびセットアップのサポート
     * 技術的なトラブルシューティング
     * ログ分析


## 標準サポートおよびメンテナンス {#standard-support}

関連するサポートおよび保守料金の支払いを条件として、エンドユーザーは以下のリモートサービスを利用する権利を有します。

  * 欧州サポートセンターへの技術担当者（最大4名まで）が、インシデントの報告や支援要請のために、24時間365日いつでもウェブサイトにアクセスできる。
  * サポートセンターによるオンラインサポートは、月曜日から金曜日の午前9時から午後5時まで（ヨーロッパのコールセンター現地時間）ご利用いただけます。
  * 最大4名の技術担当者が、知識データベース、FAQ、その他のオンライン情報施設にアクセスできます。
  * インシデントが報告された後、Evidenはサポートセンターの営業時間内4時間以内に報告を受け付けたことを確認します。
  * ライセンス製品のサービスパック、アップデート、アップグレードは追加料金なしで提供されます。
  * ライセンス対象サーバーのホスト名が変更された場合、追加料金なしで新しいライセンスキーを取得する権利。
  * ログインが必要です

  * 自分のペースで学習できるオンラインモジュール。いつでも利用可能。
  * 完全無料
