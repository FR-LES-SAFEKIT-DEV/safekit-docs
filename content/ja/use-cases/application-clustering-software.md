# OEM 高可用性：SafeKit クラスタリングをソフトウェアに組み込む {#oem-high-availability-embedding-safekit-clustering-into-your-software}

## OEM 高可用性ユースケース {#the-oem-high-availability-use-case}

### ソフトウェアのみのハイアベイラビリティソリューション {#a-software-only-high-availability-solution}

SafeKit は特定のハードウェアに依存しません。あらゆる物理サーバーまたは仮想サーバーで動作します。


![SafeKit によるアプリケーションクラスタリングソフトウェア](/wp-content/uploads/2023/02/application-clustering-software-3.png "w:250")


### ソフトウェアベンダー向けのシンプルで費用対効果の高いアプリケーションクラスタリングソフトウェア {#simple-and-economical-application-clustering-software-for-a-software-publisher}

ますます多くのソフトウェアベンダーが、OEM 高可用性オプションとして SafeKit をカタログに掲載しています。彼らが SafeKit を選ぶのは、シンプルで費用対効果の高いアプリケーションクラスタリングソフトウェアだからです。

ソフトウェアベンダー様で、ご自身のソフトウェアに簡単に組み込めるアプリケーションクラスタリングが必要な場合は、当社の OEM プログラムにご参加ください。SafeKit を貴社のソフトウェア製品にバンドルできます。貴社のアプリケーションに変更を加える必要はありません。

### リアルタイムレプリケーション、ロードバランシング、フェイルオーバーを備えたアプリケーションクラスタリング {#application-clustering-with-real-time-replication-load-balancing-and-failover}

SafeKit ソフトウェアには、アプリケーションクラスタリング用の 2 つの汎用モジュール、mirror モジュールと <span class="notranslate farm-term" translate="no">farm</span> モジュールが用意されています。

[mirror モジュール](/ja/architectures/file-replication-byte-level-with-failover-mirror-cluster/)は、リアルタイムのファイルレプリケーションとアプリケーションのフェイルオーバーを実装します。データベースを使用するアプリケーションに適しています。

[<span class="notranslate farm-term" translate="no">farm</span> モジュール](/ja/architectures/network-load-balancing-cluster/)はネットワーク負荷分散とアプリケーションフェイルオーバーを実装します。Web サービスを伴うアプリケーションに適しています。

両方のモジュールを組み合わせることも可能です。
