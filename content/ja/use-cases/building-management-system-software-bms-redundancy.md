# ビル管理システム（BMS）の高可用性と冗長性 {#high-availability-and-redundancy-for-building-management-systems-bms}

##  ビル管理システム（BMS）とは？ {#what-is-a-building-management-system-bms}

ビル管理システム（BMS）は、暖房、換気、空調（HVAC）、電力供給、照明などのビルサービスを自動かつ一元的に制御します。

ビル管理システムは、ビル利用者の安全性を高めます。また、エネルギー消費量を削減し、運用・保守コストを低減します。

##  BMS ソフトウェアが重要な理由とは？ {#why-a-bms-software-is-critical}

BMS ソフトウェアは、防火安全システム、配電盤、水の消費量、空調システム、照明を制御します。

建物利用者の安全は、BMS ソフトウェアの正しい動作に直接左右されます。

そのため、システムは常に利用可能でなければなりません。ビル管理者は、どんな些細なインシデントにも即座に対応しなければなりません。
