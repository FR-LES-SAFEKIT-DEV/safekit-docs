# データセンター不要のエッジ高可用性：OTおよび分散サイト向けSafeKit {#edge-high-availability-without-a-data-center-safekit-for-ot--distributed-sites}

## Edge HAチャレンジ {#the-edge-ha-challenge}

エッジサイトにはデータセンターがなく、高可用性（HA）に関する専門知識も不足していることが多いが、事業継続性は極めて重要である。工場、海上石油プラットフォーム、病院の診療所、小売店、5Gアンテナサイトなどは、ダウンタイムを許容できない一方で、従来のデータセンターのHAクラスタを構築するコストと複雑さを正当化することもできない。

従来のHAソリューション（ Microsoft 、Pacemaker/Corosync、VMware HAなど）はデータセンター向けに設計されており、共有ストレージ（SAN/NAS）、専用クラスタハードウェア、常駐のITスタッフ、複雑なOSレベルの専門知識を前提としています。しかし、エッジ環境ではこれらの要素はどれも存在しません。

SafeKitまさにこのニーズに応えるために開発されました。工場、石油プラットフォーム、船舶、ビルセキュリティ、航空管制、5Gネットワーク、医療、小売など、さまざまな分野でエッジアプリケーションを稼働させ続けることができます。必要なのは、標準的なサーバー2台とLANだけです。

## SafeKitがEdgeに最適な理由 {#what-makes-safekit-the-natural-fit-for-edge}

SafeKit 、2台の標準的なエッジサーバー（メーカー不問、物理サーバーでも仮想サーバーでも可）をプラグアンドプレイのHAクラスタに変換します。共有ストレージ、SAN、特別なハードウェアは不要です。軽量なソフトウェアスタック1つで以下の機能を実現します。

  * **リアルタイム同期ファイルレプリケーション** — 書き込み時にデータがバイトレベルでスタンバイサーバーにミラーリングされます
  * **自動フェイルオーバー** — プライマリサーバーが故障した場合、スタンバイサーバーが人間の介入なしに数秒以内に引き継ぎます。
  * **オプションのネットワーク負荷分散** — 両方のサーバーがワークロードを共有するアクティブ/アクティブ構成の場合
  * ** Webコンソール** — ブラウザベースの管理、HTTPS経由でリモートアクセス可能、オンサイトの専門知識は不要
  * **サイレントインストール、スクリプト対応** — OEMへの組み込みや数百の分散サイトへの大規模展開に適しています


SANの調達は不要で、 Windowsサーバーデータセンターライセンスも不要、 LinuxクラスタOSの専門知識も不要、専用のクラスタハードウェアも不要です。HAスタック全体が単一のソフトウェアパッケージで実現します。

SafeKitは、エッジ、ブランチオフィス、および分散型エンタープライズのシナリオ向けに特別に設計されています。

## エッジOT環境が異なる理由 {#why-edge-ot-environments-are-different}

OT（運用技術）環境（SCADA、BMS、物理セキュリティ、産業制御など）は、ITデータセンターとは根本的に異なる要件を持っています。

  * **現場にIT担当者はいません。** 変電所、遠隔ポンプ場、船舶にはシステム管理者が存在しない。HA（高可用性）は自己管理型でなければならない。
  * **エアギャップまたは制約のあるネットワーク。** 多くのOTサイトはインターネット接続がなく、WAN帯域幅も限られています。そのため、HAソフトウェアは完全にオフラインで動作する必要があります。
  * **24時間365日稼働、複雑さは一切許容しない。** 生産ラインの停止、ビデオ監視システムの停止、アクセス制御の中断といった事態は、HAソフトウェア自体にかかる費用をはるかに上回る損失をもたらす。
  * **機器のライフサイクルが長い。** OTサーバーは10～15年間稼働する可能性がある。HAソリューションは、安定性が高く、メンテナンスの手間が少なく、頻繁なアップデートを必要としないものでなければならない。
  * **標準的なx86ハードウェアのみに対応。** 遠隔地の工業施設にSANや専用クラスタノードを設置するための予算も正当性も存在しない。
  * **OSレベルの複雑さに対する耐性の欠如。** Pacemaker、Corosync、またはWSFCは、OTオペレーターが持ち合わせていない、また必要とすべきではないクラスタリングに関する専門知識を必要とする。


SafeKitのSANレス、2サーバー構成、自動フェイルオーバーモデルは、これらの制約すべてに直接的に対応しています。

## 技術的な最小要件 {#technical-minimum-requirements}

  * **サーバー: ** 2 台の標準 x86 サーバーまたは VM (ハードウェアのブランドは問わず、物理環境または仮想環境)、または ARM ( Linuxのみ)
  * ** OS: ** Windows Server 2019 / 2022 / 2025、 Windows 11、RHEL 8/9、Ubuntu 24.04
  * **ネットワーク：レプリケーション用の** 1Gbps LAN。専用のハートビートネットワークを推奨。
  * **ストレージ: **ローカルディスクのみ - SAN、NAS、共有ストレージは一切使用不可
  * **特別な OS エディションは不要です** — Windows Server Standard で十分です。データセンター ライセンスは不要です。
