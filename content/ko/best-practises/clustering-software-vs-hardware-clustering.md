# 고가용성을 위한 소프트웨어 클러스터링 vs. 하드웨어 클러스터링 {#software-clustering-vs-hardware-clustering-for-high-availability}

## 소프트웨어 클러스터링과 하드웨어 클러스터링의 차이점은 무엇 ? {#difference-between-software-clustering-and-hardware-clustering}

### 개요 {#overview}

이 글에서는 데이터 복제, 공유 디스크, 로드 밸런싱, 하드웨어 및 소프트웨어 요구 사항, 클러스터 구성 기술 등과 같은 기능을 살펴보면서 소프트웨어 클러스터링과 하드웨어 클러스터링의 장단점을 비교 분석합니다. 


![ 소프트웨어 클러스터링 vs 하드웨어 클러스터링 ](/wp-content/uploads/2023/03/high-availability-architectures-and-best-practices.png "w:400")


다음 비교표는 하드웨어 클러스터링과 소프트웨어 클러스터링 제품인 SafeKit 의 차이점을 자세히 설명합니다.

### 하드웨어 클러스터링이란 무엇인가요? {#what-is-hardware-clustering}

하드웨어 클러스터링 솔루션에는 두 가지 유형이 있습니다. 하나는 데이터베이스와 같은 백엔드 애플리케이션용 하드웨어 클러스터링이고, 다른 하나는 웹 서비스와 같은 프런트엔드 애플리케이션용 하드웨어 클러스터링입니다.

백엔드용 하드웨어 클러스터링(예: [ Microsoft 장애 조치 클러스터, ](<https://learn.microsoft.com/en-us/windows-server/failover-clustering/clustering-requirements>) )은 디스크를 공유하는 두 대의 서버를 기반으로 하며, 장애 발생 시 애플리케이션이 자동으로 장애 조치됩니다.

프런트엔드용 하드웨어 클러스터링은 `farm` 서버(2대 이상) 앞에 로드 밸런서(예: [ F5 BIG-IP, ](<https://www.f5.com/products/big-ip-services/local-traffic-manager>) )를 배치하여 구성됩니다. 로드 밸런서는 TCP 세션을 farm 에 있는 사용 가능한 서버로 분산합니다.

### 소프트웨어 클러스터링이란 무엇인가요? {#what-is-software-clustering}

하드웨어 클러스터링과 마찬가지로 소프트웨어 클러스터링 솔루션에도 두 가지 유형이 있습니다. 데이터베이스와 같은 백엔드 애플리케이션용 소프트웨어 클러스터링과 웹 서비스와 같은 프런트엔드 애플리케이션용 소프트웨어 클러스터링입니다.

백엔드용 소프트웨어 클러스터링(예: [ SafeKit ](</>) )은 두 대의 서버가 실시간으로 데이터를 복제하고 장애 발생 시 애플리케이션이 자동으로 페일오버되는 방식으로 구성됩니다.

프런트엔드용 소프트웨어 클러스터링( SafeKit 와 같은 경우)은 서버(2대 이상)로 구성된 `farm` 에서 로드 밸런싱을 기반으로 합니다. 로드 밸런싱은 소프트웨어에 의해 수행되며 TCP 세션을 farm 에서 사용 가능한 서버로 분산합니다.

## 소프트웨어 클러스터링 vs 하드웨어 클러스터링: 장단점 비교 {#software-clustering-vs-hardware-clustering-pros-and-cons}

고가용성은 **소프트웨어 클러스터링** , **하드웨어 클러스터링** (공유/복제 스토리지), **하드웨어 로드 밸런서** (전용 네트워크 어플라이언스) 등 다양한 클러스터링 방식을 통해 구현할 수 있습니다. 각 방식은 기능, 필요한 하드웨어, 소프트웨어 요구 사항, 배포에 필요한 IT 기술 수준 등에서 차이가 있습니다. SafeKit 복제, 장애 조치, 로드 밸런싱 기능을 단일 제품에 통합한 순수 소프트웨어 방식 솔루션을 제공하여 전용 하드웨어나 엔터프라이즈 에디션이 필요하지 않습니다.

**표: 주요 배포 기준에 따른 소프트웨어 클러스터링( SafeKit ), 하드웨어 클러스터링, 하드웨어 로드 밸런서 비교**

기준 | [ SafeKit ](</>) 소프트웨어 클러스터링 | 하드웨어 클러스터링 | 하드웨어 로드 밸런서  
---|---|---|---  
기능 | (1) 실시간 파일 복제 <br> (2) 페일오버 툴킷 <br> (3) 네트워크 로드 밸런싱(전용 프록시 없음) | (1) 디스크 복제 <br> (2) 페일오버 툴킷 | (1) 네트워크 로드 밸런싱  
하드웨어 | 표준 물리 서버, 가상 서버 또는 클라우드 | 전용 스토리지(공유 또는 복제) | 전용 네트워크 로드 밸런싱 장비  
소프트웨어 | Windows , Linux 의 표준 버전 및 데이터베이스(PC용 운영 체제 및 무료 데이터베이스 버전 포함)를 포함합니다. | 운영 체제 및 데이터베이스의 엔터프라이즈 버전입니다. | 로드 밸런서용 펌웨어입니다.  
기술 | 배포에 필요한 특정 IT 기술 없음 SafeKit | 스토리지 및 운영 체제에 대한 고급 기술 | 네트워크에 대한 고급 기술  
  
요약 **, 소프트웨어 클러스터링** 실시간 복제, 자동 장애 조치, 네트워크 로드 밸런싱 SafeKit 세 가지 기능 **하나의 경량 제품에 모두 결합한 유일한 접근 방식입니다. 표준 운영 체제 및** 에디션을 사용하는 표준 하드웨어(물리적, 가상 또는 클라우드)에서 실행되므로 특별한 IT 기술이 필요하지 않습니다. 반면 하드웨어 클러스터링은 전용 스토리지 인프라와 엔터프라이즈 소프트웨어 라이선스가 필요하고, 하드웨어 로드 밸런싱은 전용 어플라이언스와 네트워크 전문 지식이 필요하며, 둘 다 소프트웨어 SafeKit 처럼 모든 기능을 기본적으로 제공하지 않습니다.
