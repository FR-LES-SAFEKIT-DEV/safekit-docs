# SafeKit: 올인원 SANless 고가용성 및 애플리케이션 클러스터링 소프트웨어 {#safekit-all-in-one-sanless-high-availability--application-clustering-software}

## SafeKit이란 무엇인가요? {#what-is-safekit}

**SafeKit**은 **올인원 고가용성 소프트웨어**입니다. 실시간 **호스트 기반 복제**, **자동 장애 조치** 및 **부하 분산**을 단일 패키지로 결합하여 데이터 손실 없이 약 1분 만에 두 번째 서버에서 애플리케이션을 다시 시작할 수 있습니다.

**SafeKit**은 표준 서버 간에 데이터를 동기화하여 고가의 공유 스토리지(SAN)나 전문 IT 기술의 필요성을 없애고, Windows 및 Linux 환경 전반에 걸쳐 **엔터프라이즈 데이터베이스** (SQL Server 등), **중요 보안 시스템** (Milestone XProtect 비디오 관리 소프트웨어 등), **SCADA 산업 제어 소프트웨어** (Siemens 애플리케이션 등)를 보호하는 간단하고 비용 효율적인 방법을 제공합니다.


SafeKit은 다음과 같은 상황으로부터 애플리케이션을 보호합니다:

* 컴퓨터실의 완전한 고장을 포함한 **하드웨어 고장**
* 중요 프로세스의 충돌 또는 정지와 같은 **소프트웨어 오류**가 발생하면 SafeKit은 오류를 감지하고 프로세스를 자동으로 다시 시작합니다
* 간단한 구성과 단일 웹 콘솔로 줄일 수 있는 **인적 오류**
