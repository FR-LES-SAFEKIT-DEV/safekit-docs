# SafeKit: SAN 없이도 고가용성 및 애플리케이션 클러스터링을 지원하는 올인원 소프트웨어 {#safekit-all-in-one-sanless-high-availability--application-clustering-software}

## SafeKit이란 무엇인가요? {#what-is-safekit}

**SafeKit**은 **올인원 고가용성 소프트웨어**입니다. 실시간 **호스트 기반 복제**, **자동 장애 조치** 및 **로드 밸런싱**을 단일 제품에 결합하여 데이터 손실 없이 약 1분 만에 두 번째 서버에서 애플리케이션을 다시 시작할 수 있습니다.

SafeKit은 표준 서버 간에 데이터를 동기화하므로 고가의 공유 스토리지(SAN)나 전문적인 IT 기술이 필요하지 않습니다. 이 솔루션은 Windows 및 Linux 환경에서 **기업 데이터베이스** (예: SQL Server), **중요 보안 시스템** (예: Milestone XProtect 비디오 관리 소프트웨어) 및 **SCADA 산업 제어 소프트웨어** (예: Siemens 애플리케이션)를 보호하는 간단하고 비용 효율적인 방법을 제공합니다.


SafeKit은 다음과 같은 상황으로부터 애플리케이션을 보호합니다:

* **하드웨어 장애:** SafeKit은 전체 서버실의 손실까지도 보장합니다.
* **소프트웨어 오류:** SafeKit은 충돌하거나 멈춘 중요 프로세스를 감지하고 자동으로 다시 시작합니다.
* **인적 오류:** 간단한 구성과 단일 웹 콘솔로 실수 위험을 줄입니다.
