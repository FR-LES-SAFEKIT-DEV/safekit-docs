# SafeKit: 올인원 SANless 고가용성(HA) 및 애플리케이션 클러스터링 소프트웨어 {#safekit-all-in-one-sanless-high-availability--application-clustering-software}

## SafeKit이란 무엇인가요? {#what-is-safekit}

**SafeKit**은 **올인원 고가용성 소프트웨어**입니다. 실시간 **호스트 기반 복제**, 자동 **장애 조치(failover)**, **부하 분산(load balancing)**을 하나의 패키지로 결합하여 데이터 손실 없이 약 1분 안에 애플리케이션을 두 번째 서버에서 다시 시작합니다.

표준 서버 간의 데이터를 동기화함으로써 **SafeKit** 은 고가의 공유 스토리지(SAN)나 전문적인 IT 기술 없이도 **엔터프라이즈 데이터베이스**(SQL Server 등), **핵심 보안 시스템**(Milestone XProtect 비디오 관리 소프트웨어 등), **SCADA 산업용 제어 소프트웨어**(Siemens 애플리케이션 등)를 Windows 및 Linux 환경 모두에서 보호할 수 있는 간단하고 비용 효율적인 방법을 제공합니다.


SafeKit은 다음과 같은 문제로부터 애플리케이션을 보호합니다:

* **하드웨어 장애**(서버실 전체의 장애 포함)
* **소프트웨어 장애**(중요 프로세스의 충돌 또는 중단을 자동으로 감지하고 재시작)
* **사람의 실수**(간단한 구성과 단일 웹 콘솔로 감소)
