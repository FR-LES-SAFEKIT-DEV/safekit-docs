# 데이터센터 없이 엣지 고가용성 구현: OT 및 분산 사이트를 위한 SafeKit {#edge-high-availability-without-a-data-center-safekit-for-ot--distributed-sites}

## 엣지 HA 챌린지 {#the-edge-ha-challenge}

엣지 사이트는 데이터 센터가 없고 고가용성(HA) 전문 지식도 부족한 경우가 많지만, 비즈니스 연속성은 매우 중요합니다. 공장, 해상 석유 시추 플랫폼, 병원, 소매점, 5G 안테나 사이트 등은 가동 중단을 용납할 수 없지만, 기존 데이터 센터 HA 클러스터를 구축하는 데 드는 비용과 복잡성 때문에 엄두를 내지 못하는 경우가 많습니다.

기존의 Microsoft 가용성(HA) 솔루션(WSFC(Failover Cluster), Pacemaker/Corosync, VMware HA 등)은 데이터 센터용으로 설계되었습니다. 이러한 솔루션은 공유 스토리지(SAN/NAS), 전용 클러스터 하드웨어, 상주 IT 직원, 복잡한 운영 체제 수준의 전문 지식을 전제로 합니다. 하지만 이러한 요소들은 엣지 환경에서는 존재하지 않습니다.

SafeKit 바로 이러한 격차를 해소하기 위해 개발되었습니다. 이 제품은 표준 서버 두 대와 LAN만으로 공장, 석유 시추 플랫폼, 선박, 건물 보안, 항공 교통 관제, 5G 네트워크, 의료, 소매업 등 다양한 분야에서 엣지 애플리케이션을 안정적으로 운영할 수 있도록 지원합니다.

## SafeKit Edge {#what-makes-safekit-the-natural-fit-for-edge} 에 완벽하게 어울리는 이유는 무엇일까요?

SafeKit 표준 엣지 서버 두 대(브랜드, 물리적 또는 가상 서버 불문)를 플러그 앤 플레이 방식의 고가용성(HA) 클러스터로 구성해 줍니다. 공유 스토리지, SAN, 특수 하드웨어가 필요하지 않습니다. 하나의 경량 소프트웨어 스택으로 다음과 같은 기능을 제공합니다.

  * ** 실시간 동기 파일 복제 ** — 데이터는 쓰기 시점에 바이트 단위로 대기 서버에 미러링됩니다.
  * ** 자동 페일오버 ** — 기본 서버에 장애가 발생하면 대기 서버가 사람의 개입 없이 몇 초 내에 자동으로 인계됩니다.
  * ** 선택적 네트워크 로드 밸런싱 ** — 두 서버가 워크로드를 공유하는 액티브-액티브 배포용
  * ** 웹 콘솔 ** — 브라우저 기반 관리, HTTPS를 통해 원격 접속 가능, 현장 전문가 불필요
  * ** 스크립트로 간편하게 설치할 수 있는 무인 설치 방식이며, ** OEM 내장 및 수백 개의 분산된 사이트에 걸친 대규모 배포에 적합합니다.


SAN을 구매할 필요도 없고, Windows 서버 데이터센터 라이선스도 필요 없으며, Linux 클러스터 OS 전문 지식도 필요 없고, 전용 클러스터 하드웨어도 필요 없습니다. 전체 HA 스택이 단일 소프트웨어 패키지로 구성되어 있습니다.

## 엣지 및 분산 배포 적합성 {#edge--distributed-deployment-suitability}

SafeKit 는 엣지, 지점, 분산형 엔터프라이즈 시나리오에 맞게 특별히 설계되었습니다.

에지 요구 사항 | SafeKit 답변  
---|---  
현장에 전담 IT 직원이 없습니다 | 자동 장애 조치 기능으로 수동 개입이 필요 없습니다.  
SAN/NAS 인프라 없음 | SAN리스 아키텍처, 로컬 디스크만 사용  
원격 관리 | 웹 콘솔은 모든 브라우저에서 HTTPS를 통해 접속할 수 있습니다.  
하드웨어 요구 사항이 낮은 | 표준 서버 또는 가상 머신 2대를 지원하며, 특별한 하드웨어가 필요하지 않습니다.  
방화벽/NAT 환경에서도 작동, | 포트 구성 가능, HTTPS 기반 콘솔  
두 지리적 사이트 간의 확장된 VLAN을 통한 다중 사이트 재해 복구 | Mirror  
인터넷 연결이 필요 없는 완전 독립형 네트워크 |  
OEM/임베디드 배포 | 무인 설치, 스크립트 가능, 소프트웨어 게시자가 임베딩 가능  
수백 개의 분산 클러스터 | 는 여러 지점을 관리하는 분산형 기업을 위해 설계되었습니다.  
  
## 엣지 OT 환경이 다른 이유는 무엇일까요 {#why-edge-ot-environments-are-different}

OT(운영 기술) 환경(SCADA, BMS, 물리적 보안, 산업 제어)은 IT 데이터 센터와 근본적으로 다른 요구 사항을 가지고 있습니다.

  * ** 현장에 IT 직원이 없습니다. ** 변전소, 원격 펌프 스테이션 또는 선박에는 시스템 관리자가 없습니다. 고가용성(HA)은 자체 관리되어야 합니다.
  * ** 에어갭 또는 제한된 네트워크. ** 많은 OT 사이트는 인터넷 접속이 불가능하고 WAN 대역폭이 제한적입니다. HA 소프트웨어는 완전히 오프라인에서 작동해야 합니다.
  * ** 24시간 365일 가동을 보장하며, 복잡성을 허용하지 않습니다. ** 생산 라인 중단, 영상 감시 시스템 손실 또는 접근 제어 중단은 고가용성 소프트웨어 자체보다 훨씬 더 큰 손실을 초래합니다.
  * ** 장비 수명 주기가 깁니다. ** OT 서버는 10~15년 동안 작동할 수 있습니다. 고가용성(HA) 솔루션은 안정적이고 유지 관리가 간편하며 지속적인 업데이트가 필요하지 않아야 합니다.
  * ** 표준 x86 하드웨어만 지원합니다. ** 원격 산업 현장에 SAN 또는 전용 클러스터 노드를 설치할 예산이나 타당성이 없습니다.
  * ** OS 수준의 복잡성에 대한 허용치가 낮습니다. ** Pacemaker, Corosync 또는 WSFC는 OT 운영자가 보유하지도 않고 필요로 하지도 않는 클러스터 전문 지식을 요구합니다.


SafeKit 의 SAN이 필요 없는 2개 서버 자동 장애 조치 모델은 이러한 모든 제약 조건을 직접적으로 해결합니다.

## 엣지 고가용성(HA)과 데이터센터 고가용성(HA): 주요 차이점 {#edge-vs-data-center-ha-key-differences}

기준 | 데이터 센터 HA(WSFC, Pacemaker, VMware HA) | SafeKit 엣지 HA  
---|---|---  
스토리지 | 는 SAN/NAS 공유 스토리지가 필요하고, | SAN이 필요 없으며 로컬 디스크만 사용합니다.  
하드웨어 | 전용 클러스터 노드, HBA, 스위치 | 표준 x86 서버 두 대  
OS 전문 지식 | Windows , 데이터센터 또는 클러스터 OS 기술 Linux , 표준 관리 기술 | Windows / Linux  
현장 직원 | 설치 및 개입 필요) | (완전 자동 작동) (필요 없음)  
인터넷/클라우드 의존성 | 클라우드 관리형 | 완전한 에어갭 기능 지원  
배포 규모 | 단일 데이터 센터 | 수백 개의 분산 사이트  
라이선스 비용 | 높음 (데이터센터 OS, SAN 라이선스) | 클러스터당 단일 저렴한 소프트웨어 라이선스  
일반적인 RTO | 1~5분, | 는 1분 미만(설정 가능)입니다.  
  
## 기술 최소 요구 사항 {#technical-minimum-requirements}

  * ** 서버: ** 표준 x86 서버 또는 VM 2대(하드웨어 브랜드 무관, 물리적 또는 가상) 또는 ARM( Linux 만 해당)
  * ** OS: ** Windows Server 2019/2022/2025, Windows 11, RHEL 8/9, Ubuntu 24.04
  * ** 네트워크: 복제를 위한 ** 1Gbps LAN; 전용 하트비트 네트워크 사용을 권장합니다.
  * ** 스토리지: ** 로컬 디스크만 사용 - SAN, NAS, 공유 스토리지 등은 일절 사용하지 않음
  * ** 특별한 OS 에디션이 필요하지 않으며, ** 부터 Windows 까지는 서버 스탠다드 버전으로 충분합니다. 데이터센터 라이선스는 필요하지 않습니다.
