# SafeKit: alles-in-één software voor hoge beschikbaarheid en applicatieclustering zonder SAN {#safekit-all-in-one-sanless-high-availability--application-clustering-software}

## Wat is SafeKit? {#what-is-safekit}

**SafeKit** is **alles-in-één software voor hoge beschikbaarheid**. Het combineert real-time **host-gebaseerde replicatie**, **automatische failover** en **load balancing** in één product, zodat uw applicatie binnen ongeveer een minuut opnieuw opstart op een tweede server zonder gegevensverlies.

SafeKit synchroniseert gegevens tussen standaardservers, zodat u geen dure gedeelde opslag (SAN) of gespecialiseerde IT-vaardigheden nodig hebt. Het biedt een eenvoudige, kosteneffectieve manier om **bedrijfsdatabases** (zoals SQL Server), **kritieke beveiligingssystemen** (zoals de Milestone XProtect videobeheersoftware) en **SCADA industriële besturingssoftware** (zoals Siemens toepassingen) te beschermen op zowel Windows als Linux.


SafeKit beschermt uw applicaties tegen:

* **Hardwarestoringen:** SafeKit dekt ook het verlies van een complete serverruimte.
* **Softwarefouten:** SafeKit detecteert een kritiek proces dat crasht of vastloopt en start het automatisch opnieuw op.
* **Menselijke fouten:** een eenvoudige configuratie en één enkele webconsole verminderen het risico op fouten.
