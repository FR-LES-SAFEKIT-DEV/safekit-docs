# Alta disponibilidade e redundância para sistemas de gestão predial (BMS) {#high-availability-and-redundancy-for-building-management-systems-bms}

##  O que é um sistema de gestão predial (BMS)? {#what-is-a-building-management-system-bms}

Um sistema de gestão predial (BMS) proporciona o controle centralizado e automático dos sistemas de climatização (aquecimento, ventilação e ar condicionado), elétrico, de iluminação...

Um sistema de gestão predial aumenta a segurança dos moradores do edifício, reduz o consumo de energia e diminui os custos de operação e manutenção.

##  Por que um software BMS é essencial? {#why-a-bms-software-is-critical}

Um software BMS controla o sistema de incêndio, os painéis de distribuição elétrica, o consumo de água, os sistemas de ar condicionado e o controle de iluminação.

A segurança da vida no edifício está diretamente relacionada à correta execução do software BMS.

Por isso, o sistema deve estar sempre disponível para os operadores do edifício, que precisam reagir imediatamente ao menor incidente.
