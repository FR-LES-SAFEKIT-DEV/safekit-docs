# Padronizando a alta disponibilidade para empresas distribuídas com muitas filiais {#standardizing-high-availability-for-distributed-enterprises-with-many-branches}

## Continuidade de negócios em uma empresa distribuída {#business-continuity-in-a-distributed-enterprise}

### Uma solução padrão de alta disponibilidade para muitas filiais {#business-continuity-in-a-distributed-enterprise-1}

Uma empresa distribuída executa as mesmas aplicações críticas em muitas filiais. Com SafeKit, implementar dezenas de clusters idênticos é simples.


![software de continuidade de negócios em uma empresa distribuída](/wp-content/uploads/2023/02/distributed-enterprise-1.png "w:300")


### Como implementar um software de continuidade de negócios sem conhecimentos específicos de TI? {#how-to-deploy-a-business-continuity-software-without-specific-it-skills}

Garantir a continuidade dos negócios para vários aplicativos em servidores Windows ou Linux em cada filial gera problemas econômicos e organizacionais. SafeKit resolve esses problemas com um software de continuidade de negócios simples e econômico.

### O software SafeKit: uma solução simples para a continuidade dos negócios {#the-safekit-software-a-simple-solution-for-business-continuity}

SafeKit oferece dois módulos simples: o módulo mirror e o módulo <span class="notranslate farm-term" translate="no">farm</span>. Eles protegem seus aplicativos críticos contra falhas. Você os implanta em servidores padrão e não precisa de conhecimentos de TI para gerenciar a solução. Você não precisa de um disco compartilhado, uma SAN replicada, balanceadores de carga ou edições empresariais de sistemas operacionais ou bancos de dados.
