# Alta Disponibilidade e Redundância para Software de Controle de Acesso Eletrônico (EACS) {#high-availability-and-redundancy-for-electronic-access-control-software-eacs}

##  O que é um sistema eletrônico de controle de acesso (EACS)? {#what-is-an-electronic-access-control-system-eacs}

Um sistema eletrônico de controle de acesso consiste em dispositivos de hardware que controlam a entrada em instalações privadas.

Roubos e arrombamentos são crimes comuns em empresas. É por isso que os sistemas eletrônicos de controle de acesso são amplamente utilizados.

##  Por que o software EACS é fundamental? {#why-an-eacs-software-is-critical}

O software EACS gerencia os dispositivos de hardware. Ele impede a entrada de pessoas não autorizadas e dispara um alarme quando um intruso invade o local.

A segurança das pessoas depende diretamente do funcionamento correto do software EACS.

Os agentes de segurança devem reagir imediatamente ao menor incidente. O sistema deve, portanto, estar sempre disponível para eles.
