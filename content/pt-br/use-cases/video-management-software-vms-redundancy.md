# Alta Disponibilidade e Redundância para Software de Gerenciamento de Vídeo (VMS) {#high-availability-and-redundancy-for-video-management-software-vms}

##  O que é um software de gerenciamento de vídeo (VMS)? {#what-is-video-management-software-vms}

O software de gerenciamento de vídeo (VMS) coleta e grava o vídeo da câmera. Ele fornece uma interface para os operadores visualizarem vídeos ao vivo e gravados.

O software de gerenciamento de vídeo aumenta a segurança e reduz o roubo. Ele também melhora a eficiência dos agentes de segurança.

##  Por que o software VMS é fundamental? {#why-a-vms-software-is-critical}

O software VMS registra todos os atos criminosos, desde roubo até assassinato. Ele também ajuda a rastrear criminosos.

A segurança das pessoas depende diretamente do software VMS.

Os agentes de segurança devem reagir imediatamente ao menor incidente. O software VMS deve, portanto, estar sempre disponível para eles.
