# SafeKit: software tudo-em-um para alta disponibilidade e agrupamento de aplicações sem SAN {#safekit-all-in-one-sanless-high-availability--application-clustering-software}

## O que é SafeKit? {#what-is-safekit}

**SafeKit** é **um software de alta disponibilidade tudo-em-um**. Combina **replicação em tempo real baseada no anfitrião**, **failover automático** e **balanceamento de carga** num único produto, para que a sua aplicação reinicie num segundo servidor em cerca de um minuto, sem perda de dados.

SafeKit sincroniza dados entre servidores padrão, pelo que não necessita de armazenamento partilhado dispendioso (SAN) ou de competências de TI especializadas. Oferece uma forma simples e económica de proteger **bases de dados empresariais** (como SQL Server), **sistemas de segurança críticos** (como o software de gestão de vídeo Milestone XProtect) e **software de controlo industrial SCADA** (como aplicações Siemens) tanto em Windows como em Linux.


SafeKit protege as suas aplicações contra:

* **Falhas de hardware:** SafeKit também cobre a perda de uma sala de servidores inteira.
* **Falhas de software:** SafeKit deteta um processo crítico que falha ou congela e reinicia-o automaticamente.
* **Erros humanos:** uma configuração simples e uma única consola web reduzem o risco de erros.
