# Alta disponibilidade para gestão de edifícios (BMS) {#high-availability-for-building-management-bms}

![Alta Disponibilidade e Redundância para Sistemas de Gestão de Edifícios (BMS)](/wp-content/uploads/2026/05/safekit-bms-512-512.jpg)

##  O que é um sistema de gestão de edifícios (BMS)? {#what-is-a-building-management-system-bms}

Um sistema de gestão de edifícios (BMS) fornece controlo automático e centralizado dos serviços do edifício: aquecimento, ventilação e ar condicionado (HVAC), distribuição de energia, iluminação e muito mais.

Um sistema de gestão de edifícios aumenta a segurança dos ocupantes do edifício. Também reduz o consumo de energia e diminui os custos de operação e manutenção.

##  Por que é que o software BMS é tão importante? {#why-a-bms-software-is-critical}

O software BMS controla os sistemas de segurança contra incêndios, os quadros de distribuição elétrica, o consumo de água, os sistemas de ar condicionado e a iluminação.

A segurança dos ocupantes do edifício depende diretamente do correto funcionamento do software do BMS.

É por isso que o sistema deve estar sempre disponível. Os operadores do edifício devem reagir imediatamente ao mais pequeno incidente.
