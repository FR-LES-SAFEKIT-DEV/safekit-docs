# Padronização da Alta Disponibilidade para Empresas Distribuídas com Múltiplas Filiais {#standardizing-high-availability-for-distributed-enterprises-with-many-branches}

## Continuidade de negócios numa empresa distribuída {#business-continuity-in-a-distributed-enterprise}

### Uma solução padrão de alta disponibilidade para várias filiais {#business-continuity-in-a-distributed-enterprise-1}

Uma empresa distribuída executa as mesmas aplicações críticas em muitas filiais. Com SafeKit, a implementação de dezenas de clusters idênticos é simples.


![software de continuidade de negócios numa empresa distribuída](/wp-content/uploads/2023/02/distributed-enterprise-1.png "w:300")


### Como implementar software de continuidade de negócios sem conhecimentos específicos de TI? {#how-to-deploy-a-business-continuity-software-without-specific-it-skills}

Garantir a continuidade de negócios para múltiplas aplicações em servidores Windows ou Linux em cada sucursal levanta problemas económicos e organizacionais. SafeKit resolve estes problemas com um software de continuidade de negócios simples e económico.

### O software SafeKit: uma solução simples para a continuidade do negócio {#the-safekit-software-a-simple-solution-for-business-continuity}

SafeKit oferece dois módulos simples: o módulo mirror e o módulo <span class="notranslate farm-term" translate="no">farm</span>. Eles protegem as suas aplicações críticas contra falhas. Pode implementá-los em servidores padrão e não precisa de conhecimentos de TI para gerir a solução. Não precisa de um disco partilhado, de uma SAN replicada, de balanceadores de carga ou de edições empresariais de sistemas operativos ou bases de dados.
