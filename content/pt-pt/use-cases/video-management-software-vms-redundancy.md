# Alta Disponibilidade e Redundância para Software de Gestão de Vídeo (VMS) {#high-availability-and-redundancy-for-video-management-software-vms}

##  O que é um software de gestão de vídeo (VMS)? {#what-is-video-management-software-vms}

O software de gestão de vídeo (VMS) recolhe e grava o vídeo das câmaras. Fornece uma interface para os operadores visualizarem o vídeo em direto e gravado.

O software de gestão de vídeo aumenta a segurança e reduz os roubos. Também melhora a eficiência dos agentes de segurança.

##  Por que é que o software VMS é crucial? {#why-a-vms-software-is-critical}

O software VMS regista todos os atos criminosos, desde roubos a homicídios. Também ajuda a localizar criminosos.

A segurança das pessoas depende diretamente do software VMS.

Os agentes de segurança devem reagir imediatamente ao mais pequeno incidente. O software VMS deve, portanto, estar sempre disponível para eles.
