# Alta disponibilidade e redundância para software de gerenciamento de vídeo (VMS) {#high-availability-and-redundancy-for-video-management-software-vms}

##  O que é um software de gerenciamento de vídeo (VMS)? {#what-is-video-management-software-vms}

O software de gerenciamento de vídeo (VMS) coleta e grava vídeos das câmeras e fornece uma interface para que os operadores visualizem vídeos ao vivo e gravados.

O software de gestão de vídeo aumenta a segurança da vida, reduz os roubos e melhora a eficiência dos agentes de segurança.

##  Por que um software VMS é essencial? {#why-a-vms-software-is-critical}

O software de gerenciamento de vídeo (VMS) registra todos os atos criminosos, desde roubo até assassinato, e fornece um meio de rastrear criminosos.

A segurança das pessoas está diretamente relacionada à correta execução do software VMS.

E é por isso que o sistema deve estar sempre disponível para os agentes de segurança, que precisam reagir imediatamente ao menor incidente.
