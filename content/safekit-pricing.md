# How SafeKit pricing works

## Licensing model and pricing {#licensing-model-and-pricing}

SafeKit uses a **perpetual licensing model** : the license is purchased once and is based on the hostnames of the protected servers. Licensing is scoped per server (physical or virtual). A standard SafeKit cluster typically uses 2 servers.

Pricing is independent of the number of CPUs or sockets and of the Windows or Linux edition.

The pre-configured `.safe` application modules are provided free of charge.

SafeKit supports offline license activation, so an internet connection is not required to activate a license key.

A full-featured free trial is available for evaluation.

## Standard support and maintenance {#standard-support-and-maintenance}

The first year of standard support and maintenance is mandatory with the license purchase. Subsequent years can be renewed optionally.

With an active support contract, standard support includes 24/7/365 access to the web support portal for up to four named Technical Contacts, Knowledge Base access, and all Service Packs, Updates and Upgrades at no additional charge. Live support is available from the European Support Centre, Monday to Friday, 9:00 AM–5:00 PM, with incident acknowledgement within four Support Centre Working Hours.

## Request a quote {#information-to-include-in-your-quote-request}

  * Specify the number of nodes; a standard SafeKit cluster typically has 2 nodes.
  * Specify whether the nodes run Windows or Linux.
  * Specify the application for application-level HA or the hypervisor for VM-level HA.


**Note:** For VM-level HA, `hyperv.safe` and `kvm.safe` require only two SafeKit licenses for the two hypervisor hosts, regardless of the number of virtual machines replicated and restarted.
