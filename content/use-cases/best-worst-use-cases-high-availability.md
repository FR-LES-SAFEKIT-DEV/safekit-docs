# Best and Worst High Availability Use Cases: A SafeKit Implementation Guide {#best-and-worst-high-availability-use-cases-a-safekit-implementation-guide}

## Best use cases {#best-use-cases}

### OEM Software {#oem-software}

A software vendor uses SafeKit as OEM software for the high availability of its application. Read more about the [OEM use case](</use-cases/application-clustering-software/>).


![Application clustering software for a software vendor](/wp-content/uploads/2023/02/application-clustering-software-3.png "w:300")


### Distributed Enterprise {#distributed-enterprise}

A distributed enterprise deploys SafeKit in many branches without specific IT skills. Read more about the [distributed enterprise use case](</use-cases/business-continuity-software/>).


![High availability software in a distributed enterprise](/wp-content/uploads/2023/02/distributed-enterprise-1.png "w:300")


### Remote Sites {#remote-sites}

SafeKit is deployed on two remote sites. It does not need disk arrays replicated through a SAN. Read more about [high availability and disaster recovery](</best-practises/high-availability-disaster-recovery-hadr/>).


![Business continuity and disaster recovery without a replicated SAN](/wp-content/uploads/2023/02/remote-datacenters.png "w:300")
