# SafeKit：全合一 SANless 高可用性与应用程序集群软件

## 什么是 SafeKit？

**SafeKit** 是一款**全合一高可用性软件** 解决方案，它将实时**基于主机的复制** 、自动**故障转移** 和**负载均衡** 整合到一个软件包中，确保应用程序实现 100% 的正常运行时间。

通过在标准服务器之间同步数据，**SafeKit** 摆脱了对昂贵的共享存储（SAN）或专业 IT 技能的依赖，为在 Windows 和 Linux 环境中保护**企业数据库** （如 SQL Server）、**关键安全系统** （如 Milestone XProtect 视频管理软件）以及 **SCADA 工业控制软件** （如西门子应用）提供了一种简单且极具成本效益的方式。
