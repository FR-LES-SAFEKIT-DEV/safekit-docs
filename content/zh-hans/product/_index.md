# SafeKit：一体化无共享存储高可用性和应用集群软件 {#safekit-all-in-one-sanless-high-availability--application-clustering-software}

## 什么是 SafeKit？ {#what-is-safekit}

**SafeKit** 是**一款一体化高可用性软件**。它将**基于主机的实时复制**、**自动故障转移**和**负载均衡**结合在一个软件包中，因此您的应用程序可以在大约一分钟内重新启动到第二台服务器上，且不会丢失数据。

通过在标准服务器之间同步数据，**SafeKit** 无需昂贵的共享存储 (SAN) 或专业的 IT 技能，即可提供一种简单、经济高效的方式来保护**企业数据库**（如 SQL Server）、**关键安全系统**（如 Milestone XProtect 视频管理软件）和 **SCADA 工业控制软件**（如 Siemens 应用程序），同时支持 Windows 和 Linux 环境。


SafeKit 可保护您的应用程序免受以下威胁：

* **硬件故障**，包括机房完全瘫痪
* **软件故障**，例如关键进程崩溃或冻结。SafeKit 会检测到故障并自动重启进程
* 通过简单的配置和单一的 Web 控制台，可减少**人为错误**
