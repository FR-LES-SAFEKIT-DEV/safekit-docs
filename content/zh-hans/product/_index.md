# SafeKit：一体化高可用性和应用集群软件，无需 SAN {#safekit-all-in-one-sanless-high-availability--application-clustering-software}

## 什么是 SafeKit？ {#what-is-safekit}

**SafeKit** 是**一款一体化高可用性软件**。它将**基于主机的实时复制**、**自动故障转移**和**负载均衡**结合在一个产品中，因此您的应用程序可以在大约一分钟内重新启动到第二台服务器上，且不会丢失数据。

SafeKit 可在标准服务器之间同步数据，因此您无需昂贵的共享存储 (SAN) 或专业的 IT 技能。它提供了一种简单、经济高效的方式来保护 Windows 和 Linux 上的**企业数据库**（如 SQL Server）、**关键安全系统**（如 Milestone XProtect 视频管理软件）和 **SCADA 工业控制软件**（如 Siemens 应用程序）。


SafeKit 可保护您的应用程序免受以下威胁：

* **硬件故障：** SafeKit 还涵盖了整个服务器机房的损失。
* **软件故障：** SafeKit 会检测到崩溃或冻结的关键进程，并自动重新启动。
* **人为错误：** 简单的配置和单一的 Web 控制台可降低出错风险。
