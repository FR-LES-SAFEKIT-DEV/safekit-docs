# SafeKit：全合一 SANless 高可用性与应用程序集群软件 {#safekit-all-in-one-sanless-high-availability--application-clustering-software}

## 什么是 SafeKit？ {#what-is-safekit}

**SafeKit** 是**全合一高可用性软件**。它将实时**基于主机的复制**、自动**故障转移**和**负载均衡**整合到一个软件包中，使应用程序可在约一分钟内于第二台服务器上重新启动，且不会丢失数据。

通过在标准服务器之间同步数据，**SafeKit** 摆脱了对昂贵的共享存储（SAN）或专业 IT 技能的依赖，为在 Windows 和 Linux 环境中保护**企业数据库** （如 SQL Server）、**关键安全系统** （如 Milestone XProtect 视频管理软件）以及 **SCADA 工业控制软件** （如西门子应用）提供了一种简单且极具成本效益的方式。


SafeKit 可保护您的应用程序免受以下问题影响：

* **硬件故障**，包括整个机房完全失效
* **软件故障**，包括关键进程崩溃或冻结；系统会自动检测并重启这些进程
* **人为错误**，可通过简单配置和单一 Web 控制台减少
