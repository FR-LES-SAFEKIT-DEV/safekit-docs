# SafeKit 高可用性培训：免费在线认证计划 {#safekit-high-availability-training-free-online-certification-program}

## 如何进入培训平台？ {#certif}

### SafeKit 培训平台 {#the-safekit-training-platform}

SafeKit 在线培训是一种自定进度的综合资源，旨在帮助您掌握高可用性和应用程序集群。您可以通过以下步骤访问该平台：

  * 导航至**👉🎓[SafeKit在线培训平台](<https://training.my.evidian.com/mod/page/view.php?id=712>)**。这是您所有学习模块和免费认证计划的中心枢纽。
  * **获取您的凭据：** 如果您还没有帐户，请单击 **联系方式** 在培训平台的顶部菜单中请求您的登录凭据。
  * 该平台分为多个主题部分，包括： 
    * **架构和简介：** 了解镜像和场集群概念。
    * **演示：** 访问基于视频的 SQL Server、Hyper-V 和 Apache 负载平衡场景。
    * **安装和设置：** 了解如何通过 Web 管理控制台或 CLI 安装软件包和配置。
    * **高级配置：** 深入研究 userconfig.xml、心跳、复制和虚拟 IP。
  * **利用视频课程：** 大部分培训都是通过托管视频提供的。每个视频通常分为几个章节（例如，先决条件、安装、故障排除），以便您可以直接跳转到您需要的主题。
  * **通过测验获得不同级别的认证：** 在模块结束时测试您的知识，以获得对您 SafeKit 专业知识的官方认可。
  * **获取 SafeKit 8 份培训材料：** 访问 [完整资源包](#training82) 以支持您的学习。
