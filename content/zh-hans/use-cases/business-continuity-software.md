# 为拥有众多分支机构的分布式企业实现高可用性的标准化 {#standardizing-high-availability-for-distributed-enterprises-with-many-branches}

## 分布式企业中的业务连续性 {#business-continuity-in-a-distributed-enterprise}

### 为众多分支机构提供标准的高可用性解决方案 {#business-continuity-in-a-distributed-enterprise-1}

分布式企业在许多分支机构运行相同的关键应用程序。使用 SafeKit，部署数十个相同的集群非常简单。


![分布式企业中的业务连续性软件](/wp-content/uploads/2023/02/distributed-enterprise-1.png "w:300")


### 如何在没有特定 IT 技能的情况下部署业务连续性软件？ {#how-to-deploy-a-business-continuity-software-without-specific-it-skills}

为每个分支机构 Windows 或 Linux 服务器上的多个应用程序提供业务连续性会引发经济和组织问题。SafeKit 凭借简单且经济高效的业务连续性软件解决了这些问题。

### SafeKit 软件：一个简单的业务连续性解决方案 {#the-safekit-software-a-simple-solution-for-business-continuity}

SafeKit 提供两个简单的模块：mirror 模块和 <span class="notranslate farm-term" translate="no">farm</span> 模块。它们可保护您的关键应用程序免受故障影响。您可以在标准服务器上部署它们，并且无需 IT 技能即可管理该解决方案。您不需要共享磁盘、复制 SAN、负载均衡器或操作系统或数据库的企业版。
