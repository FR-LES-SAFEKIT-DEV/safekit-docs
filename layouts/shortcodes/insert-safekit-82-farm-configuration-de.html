Wählen Sie ein Modul aus * Klicken Sie in `New module` auf das Modul `{{ .Get "mod" }}.safe`. ℹ️Im blauen Banner oben,🛜 `node1`stellt den Konsolenverbindungsknoten dar. Modul konfigurieren * Wählen Sie in `Module startup at boot` die Option, das Modul beim Systemstart ohne Verzögerung automatisch zu starten. * Geben Sie in `Macros` / `SERVICES` die Dienstnamen Ihrer Anwendung in der Startreihenfolge durch Kommas getrennt ein. * In `Heartbeat networks` sollten Sie ein einzelnes Heartbeat-Netzwerk haben, es sei denn, Sie haben in Schritt 2 ein LAN hinzugefügt. * Geben Sie in `Virtual IP addresses` eine virtuelle Adresse IP ein. Eine virtuelle Adresse IP ist eine Standardadresse IP im selben Netzwerk IP (demselben Subnetz) wie die Adressen IP beider Knoten. Anwendungsclients müssen mit der virtuellen Adresse IP (oder dem DNS-Namen der virtuellen Adresse IP) konfiguriert werden. * In `Load balancing rules` wird der Dienstport für den Lastausgleich festgelegt (z. B. TCP 9010 im Beispiel). * In `Load balancing rules` legen Sie die Lastverteilungsregel, `Source address` oder `Source port` fest: * Mit der Quelladresse IP des Clients wird derselbe Client über mehrere TCP-Sitzungen mit demselben Knoten im Bereich farm verbunden und ruft seinen Kontext auf dem Knoten ab. * Mit dem Quell-TCP-Port des Clients wird derselbe Client über mehrere TCP-Sitzungen mit verschiedenen Knoten im farm verbunden (ohne einen Kontext abzurufen). * In `Checkers` können Sie bei Bedarf Prüfmechanismen konfigurieren, z. B. Prozessüberwachung, benutzerdefinierte Prüfmechanismen sowie TCP-, Ping- oder Split-Brain-Prüfmechanismen. Wird beispielsweise ein Prozessname in `Monitored processes/services` angezeigt, wird dieser überwacht und im Fehlerfall neu gestartet. Die Konfiguration eines falschen Prozessnamens führt dazu, dass das Modul direkt nach dem Start beendet wird. ℹ️Wenn Sie auf klicken`Advanced configuration`, Die`userconfig.xml`Die Datei wird angezeigt. Diese Datei wird automatisch von der Konsole befüllt und zusammen mit den Neustartskripten auf den Knoten bereitgestellt. ℹ️Bei einer Cloud-Bereitstellung ist keine Konfiguration eines virtuellen Servers erforderlich.IPAdress- und Lastverteilungsregeln inSafeKitDie virtuelleIPund die Regeln für den Lastausgleich werden auf der🛠️ [Cloud Load Balancer-Ebene](/resources/safekit-user-guide-82/#Cloud)Die ℹ️Wenn Sie dieSafeKitKonfiguration, die`startup type`von Diensten wird automatisch eingestellt auf`Manual`in Windows-Diensten. Dadurch wird sichergestellt, dass Dienste nicht automatisch beim Systemstart gestartet werden, sondern nur dann, wenn das Modul selbst gestartet wird (dasselbe gilt fürLinux). ![Geben Sie die Moduleinstellungen für {{ .Get "app" }} und farm ein.](/wp-content/uploads/2025/05/36-module-farm-config-edit-1.jpg) ### 5.
