Geroutete Layer-3-Netzwerke erfordern 🛠️ [Cloud-Load Balancer](/de/resources/safekit-user-guide-82/#Cloud). ### 1. Starten Sie die SafeKit Konsole {#1-launch-the-safekit-console} * Öffnen Sie auf einem Clusterknoten einen Browser und verbinden Sie sich mit `http://localhost:9010`. * Melden Sie sich mit dem Benutzernamen `admin` und dem während der Installation festgelegten Passwort an. Sie können die Konsole auch von einer Workstation außerhalb des Clusters aus öffnen. ⚠️ Verwenden Sie einen einzigen Browser, um beide Knoten mit SafeKit zu konfigurieren. ℹ️ Um die Webkonsole zu sichern, siehe 🛠️ [11. Sichern des SafeKit Webdienstes](/de/resources/safekit-user-guide-82/#https) im Benutzerhandbuch. ![SafeKit Webkonsole für den {{ .Get "app" }} Cluster](/wp-content/uploads/2024/03/01-login-large.png) ### 2. Knotenadressen konfigurieren {#2-configure-node-addresses} * Geben Sie die IP-Adresse jedes Knotens ein. Drücken Sie die Tabulatortaste, um die Verbindung zu überprüfen und die Knotennamen auszufüllen. * Wenn `node1` oder `node2` rot ist, überprüfen Sie, ob der Browser beide Knoten erreichen kann. Überprüfen Sie die Firewall auf jedem Knoten. Siehe 🛠️ [Fehlerbehebung](/de/resources/safekit-user-guide-82/#Troubleshooting). * Klicken Sie auf `Save and apply` um die Konfiguration zu speichern. * Überprüfen Sie, ob bei beiden Knoten ✅ `Success` angezeigt wird. * Wenn ein Knoten ❌ `Failure` anzeigt, erweitern Sie sein ▼ Panel und lesen Sie die Nachrichten. Verwenden Sie die SafeKit AI 🤖 wenn Sie Hilfe benötigen. ℹ️ Um ein zweites Heartbeat-Netzwerk und ein dediziertes Replikationsnetzwerk hinzuzufügen, klicken Sie auf die erste ➕ Schaltfläche unter `LAN and nodes`. ℹ️ Klicken Sie auf `Advanced configuration`, um die Datei `cluster.xml` anzuzeigen. Die Konsole füllt diese Datei aus und stellt sie auf beiden Knoten bereit. ![Knotenadressen für den {{ .Get "app" }} Cluster](/wp-content/uploads/2024/03/02-cluster-edit.png) ### 3. Modul auswählen {#3-select-a-module} * Wählen Sie im `New module` das Modul `{{ .Get "mod" }}.safe` aus. ℹ️ Im blauen Banner ist 🛜 `node1` der Knoten, der mit der Konsole verbunden ist. Er leitet bei Bedarf Anfragen an `node2` weiter. ℹ️ Wenn Sie während der Installation eine Moduldatei `xxx.safe` hinzugefügt haben, sucht die Konsole im Verzeichnis `Application_Modules/generic/` auf `node1` danach. ![Modul für die {{ .Get "app" }} auswählen](/wp-content/uploads/2024/03/04-module-new.png) ### 4. Modul konfigurieren {#4-configure-the-module} * Legen Sie im `Module startup at boot` fest, dass das Modul beim Start automatisch und ohne Verzögerung gestartet wird. * Listen Sie unter `Macros`/`SERVICES` die Anwendungsdienste in der Startreihenfolge auf. Trennen Sie die Namen durch Kommas. * In `Heartbeat networks` behalten Sie ein Heartbeat-Netzwerk bei, es sei denn, Sie haben in Schritt 2 ein LAN hinzugefügt. * Geben Sie unter `Virtual IP addresses` eine virtuelle IP-Adresse im selben Subnetz wie beide Knoten ein. * Konfigurieren Sie die Anwendungsclients so, dass sie diese virtuelle IP-Adresse oder ihren DNS-Namen verwenden. * Geben Sie unter `Load balancing rules` den zu verteilenden Dienstport ein, z. B. TCP-Port 9010. * Wählen Sie unter `Load balancing rules` `Source address` oder `Source port` aus: * `Source address`: Alle TCP-Verbindungen vom selben Client gehen an denselben Knoten in der farm. Dadurch bleibt der Sitzungskontext des Clients auf diesem Knoten erhalten. * `Source port`: TCP-Verbindungen vom selben Client können an verschiedene Knoten in der farm gehen. Der Sitzungskontext wird nicht zwischen den Knoten geteilt. * Fügen Sie bei Bedarf in `Checkers` Prüfungen hinzu: Prozessüberwachung, benutzerdefinierte Prüfungen, TCP, Ping oder Split-Brain-Prüfungen. * Ein unter `Monitored processes/services` aufgeführter Prozess wird überwacht und bei einem Fehler neu gestartet. Ein falscher Prozessname führt dazu, dass das Modul sofort nach dem Start beendet wird. ℹ️ Klicken Sie auf `Advanced configuration` um die Datei `userconfig.xml` anzuzeigen. Die Konsole füllt diese Datei aus und stellt sie mit den Neustartskripten auf beiden Knoten bereit. ℹ️ In einer Cloud-Bereitstellung verwaltet der 🛠️ [Cloud Load Balancer](/de/resources/safekit-user-guide-82/#Cloud) die virtuelle IP-Adresse und die Lastausgleichsregeln. Konfigurieren Sie diese nicht in SafeKit. ℹ️ Wenn Sie die Konfiguration anwenden, setzt SafeKit den Starttyp Windows Dienstes auf `Manual`. Dienste werden mit dem Modul gestartet, nicht beim Systemstart. SafeKit verhindert auch, dass diese Dienste beim Systemstart unter Linux gestartet werden. ![Moduleinstellungen für die {{ .Get "app" }} farm](/wp-content/uploads/2025/05/36-module-farm-config-edit-1.jpg) ### 5. Skripte bearbeiten (optional) {#5-edit-scripts-optional} * In den meisten Fällen können Sie diesen Schritt überspringen. Die Skripte sind bereits so konfiguriert, dass sie die im vorherigen Schritt aufgeführten Dienste neu starten. * Klicken Sie auf `Next step`, wenn keine Änderungen erforderlich sind. * Das Skript `start_both.ps1` startet Dienste in der Reihenfolge der Liste `SERVICES`. * Das Skript `stop_both.ps1` stoppt Dienste in umgekehrter Reihenfolge. * Das Skript `start_both.ps1` überprüft auch jeden Dienst. Es stoppt das Modul, wenn ein Dienst nicht gestartet werden kann. ![Skripte für das {{ .Get "app" }} Modul neu starten](/wp-content/uploads/2025/05/35-module-iis-edit-script-1.png) ### 6. Kommunikationsverschlüsselung (optional) {#6-communication-encryption-optional} * Lassen Sie die Kommunikationsverschlüsselung zwischen den Knoten aktiviert. ![Kommunikationsverschlüsselung für das {{ .Get "app" }} Modul](/wp-content/uploads/2025/05/07-module-encryption-1.png) ### 7. Speichern und anwenden {#7-save-and-apply} * Klicken Sie auf `Save and apply`, um die Konfiguration und die Skripte auf beiden Knoten bereitzustellen. ![Konfigurationsbereitstellung für das {{ .Get "app" }} Modul](/wp-content/uploads/2025/05/08-module-save-1.png) ### 8. Konfigurationsergebnis prüfen {#8-check-the-configuration-result} * Überprüfen Sie, ob bei beiden Knoten ✅ `Success` angezeigt wird. Klicken Sie dann auf `Monitor modules`. * Wenn ein Knoten ❌ `Failure` anzeigt, erweitern Sie sein ▼ Panel und lesen Sie die Nachrichten. Verwenden Sie die SafeKit AI 🤖 wenn Sie Hilfe benötigen. ![Konfigurationsergebnis für das {{ .Get "app" }} Modul](/wp-content/uploads/2025/05/09-module-save-check-1.png) ### 9. Starten Sie den Farm-Cluster auf Knoten 1 und Knoten 2 {#9-start-the-farm-cluster-on-node-1-and-node-2} * Öffnen Sie das ⋯-Menü und wählen Sie `Start` auf beiden Knoten aus, wie in der Abbildung gezeigt. ![Starten Sie den {{ .Get "app" }} Cluster auf beiden Knoten](/wp-content/uploads/2024/03/11-monitoring-farm-stop-stop-start.png) ### 10. Warten Sie, bis beide Knoten `UP` (grün) sind {#10-wait-until-both-nodes-are-up-green}

Beide Knoten müssen den Status UP (grün) erreichen. Das bedeutet, dass das Skript start_both auf beiden Knoten ausgeführt wurde.

⚠️ Wenn ein Knoten nicht UP (grün) erreicht oder wenn die Anwendung nicht startet, überprüfen Sie das Modulprotokoll 🖼️.

* Klicken Sie auf das 🔍 Symbol für `node1` oder `node2`, um das Modulprotokoll zu öffnen. Suchen Sie nach Fehlern, z. B. einer Prüfung, die das Modul gestoppt hat. * Klicken Sie im Protokoll auf `start_both`. Die Skriptausgabe wird rechts angezeigt. Suchen Sie nach Fehlern beim Starten des Dienstes. * Nutzen Sie die SafeKit AI 🤖 für Hilfe bei Protokollnachrichten. ℹ️ Verwenden Sie die 🕒 **[Zeitleiste 🖼️](/wp-content/uploads/2026/05/safekit-console-timeline.png)** um die Abfolge der Ereignisse im Cluster zu verstehen. ![Beide Knoten des {{ .Get "app" }} Clusters werden ausgeführt](/wp-content/uploads/2024/03/15-monitoring-up-up.png) ### 11. Tests {#11-testing} SafeKit enthält einen integrierten Mosaik. Siehe [Testen der virtuellen IP-Adresse für Lastausgleich in einem SafeKit-Farm-Cluster](/de/best-practises/test-load-balancing-vip-farm/). ![Testen Sie die virtuelle IP-Adresse der {{ .Get "app" }} mit dem Mosaik](/wp-content/uploads/2024/03/appli-19.png) ℹ️ Weitere Informationen und Videos finden Sie im [SafeKit Online-Training](/de/resources/safekit-on-line-training/). ### 12. Sammeln Sie die beiden .zip-Dateien. ℹ️ Weitere Informationen finden Sie [im SafeKit-Support](/de/resources/safekit-support/). ![Unterstützung von Snapshots für den {{ .Get "app" }} Cluster](/wp-content/uploads/2026/09/32-snapshots-network-load-balancing-cluster.png)
