Inicie o console SafeKit * Inicie o console da web em um navegador em um nó do cluster conectando-se a `http://localhost:9010`. * Insira `admin` as como nome de usuário e a senha definida durante a instalação. Você também pode executar o console em um navegador em uma estação de trabalho externa ao cluster. ⚠️ A configuração de SafeKit é feito em ambos os nós a partir de um único navegador. ℹ️ Para proteger o console da web, consulte 🛠️ [11\. Securing the SafeKit web service](/resources/safekit-user-guide-82/#https) no Guia do Usuário. ![Inicie o console web SafeKit para configurar o cluster {{ .Get "app" }} .](/wp-content/uploads/2024/03/01-login-large.png) ### 2. Configurar endereços de nó * Insira os endereços dos nós IP , pressione `Tab key` para verificar a conectividade e preencha os nomes dos nós. Se node1 ou node2 estiver em vermelho, verifique a conectividade do navegador com ambos os nós e verifique o firewall em ambos os nós para 🛠️ [troubleshooting](/resources/safekit-user-guide-82/#Troubleshooting). * Em seguida, clique em `Save and apply` para salvar a configuração. * Verifique a mensagem `Success` ✅ em ambos os nós. * Se a configuração `Failure` ❌ ocorrer em um nó, abra o painel ▼ para esse nó e revise as mensagens. Observe que você pode usar o SafeKit AI 🤖 para obter ajuda. ℹ️ Se desejar, você pode adicionar um novo `LAN and nodes` (primeiro ➕) para criar um segundo heartbeat e uma rede de replicação dedicada. ℹ️ Se você clicar em `Advanced configuration`, o `cluster.xml` O arquivo é exibido. Este arquivo é preenchido automaticamente pelo console e implantado nos nós. ![Insira os nós do cluster {{ .Get "app" }} ](/wp-content/uploads/2024/03/02-cluster-edit.png) ### 3. Selecione um módulo * Em `New module`, clique no módulo `{{ .Get "mod" }}.safe` . Na faixa azul na parte superior, ℹ️ , 🛜 `node1` representa o nó de conexão do console. Este nó retransmite solicitações para `node2` quando necessário. ℹ️ O console procura por `xxx.safe` no `Application_Modules/generic/` diretório no nó de conexão (`node1`) se você colocou um módulo lá durante a instalação. ![Escolha o módulo para {{ .Get "app" }}](/wp-content/uploads/2024/03/04-module-new.png) ### 4. Configure o módulo * Em In `Module startup at boot`, selecione a inicialização automática do módulo na inicialização do sistema, sem demora. * Em `Macros` / `SERVICES`, insira os nomes dos serviços do seu aplicativo, na ordem de inicialização, separados por vírgulas. * Em `Heartbeat networks`, você deve ter uma única rede de pulsação, exceto se tiver adicionado um LAN na etapa 2. * Em `Virtual IP addresses`, insira um endereço virtual IP . Um endereço virtual IP é um endereço IP padrão na mesma rede IP (mesma sub-rede) que os endereços IP de ambos os nós. Os clientes de aplicativos devem ser configurados com o endereço virtual IP (ou o nome DNS associado ao endereço virtual IP ). * Em In `Load balancing rules`, defina a porta de serviço para balanceamento de carga (ex.: TCP 9010 no exemplo). * Em `Load balancing rules`, defina a regra de balanceamento de carga, `Source address` ou `Source port`: * Com o endereço de origem IP do cliente, o mesmo cliente se conectará ao mesmo nó na zona farm em múltiplas sessões TCP e recuperará seu contexto no nó. * Com a porta TCP de origem do cliente, o mesmo cliente se conectará a diferentes nós na farm em múltiplas sessões TCP (sem recuperar um contexto). * Em `Checkers`, você poderá configurar verificadores, se necessário, como monitoramento de processos, verificadores personalizados, TCP, ping ou verificadores de split-brain. Por exemplo, se um nome de processo for exibido em `Monitored processes/services`, ele será monitorado com uma ação de reinicialização em caso de falha. Configurar um nome de processo incorreto fará com que o módulo pare logo após ser iniciado. ℹ️ Se você clicar em `Advanced configuration`, o `userconfig.xml` O arquivo é exibido. Este arquivo é preenchido automaticamente pelo console e implantado nos nós com os scripts de reinicialização. ℹ️ Em uma implementação em nuvem, você não precisa configurar um ambiente virtual. IP regras de endereço e balanceamento de carga em SafeKitO virtual IP e as regras de balanceamento de carga são gerenciadas no 🛠️ [cloud load balancer level](/resources/safekit-user-guide-82/#Cloud). ℹ️ Ao aplicar o SafeKit configuração, o `startup type` de serviços é configurado automaticamente para `Manual` nos serviços do Windows. Isso garante que os serviços não sejam iniciados automaticamente quando o sistema for inicializado, mas sim somente quando o próprio módulo for iniciado (o mesmo se aplica a Linux). ![Insira as configurações do módulo {{ .Get "app" }} farm ](/wp-content/uploads/2025/05/36-module-farm-config-edit-1.jpg) ### 5. Editar scripts (opcional) * Esta etapa é opcional e pode ser ignorada na maioria dos casos, pois os scripts de reinicialização já estão pré-configurados para reiniciar os serviços definidos na etapa anterior. * Então, clique diretamente em `Next step`. * `start_both.ps1` inicia todos os serviços na ordem especificada na lista `SERVICES` , enquanto `stop_both.ps1` interrompe todos os serviços na ordem inversa. * Além disso, o `start_both.ps1` verifica a inicialização de cada serviço e interrompe o módulo se algum serviço não iniciar corretamente. ![Insira as configurações do módulo {{ .Get "app" }} ](/wp-content/uploads/2025/05/35-module-iis-edit-script-1.png) ### 6. Criptografia de comunicação (opcional) * Mantenha a criptografia nas comunicações entre os nós. ![Criptografia de comunicação do módulo {{ .Get "app" }} ](/wp-content/uploads/2025/05/07-module-encryption-1.png) ### 7. Salvar e aplicar * `Save and apply` a configuração e os scripts em ambos os nós. ![Salve e aplique a configuração do módulo {{ .Get "app" }} .](/wp-content/uploads/2025/05/08-module-save-1.png) ### 8. Verifique se a configuração foi bem-sucedida. * Verifique a mensagem `Success` ✅ em ambos os nós e clique em `Monitor modules`. * Se a configuração `Failure` ❌ ocorrer em um nó, abra o painel ▼ para esse nó e revise as mensagens. Observe que você pode usar o SafeKit AI 🤖 para obter ajuda. ![Verifique se a configuração do módulo {{ .Get "app" }} foi concluída com sucesso.](/wp-content/uploads/2025/05/09-module-save-check-1.png) ### 9. Inicie o cluster farm no nó 1 e no nó 2. * ⋯ `Start` the farm cluster conforme mostrado na imagem. ![Inicie o cluster {{ .Get "app" }} em ambos os nós.](/wp-content/uploads/2024/03/11-monitoring-farm-stop-stop-start.png) ### 10. Aguarde a transição para CIMA (verde) / CIMA (verde) Os nós 1 e 2 devem atingir o estado ATIVO (verde), o que significa que o script `start_both` foi executado nos nós 1 e 2. ⚠️ Se o indicador UP (verde) não for atingido ou se o aplicativo não for iniciado, analise o motivo com o [module log 🖼️](/wp-content/uploads/2024/03/37-module-log-farm-script.png) do nó 1 ou do nó 2. * Clique no ícone 🔍 **log** ou `node1` ou `node2` para abrir o registro do módulo e procurar mensagens de erro, como um verificador detectando um erro e interrompendo o módulo. * Clique em `start_both` no registro: as mensagens de saída do script são exibidas à direita e erros podem ser detectados, como um serviço iniciado incorretamente. * Use o SafeKit AI 🤖 para obter ajuda com as mensagens de registro. ℹ️ Observe que você tem um 🕒 **[timeline 🖼️](/wp-content/uploads/2026/05/safekit-console-timeline.png)** Isso pode ser útil para entender o que acontece no cluster. ![O cluster {{ .Get "app" }} foi iniciado.](/wp-content/uploads/2024/03/15-monitoring-up-up.png) ### 11. Testes O SafeKit inclui um teste integrado no produto: * Configure uma regra para a porta TCP 9010 com balanceamento de carga na porta TCP de origem. * Conecte uma estação de trabalho externa fora dos nós farm . * Inicie um navegador em http://virtual-ip:9010/safekit/mosaic.html. Você deverá ver um mosaico de cores dependendo dos nós que respondem às solicitações HTTP. * Interrompa um nó UP (verde) rolando para baixo no menu de contexto e clicando em Parar. * Verifique se não há mais conexões TCP no nó parado e no endereço virtual IP . ℹ️ Encontre mais detalhes, juntamente com vídeos, no [SafeKit Online Training](/resources/safekit-on-line-training/). ![Teste o endereço virtual IP de {{ .Get "app" }} com o mosaico.](/wp-content/uploads/2024/03/appli-19.png) ### 12. Suporte * Para obter suporte, baixe 2 SafeKit `Snapshots` (2 arquivos .zip), um para cada nó. ℹ️ [More information on the support here](/resources/safekit-support/). ![Use as fotos {{ .Get "app" }} para suporte.](/wp-content/uploads/2026/09/32-snapshots-network-load-balancing-cluster.png)
