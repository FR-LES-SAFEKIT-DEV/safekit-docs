content\quick-install\safekit-quick-installation-guide-with-network-load-balancing-and-failover.md */}} ### 先决条件 * {{ .Get "app" }} 应用程序安装在 2 个（或更多）节点上。 * 虚拟 IP 负载均衡要求节点位于同一 LAN 或扩展 LAN（L2）上——不支持路由 L3 网络（除非使用 🛠️）。 [云负载均衡器](/resources/safekit-user-guide-82/#Cloud)）。### 1. 启动 SafeKit 安慰 * 通过连接到集群中的一个节点，在浏览器中启动 Web 控制台。 `http://localhost:9010`. * 进入 `admin` 作为安装过程中定义的用户名和密码。您也可以在集群外部的工作站上的浏览器中运行控制台。⚠️ 配置 SafeKit 在两个节点上均可通过单个浏览器完成操作。ℹ️ 要保护 Web 控制台，请参阅🛠️ [11. 确保 SafeKit 网络服务](/resources/safekit-user-guide-82/#https) 请参阅用户指南。 ![开始 SafeKit 用于配置 Web 控制台 {{ .Get "app" }} 簇](/wp-content/uploads/2024/03/01-login-large.png) ### 2. 配置节点地址 * 输入节点 IP 地址，然后按 `Tab key` 检查连接性并填写节点名称。如果节点 1 或节点 2 显示为红色，请检查浏览器与这两个节点的连接性，并检查这两个节点上的防火墙是否存在 🛠️ 警告。 [故障排除](/resources/safekit-user-guide-82/#Troubleshooting). * 然后，点击 `Save and apply` 保存配置。 * 检查 `Success` ✅ 两个节点上都发送了消息。 * 如果配置 `Failure` ❌ 如果某个节点出现此消息，请打开该节点的 ▼ 折叠面板并查看消息。请注意，您可以使用 SafeKit AI 🤖 提供协助。ℹ️ 如果您愿意，可以添加新的 `LAN and nodes` （首先➕）创建第二个心跳和一个专用复制网络。ℹ️ 如果您点击 `Advanced configuration`， 这 `cluster.xml` 文件已显示。该文件由控制台自动填充并部署到节点上。 ![进入节点 {{ .Get "app" }} 簇](/wp-content/uploads/2024/03/02-cluster-edit.png) ### 3. 选择一个模块 * 在 `New module`点击 `{{ .Get "mod" }}.safe` 模块。ℹ️ 在顶部的蓝色横幅中，🛜 `node1` 代表控制台连接节点。此节点将请求转发到 `node2` 必要时。ℹ️ 控制台会查找 `xxx.safe` 在 `Application_Modules/generic/` 连接节点上的目录（`node1`）如果您在安装过程中将模块放置在那里。 ![选择模块 {{ .Get "app" }}](/wp-content/uploads/2024/03/04-module-new.png) ### 4. 配置模块 * 在 `Module startup at boot`选择在启动时自动启动该模块，无需延迟。 * 在 `Macros` / `SERVICES`请按启动顺序输入应用程序的服务名称，用逗号分隔。 * 在 `Heartbeat networks`除非您在步骤 2 中添加了 LAN，否则您应该只有一个心跳网络。 * 在 `Virtual IP addresses`请输入虚拟 IP 地址。虚拟 IP 地址是与两个节点的 IP 地址位于同一 IP 网络（同一子网）中的标准 IP 地址。应用程序客户端必须配置虚拟 IP 地址（或与虚拟 IP 地址关联的 DNS 名称）。 * 在 `Load balancing rules`将服务端口设置为负载均衡（例如：示例中的 TCP 9010）。 * 在 `Load balancing rules`设置负载均衡规则， `Source address` 或者 `Source port`: * 根据客户端的源 IP 地址，同一客户端将连接到同一节点。 farm 在多个 TCP 会话上检索其在节点上的上下文。 * 通过客户端的源 TCP 端口，同一个客户端将连接到不同的节点。 farm 在多个 TCP 会话上（无需检索上下文）。 * 在 `Checkers`您可以根据需要配置检查器，例如进程监控、自定义检查器、TCP、ping 或脑裂检查器。例如，如果进程名称显示在 `Monitored processes/services`它将受到监控，并在发生故障时执行重启操作。配置错误的进程名称会导致模块在启动后立即停止。ℹ️ 如果您点击 `Advanced configuration`， 这 `userconfig.xml` 该文件将显示出来。此文件由控制台自动填充，并部署到包含重启脚本的节点上。ℹ️ 在云部署中，您无需配置虚拟 IP 地址和负载均衡规则。 SafeKit虚拟 IP 和负载均衡规则在 🛠️ 处进行管理 [云负载均衡器级别](/resources/safekit-user-guide-82/#Cloud)ℹ️ 当你应用 SafeKit 配置， `startup type` 服务自动设置为 `Manual` 在 Windows 服务。这确保服务不会在系统启动时自动启动，而仅在模块本身启动时才启动（这同样适用于……） Linux). ![进入 {{ .Get "app" }} farm 模块设置](/wp-content/uploads/2025/05/36-module-farm-config-edit-1.jpg) ### 5. 编辑脚本（可选） * 此步骤是可选的，大多数情况下可以跳过，因为重启脚本已经预先配置好，可以重启上一步中定义的服务。 * 所以，直接点击 `Next step`. * `start_both.ps1` 按照指定的顺序启动所有服务。 `SERVICES` 列表，而 `stop_both.ps1` 按相反顺序停止所有服务。 * 此外， `start_both.ps1` 检查每个服务的启动情况，如果任何服务启动失败，则停止该模块。 ![进入 {{ .Get "app" }} 模块设置](/wp-content/uploads/2025/05/35-module-iis-edit-script-1.png) ### 6. 通信加密（可选） * 对节点间的通信保持加密。 ![通信加密 {{ .Get "app" }} 模块](/wp-content/uploads/2025/05/07-module-encryption-1.png) ### 7. 保存并应用 * `Save and apply` 两个节点上的配置和脚本。 ![保存并应用 {{ .Get "app" }} 模块配置](/wp-content/uploads/2025/05/08-module-save-1.png) ### 8. 验证配置是否成功 * 检查 `Success` ✅ 在两个节点上都显示消息并点击 `Monitor modules`. * 如果配置 `Failure` ❌ 如果某个节点出现此消息，请打开该节点的 ▼ 折叠面板并查看消息。请注意，您可以使用 SafeKit AI 🤖 提供协助。 ![检查 {{ .Get "app" }} 模块配置成功](/wp-content/uploads/2025/05/09-module-save-check-1.png) ### 9. 开始 farm 集群位于节点 1 和节点 2 上 * ⋯ `Start` 这 farm 如图所示，形成一个簇。 ![开始 {{ .Get "app" }} 集群在两个节点上](/wp-content/uploads/2024/03/11-monitoring-farm-stop-stop-start.png) ### 10. 等待状态转换至 UP（绿色）/ UP（绿色）节点 1 和节点 2 应达到 UP（绿色）状态，这意味着 `start_both` 脚本已在节点 1 和节点 2 上执行。⚠️ 如果状态未达到 UP（绿色）或应用程序未启动，请使用以下方法分析原因： [模块日志🖼️](/wp-content/uploads/2024/03/37-module-log-farm-script.png) 节点 1 或节点 2。 * 点击🔍 **日志** 图标 `node1` 或者 `node2` 打开模块日志并查找错误消息，例如检查器检测到错误并停止模块。 * 点击 `start_both` 在日志中：脚本的输出消息显示在右侧，可以检测到错误，例如服务启动不正确。 * 使用 SafeKit AI 🤖 可协助处理日志消息。ℹ️ 请注意，您有一个 🕒 **[时间线🖼️](/wp-content/uploads/2026/05/safekit-console-timeline.png)** 这有助于了解集群中发生的事情。 ![这 {{ .Get "app" }} 集群已启动](/wp-content/uploads/2024/03/15-monitoring-up-up.png) ### 11. 测试 SafeKit 产品内置测试功能：请参阅 [测试负载均衡虚拟 IP 地址 SafeKit farm 簇](/best-practises/test-load-balancing-vip-farm/)ℹ️ 更多详情及视频，请查看 [SafeKit
