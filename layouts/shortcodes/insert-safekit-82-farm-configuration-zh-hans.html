content\quick-install\safekit-quick-installation-guide-with-network-load-balancing-and-failover.md */}} ### 前提条件 * {{ .Get "app" }} 应用程序已安装在 2 个或更多节点上。 * 虚拟 IP 负载均衡要求节点位于同一 LAN 或扩展 LAN (L2) 上 — 不支持路由的 L3 网络（🛠️ [云负载均衡器](/zh-hans/resources/safekit-user-guide-82/#Cloud)除外）。 ### 1. 启动 SafeKit 控制台 * 在集群的一个节点上打开浏览器，并连接到 `http://localhost:9010`，以启动 Web 控制台。 * 输入用户名 `admin` 和安装时设置的密码。 也可以在集群外部工作站的浏览器中运行控制台。 ⚠️ 通过一个浏览器即可在两个节点上配置 SafeKit。 ℹ️ 要保护 Web 控制台，请参阅《用户指南》中的 🛠️ [11\. 保护 SafeKit Web 服务](/zh-hans/resources/safekit-user-guide-82/#https)。 ![启动 SafeKit Web 控制台以配置 {{ .Get "app" }} 集群](/wp-content/uploads/2024/03/01-login-large.png) ### 2. 配置节点地址 * 输入节点 IP 地址，按 `Tab key` 检查连接，然后填写节点名称。如果 node1 或 node2 显示为红色，请检查浏览器与两个节点的连接以及两个节点上的防火墙；请参阅 🛠️ [故障排除](/zh-hans/resources/safekit-user-guide-82/#Troubleshooting)。 * 然后，单击 `Save and apply` 保存配置。 * 确认两个节点上都显示 `Success` ✅ 消息。 * 如果某个节点出现配置 `Failure` ❌，请展开该节点的 ▼ 折叠面板并查看消息。也可以使用 SafeKit AI 🤖 获取帮助。 ℹ️ 如有需要，可以添加一个新的 `LAN and nodes`（第一个 ➕），以创建第二个心跳网络和专用复制网络。 ℹ️ 单击 `Advanced configuration` 后会显示 `cluster.xml` 文件。控制台会自动填充此文件并将其部署到节点。 ![输入 {{ .Get "app" }} 集群的节点](/wp-content/uploads/2024/03/02-cluster-edit.png) ### 3. 选择模块 * 在 `New module` 中，单击 `{{ .Get "mod" }}.safe` 模块。 ℹ️ 顶部蓝色横幅中的 🛜 `node1` 表示连接控制台的节点。必要时，该节点会将请求转发到 `node2`。 ℹ️ 控制台会在 `xxx.safe` 的 `Application_Modules/generic/` 目录中查找该模块，前提是安装时已将模块放置在连接节点 (`node1`) 上。 ![为 {{ .Get "app" }} 选择模块](/wp-content/uploads/2024/03/04-module-new.png) ### 4. 配置模块 * 在 `Module startup at boot` 中，选择在系统启动时无延迟地自动启动模块。 * 在 `Macros` / `SERVICES` 中，按启动顺序输入应用程序服务名称，并以逗号分隔。 * 在 `Heartbeat networks` 中应只有一个心跳网络，除非已在步骤 2 中添加 LAN。 * 在 `Virtual IP addresses` 中输入虚拟 IP 地址。虚拟 IP 地址是与两个节点 IP 地址处于同一 IP 网络（同一子网）的标准 IP 地址。应用程序客户端应配置为使用虚拟 IP 地址（或与其关联的 DNS 名称）。 * 在 `Load balancing rules` 中设置要进行负载均衡的服务端口（例如 TCP 9010）。 * 在 `Load balancing rules` 中设置 `Source address` 或 `Source port` 负载均衡规则： * 使用客户端的源 IP 地址时，同一客户端在多个 TCP 会话中会连接到 `farm` 中的同一节点，并从该节点获取其上下文。 * 使用客户端的源 TCP 端口时，同一客户端在多个 TCP 会话中会连接到 `farm` 中的不同节点（不获取上下文）。 * 在 `Checkers` 中，可以根据需要配置检查器，例如进程监控、自定义检查器、TCP、ping 或脑裂检查器。例如，如果 `Monitored processes/services` 中显示进程名称，系统会监控该进程，并在故障时执行重启操作。配置错误的进程名称会导致模块启动后立即停止。 ℹ️ 单击 `Advanced configuration` 后会显示 `userconfig.xml` 文件。控制台会自动填充此文件，并将其与重启脚本一起部署到节点。 ℹ️ 在云部署中，无需在 SafeKit 中配置虚拟 IP 地址或负载均衡规则。虚拟 IP 和负载均衡规则由 🛠️ [云负载均衡器](/zh-hans/resources/safekit-user-guide-82/#Cloud)管理。 ℹ️ 应用 SafeKit 配置时，Windows 服务的 `startup type` 会自动设置为 `Manual`。因此，服务不会在系统启动时自动启动，而只会在模块启动时启动（Linux 也适用）。 ![输入 {{ .Get "app" }} 的 `farm` 模块设置](/wp-content/uploads/2025/05/36-module-farm-config-edit-1.jpg) ### 5. 编辑脚本（可选） * 此步骤为可选步骤，在大多数情况下可以跳过，因为重启脚本已预先配置为重启上一步中定义的服务。 * 直接单击 `Next step`。 * `start_both.ps1` 按照 `SERVICES` 列表中的顺序启动所有服务，而 `stop_both.ps1` 按相反顺序停止所有服务。 * 此外，`start_both.ps1` 会检查每个服务是否启动；如果任何服务未能正常启动，则会停止模块。 ![输入 {{ .Get "app" }} 模块设置](/wp-content/uploads/2025/05/35-module-iis-edit-script-1.png) ### 6. 加密通信（可选） * 保持节点间通信加密。 ![{{ .Get "app" }} 模块的通信加密](/wp-content/uploads/2025/05/07-module-encryption-1.png) ### 7. 保存并应用 * 使用 `Save and apply` 将配置和脚本应用到两个节点。 ![保存并应用 {{ .Get "app" }} 模块配置](/wp-content/uploads/2025/05/08-module-save-1.png) ### 8. 验证配置是否成功 * 确认两个节点上都显示 `Success` ✅ 消息，然后单击 `Monitor modules`。 * 如果某个节点出现配置 `Failure` ❌，请展开该节点的 ▼ 折叠面板并查看消息。也可以使用 SafeKit AI 🤖 获取帮助。 ![检查 {{ .Get "app" }} 模块配置是否成功](/wp-content/uploads/2025/05/09-module-save-check-1.png) ### 9. 在节点 1 和节点 2 上启动 `farm` 集群 * 如图所示，单击 ⋯ `Start` 以启动 `farm` 集群。 ![在两个节点上启动 {{ .Get "app" }} 集群](/wp-content/uploads/2024/03/11-monitoring-farm-stop-stop-start.png) ### 10. 等待两个节点达到 UP（绿色）状态 节点 1 和节点 2 应达到 UP（绿色）状态，这表示 `start_both` 脚本已在两个节点上执行。 ⚠️ 如果未达到 UP（绿色）状态或应用程序未启动，请查看节点 1 或节点 2 的[模块日志 🖼️](/wp-content/uploads/2024/03/37-module-log-farm-script.png)以分析原因。 * 单击 `node1` 或 `node2` 的 🔍 **log** 图标以打开模块日志，并查找错误消息，例如检查器检测到错误并停止模块。 * 单击日志中的 `start_both`：脚本输出会显示在右侧，可以据此发现服务未正确启动等错误。 * 使用 SafeKit AI 🤖 获取日志消息方面的帮助。 ℹ️ 🕒 **[时间线 🖼️](/wp-content/uploads/2026/05/safekit-console-timeline.png)** 有助于了解集群中发生的情况。 ![{{ .Get "app" }} 集群已启动](/wp-content/uploads/2024/03/15-monitoring-up-up.png) ### 11. 测试 SafeKit 产品内置了一项测试： * 为 TCP 端口 9010 配置一条按源 TCP 端口进行负载均衡的规则。 * 连接一台位于 `farm` 节点之外的外部工作站。 * 在浏览器中打开以下地址：http://virtual-ip:9010/safekit/mosaic.html 根据响应 HTTP 请求的节点，页面应显示不同颜色的马赛克。 * 在上下文菜单中向下滚动并单击 Stop，以停止一个处于 UP（绿色）状态的节点。 * 确认已停止的节点和虚拟 IP 地址上不再有 TCP 连接。 ℹ️ 更多详情和视频请参阅 [SafeKit 在线培训](/zh-hans/resources/safekit-on-line-training/)。 ![使用马赛克测试 {{ .Get "app" }} 的虚拟 IP 地址](/wp-content/uploads/2024/03/appli-19.png) ### 12. 支持 * 如需获取支持，请收集 2 个 SafeKit `Snapshots`（2 个 .zip 文件），每个节点各一个。 ℹ️ [此处了解更多支持信息](/zh-hans/resources/safekit-support/)。 ![为支持请求获取 {{ .Get "app" }}
