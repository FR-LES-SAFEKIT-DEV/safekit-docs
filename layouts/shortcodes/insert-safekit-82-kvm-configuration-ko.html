IP를 설정할 수 있습니다. 네트워크 격리 시 IP 주소는 한 노드에서는 접근 가능하지만 다른 노드에서는 접근할 수 없어야 한다는 점에 유의하십시오. ![{{ .Get "app" }} 분할 브레인 매개변수를 입력하세요](/wp-content/uploads/2024/04/safekit-split-brain-checker.png) ### 17. 스냅샷 복제 {#17-replicating-snapshots} 스냅샷 XML 파일이 포함된 디렉터리는 다음과 같습니다 /var/lib/libvirt/qemu/snapshot/%VM_NAME% 여기서 `VM_NAME`은 가상 머신의 이름(vm1)입니다. 참고: 스냅샷이 생성되지 않은 경우, 디렉토리를 생성하기 위해 스냅샷을 생성하십시오(그렇지 않으면 SafeKit 구성에 실패합니다). 재현 방법: * 모듈 구성에서 `Advanced Configuration` (이미지 참조)을 클릭하여 `userconfig.xml` 편집합니다. * 아래 줄을 userconfig.xml의 `` 섹션에 삽입하세요 * 새 구성을 `Save and apply` 수정된 userconfig.xml 파일을 두 노드 모두에 다시 배포합니다(저장 및 적용하려면 두 노드 모두에서 모듈을 중지해야 함). * virt-manager 또는 명령줄을 통해 PRIM 노드에서 스냅샷을 생성합니다 virsh snapshot-create-as vm1 snapshot-name 참고: 명령줄로 스냅샷을 생성할 때 virt-manager에서 스냅샷 보기를 새로 고쳐야 합니다. PRIM 노드에서 생성된 스냅샷은 장애 조치 후 노드 2에서 작동하지만 노드 2에는 나열되지 않습니다. * 노드 2에 스냅샷을 가져오려면 다음 명령을 실행해야 합니다 virsh snapshot-create --redefine vm1 /var/lib/libvirt/qemu/snapshot/vm1/snapshot-name * vm1의 모든 스냅샷을 나열하는 명령줄은 다음과 같습니다 virsh snapshot-list vm1 ![{{ .Get "app" }} 매개변수를 입력하세요](/wp-content/uploads/2024/03/21-module-kvm-edit-config-1.png) ### 18. 지원 {#18-support} * 지원을 받으려면 각 노드에 대해 SafeKit `Snapshots` 2개(.zip 파일 2개)를 찍으십시오. ℹ️ [지원에 대한 자세한 정보는 여기에서 확인하세요](/ko/resources/safekit-support/). ![지원을 위해 {{ .Get "app" }} 스냅샷을 찍으세요](/wp-content/uploads/2024/03/30-snapshots-mirror.png)
