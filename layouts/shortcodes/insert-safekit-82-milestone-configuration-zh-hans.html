content\quick-install\safekit-quick-installation-guide-with-milestone-xprotect-management-server.md */}} ### 先决条件 * {{ .Get "app" }} 应用程序安装在 2 个节点上。 * 总复制数据限制为几 TB — 除此之外，重新同步时间变得很重要。 * 节点之间至少 1Gb/s 互连（建议使用 10Gb/s 以加快重新同步速度）。 * IP 故障转移要求两个节点位于同一 LAN 或扩展 LAN (L2) 上 — 不支持路由 L3 网络。 ⚠️ 此配置要求**至少使用 Milestone XProtect 2023 R3**。对于早期版本，请 🛠️ [参阅此文章](/quick-install/safekit-quick-installation-guide-old-milestone-configuration/)。 ### 1.启动SafeKit控制台 * 通过连接到 `http://localhost:9010`，在一个集群节点上的浏览器中启动 Web 控制台。 * 输入 `admin` 作为用户名和安装期间定义的密码。 您还可以在集群外部工作站上的浏览器中运行控制台。 ⚠️ SafeKit 的配置是通过单个浏览器在两个节点上完成的。 ℹ️ 要保护 Web 控制台，请参阅🛠️ [11\。用户指南中的保护 SafeKit Web 服务](/resources/safekit-user-guide-82/#https)。 ![启动 SafeKit Web 控制台来配置 {{ .Get "app" }} 集群](/wp-content/uploads/2024/03/01-login-large.png) ### 2.配置节点地址 * 输入节点IP地址，按`Tab key`检查连通性并填写节点名称。如果 node1 或 node2 为红色，请检查浏览器与两个节点的连接，并检查两个节点上的防火墙，以进行 🛠️ [故障排除](/resources/safekit-user-guide-82/#Troubleshooting)。 * 然后，单击“`Save and apply`”保存配置。 * 检查两个节点上的 `Success` ✅ 消息。 * 如果配置 `Failure` ❌ 发生在一个节点上，请打开该节点的 ▼ 折叠面板并查看消息。请注意，您可以使用 SafeKit AI 🤖 寻求帮助。 ℹ️ 如果需要，您可以添加一个新的 `LAN and nodes`（第一个 ➕）来创建第二个心跳和专用复制网络。 ℹ️如果点击`Advanced configuration`，则会显示`cluster.xml`文件。该文件由控制台自动填充并部署在节点上。 ![输入{{ .Get "app" }}集群的节点](/wp-content/uploads/2024/03/02-cluster-edit.png) ### 3. 选择模块 * 在`New module`中，单击`{{ .Get "mod" }}.safe`模块。 ℹ️ 顶部蓝色横幅中，🛜 `node1` 代表控制台连接节点。该节点在需要时将请求中继到 `node2`。 ℹ️ 控制台寻找 `xxx.safe` 在 `Application_Modules/generic/` 连接节点上的目录（`node1`）如果您在安装过程中放置了一个模块。 ![选择{{ .Get "app" }}的模块](/wp-content/uploads/2024/03/04-module-new.png) ### 4. 配置模块 * 在`Module startup at boot`中，选择开机时模块自动启动，无延迟。 * 在 `Macros` / `SERVICES` 中，按启动顺序输入应用程序的服务名称，以逗号分隔。请参阅此屏幕截图，了解 [Milestone XProtect 服务🖼️](/wp-content/uploads/2025/05/milestone-services.png) 的可视化示例。 * 在 `Heartbeat networks` 中，您应该有一个用于进行复制的心跳网络。如果您在步骤 2 中添加了专用 LAN，则可以在专用 LAN 上使用复制流配置两个心跳。 * 在 `Virtual IP addresses`，输入虚拟 IP 地址。一个虚拟的 IP 地址是一个标准 IP 地址在同一个 IP 网络（同一子网）作为 IP 两个节点的地址。 应用程序客户端必须配置虚拟 IP 地址（或 DNS 与虚拟关联的名称 IP 地址）。 虚拟的 IP 如果发生故障，地址会自动切换。 * 在`Replicated directories`中设置要复制的目录路径。检查它们是否存在于两个节点上并包含应用程序数据。 数据和日志复制对于数据库至关重要。 您可以根据需要创建其他复制目录。 请参阅此屏幕截图，了解 [Milestone XProtect SQL 复制 🖼️](/wp-content/uploads/2025/05/milestone-replication.png) 的直观示例。 * 在 `Checkers` 中，您将能够根据需要配置检查器，例如进程监控、自定义检查器、TCP、ping 或裂脑检查器。 例如，如果某个进程名称显示在 `Monitored processes/services` 中，则将对其进行监视，并在出现故障时进行重新启动操作。配置错误的进程名称将导致模块启动后立即停止。 ⚠️ 如果 SQL 位于管理服务器上： * [SQL 系统数据库](https://learn.microsoft.com/en-us/sql/relational-databases/databases/system-databases)（如 master.mdf 和 mastlog.ldf）必须位于两个节点上的相同目录中。这些目录必须配置为复制目录。 * SQL 还必须安装在两个节点文件系统的相同位置，因为只读的 [SQL 资源数据库](https://learn.microsoft.com/en-us/sql/relational-databases/databases/resource-database)位于二进制文件中，并且是故障转移所必需的。此数据库无需复制。 * Milestone 的 SQL 数据库（.mdf 和 .ldf）必须位于两个节点上的相同目录中。这些目录必须配置为复制目录。Milestone 数据库列表请参阅此[文章](https://doc.milestonesys.com/xprotect/xprotect-management-client/2026r1/en/change-the-location-and-name-of-a-sql-server-database.html)。 ℹ️如果点击`Advanced configuration`，则会显示`userconfig.xml`文件。该文件由控制台自动填充，并使用重新启动脚本部署在节点上。 ℹ️ 应用 SafeKit 配置时，Windows 服务的 `startup type` 会自动设置为 `Manual`。这可确保服务不会在系统启动时自动启动，而只在模块本身启动时启动。 ![输入{{ .Get "app" Management Client 时，必须使用以下方法之一进行身份验证。根据您的选择，需要执行特定步骤，以确保 SafeKit 故障转移后仍能登录。参考：[查看登录截图 🖼️](/wp-content/uploads/2022/07/milestone-management-server-connect.png)。 #### 使用 Active Directory (AD) 的 Windows 身份验证 **配置：** 无需特殊配置。 如果 Milestone 的 "Windows authentication" 配置为使用 Active Directory，用户和密码信息将从外部 AD 获取。故障转移后，辅助节点连接同一 AD，因此身份验证会自动正常工作。 #### 工作组中的 Windows 身份验证 **配置：** 必须在 "Security / Roles" 中添加 **BUILTIN/Administrators** 组。 **警告：** 在工作组中，即使名称相同，各节点上的本地用户也具有不同的安全标识符 (SID)。只有 BUILTIN/Administrators 组在两个节点上具有相同的 SID。 * 添加此组后，您可以在故障转移后使用任意本地管理员账户在辅助节点上进行身份验证。 * 否则，由于 SID 不匹配，辅助节点上的本地 Windows 身份验证将失败。 #### 使用 SQL 数据库的基本身份验证 **配置：** 创建使用 "Basic authentication" 的用户（例如 "Admin"）。 对于 "Basic authentication"，用户凭据直接存储在 SQL 数据库中。由于 SafeKit 将 SQL 数据库实时复制到辅助节点，这些用户在故障转移后始终可以立即使用。 ![在 Milestone Management Client 中设置角色](/wp-content/uploads/2022/07/milestone-management-server-roles.png) ### 14. 启动节点 2 * ⋯ `Start` 节点 2 及其上下文菜单。 * 等待 SECOND（绿色）状态。 ℹ️ * 节点 2 保持 SECOND（橙色）状态，同时重新同步复制的目录（从节点 1
