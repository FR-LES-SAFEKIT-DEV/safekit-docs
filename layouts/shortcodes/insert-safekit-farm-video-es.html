{{/* Shortcode: insert-safekit-farm-video-es */}} {{/* Parameters: none */}} ### Vídeo de SafeKit: equilibrio de carga de red y gestión de IP virtual (5:03) {#demo-farm} En este vídeo, aprenda cómo implementar una dirección IP virtual para proporcionar un único punto de entrada para un clúster de 2 nodos. SafeKit simplifica el equilibrio de carga de la red al administrar automáticamente la IP virtual, lo que garantiza que el tráfico del cliente se distribuya entre los nodos y se redirija instantáneamente durante una conmutación por error.
