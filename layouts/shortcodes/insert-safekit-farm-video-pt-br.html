{{/* Shortcode: insert-safekit-farm-video-pt-br */}} {{/* Parameters: none */}} ### Vídeo SafeKit: Balanceamento de carga de rede e gerenciamento de IP virtual (5:03) {#demo-farm} Neste vídeo, aprenda como implementar um endereço IP virtual para fornecer um ponto de entrada único para um cluster de 2 nós. O SafeKit simplifica o balanceamento de carga da rede gerenciando automaticamente o IP virtual, garantindo que o tráfego do cliente seja distribuído entre os nós e redirecionado instantaneamente durante um failover. Embora esta demonstração use Apache no Windows, a solução funciona de forma idêntica a outros aplicativos. ### Capítulos {#chapters} 1. 🎬 [Arquitetura: Preparando 2 nós para um IP Virtual compartilhado](https://www.youtube.com/watch?v=1Ww2-cXHNx4&t=0s) (0:13) 2. 🎬 [Configuração: Configurando o módulo farm.safe e endereço IP virtual](https://www.youtube.com/watch?v=1Ww2-cXHNx4&t=13s) (2:20) 3. 🎬 [Validação: testes de failover e redirecionamento de IP virtual em caso de falha do servidor](https://www.youtube.com/watch?v=1Ww2-cXHNx4&t=153s) (2:30) ### Implementação passo a passo {#step-by-step-implementation} * 🛠️ [Leia o guia sobre como configurar um cluster de farm no Windows](/quick-install/safekit-quick-installation-guide-for-a-new-windows-application-with-network-load-balancing-and-failover/) * 🛠️ [Leia o guia sobre como configurar um cluster de farm no Linux](/quick-install/safekit-quick-installation-guide-for-a-new-linux-application-with-network-load-balancing-and-failover/)
