Nota: la versión de prueba incluye todas las funciones de SafeKit. Al finalizar el período de prueba, puede activar licencias permanentes sin desinstalar el paquete. * Después de descargar el paquete `safekit_xx.bin`, ejecútelo para extraer el paquete RPM y el script `safekitinstall`. A continuación, ejecute el script **safekitinstall**. * Responda **sí** cuando se le pregunte si desea configurar el firewall automáticamente. * Establezca la contraseña de la consola web para el usuario predeterminado **admin**. **Use la misma contraseña en todos los nodos.** Descargar SafeKit (Linux) >
