Hinweis: Die kostenlose Version enthält alle SafeKit-Funktionen. Am Ende der Testversion können Sie dauerhafte Lizenzschlüssel aktivieren, ohne das Paket zu deinstallieren. * Wählen Sie nach Abschluss der Paketinstallation aus **Set console credentials and firewall rules now** und konfigurieren Sie ein Passwort für die **admin** Benutzer der SafeKit-Konsole. **Legen Sie auf allen Knoten das gleiche Passwort fest.** * Von Antiviren-Scans ausschließen **C:/safekit/** (das Standardinstallationsverzeichnis) und **alle replizierten Ordner** die Sie definieren werden. Antivirenprogramme können mit SafeKit aufgrund der engen Integration in das Betriebssystem, virtuellen IP-Mechanismen, Echtzeitreplikation und Neustart kritischer Dienste vor Erkennungsproblemen stehen.
