{{/* Shortcode: insert-safekit-installation-package-windows-en — 22 instances in 22 files */}} {{/* Parameters: app, mod */}} ### Package installation on Windows * Download and install the free version of SafeKit on 2 Windows nodes. Note: the free version includes all SafeKit features. At the end of the trial, you can activate permanent license keys without uninstalling the package. * Upon completing the package installation, select **Set console credentials and firewall rules now** and configure a password for the **admin** user of the SafeKit console. **Set the same password on all nodes.** * Exclude from antivirus scans **C:/safekit/** (the default installation directory) and **all replicated folders** that you are going to define. Antiviruses may face detection challenges with SafeKit due to its close integration with the OS, virtual IP mechanisms, real-time replication and restart of critical services.
