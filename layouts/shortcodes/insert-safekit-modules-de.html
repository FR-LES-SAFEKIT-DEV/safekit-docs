Für jede Anwendung wird das vorkonfigurierte `.safe` Modul angegeben, das Echtzeit-Replikation, Lastausgleich und automatische Failover unter Windows oder Linux bietet. Jede Zeile verweist auf eine Kurzanleitung zur Installation, die Ihnen beim Einrichten Ihres Clusters hilft. Ein SafeKit `.safe` Modul ist eine vorkonfigurierte Hochverfügbarkeitsvorlage. Es definiert, wie SafeKit eine bestimmte Anwendung clustert und schützt. In der Praxis handelt es sich um eine Zip-Datei, die eine Konfigurationsdatei, `userconfig.xml`, und Neustartskripte enthält. **⚠️ Hinweis:** Die mit einem Sternchen gekennzeichneten Module `mirror.safe` und `farm.safe` sind im SafeKit-Installationspaket enthalten. **SafeKit-Hochverfügbarkeitslösungen mit Kurzanleitungen zur Installation und herunterladbaren `.safe`-Modulen** Kategorie |
