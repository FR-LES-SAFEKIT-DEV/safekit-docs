{{/* Shortcode: insert-safekit-modules-en — 3 instances in 3 files */}} {{/* Parameters: none */}} {{/* Source: content\solutions\_index.md */}} ## SafeKit HA Modules & Quick Installation Guides {#safekit-ha-application-modules} This table lists the SafeKit high availability solutions by category: databases, web servers, virtual machines, containers, and cloud. For each application, it gives the preconfigured `.safe` module that provides real-time replication, load balancing, and automatic failover on Windows or Linux. Each row links to a quick installation guide to help you set up your cluster. A SafeKit `.safe` module is a preconfigured high availability template. It defines how SafeKit clusters and protects a specific application. In practice, it is a zip file that contains a configuration file, `userconfig.xml`, and restart scripts. **⚠️ Note:** The modules marked with an asterisk, `mirror.safe` and `farm.safe`, are included in the SafeKit installation package. **SafeKit high availability solutions with quick installation guides and downloadable `.safe` modules** Category | Architecture | Quick installation guide | Module ---|---|---|--- New Applications | 💡 [Windows Mirror Cluster Architecture]( "How Windows real-time replication works") | 🛠️ [Quick Installation Guide for Windows]( "Quick installation guide for Windows real-time replication with the mirror.safe module") | 📦 mirror.safe (Windows)* New Applications | 💡 [Linux Mirror Cluster Architecture]( "How Linux real-time replication works") | 🛠️ [Quick Installation Guide for Linux]( "Quick installation guide for Linux real-time replication with the mirror.safe module") | 📦 mirror.safe (Linux)* New Applications | 💡 [Windows Load Balancing Architecture]( "How Windows network load balancing works") | 🛠️ [Quick Installation Guide for Windows]( "Quick installation guide for Windows network load balancing with the farm.safe module") | 📦 farm.safe (Windows)* New Applications | 💡 [Linux Load Balancing Architecture]( "How Linux network load balancing works") | 🛠️ [Quick Installation Guide for Linux]( "Quick installation guide for Linux network load balancing with the farm.safe module") | 📦 farm.safe (Linux)* Databases | 💡 [Microsoft SQL Server Mirror Cluster Architecture]( "How SQL Server mirroring works") | 🛠️ [Quick Installation Guide for Microsoft SQL Server]( "Quick installation guide for a SQL Server cluster") | 📦 sqlserver.safe (Windows) Databases | 💡 [PostgreSQL Mirror Cluster Architecture]( "How PostgreSQL replication works") | 🛠️ [Quick Installation Guide for PostgreSQL]( "Quick installation guide for PostgreSQL replication") | 📦 postgresql.safe (Windows)
