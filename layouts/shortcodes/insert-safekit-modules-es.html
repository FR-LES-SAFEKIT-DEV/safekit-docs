Para cada aplicación, se indica el módulo `.safe` preconfigurado que proporciona replicación en tiempo real, equilibrio de carga y conmutación por error automática en Windows o Linux. Cada fila enlaza con una guía de instalación rápida para ayudarle a configurar su clúster. Un módulo `.safe` SafeKit es una plantilla de alta disponibilidad preconfigurada. Define cómo SafeKit agrupa y protege una aplicación específica. En la práctica, es un archivo zip que contiene un archivo de configuración, `userconfig.xml`, y scripts de reinicio. **⚠️ Nota:** Los módulos marcados con un asterisco, `mirror.safe` y `farm.safe`,
