Identifica il modulo `.safe` preconfigurato specifico (ad esempio, `mirror.safe`, `farm.safe` e altri) necessario per la replica in tempo reale, il bilanciamento del carico e il failover automatico delle applicazioni aziendali critiche su Windows o Linux. Semplifica la configurazione del cluster HA con collegamenti diretti alle guide di installazione rapida. Un modulo `.safe` di SafeKit è essenzialmente un modello di alta disponibilità (HA) preconfigurato che definisce come un’applicazione specifica verrà raggruppata in cluster e protetta dal software SafeKit. In pratica, è un file zip che contiene un file di configurazione (`userconfig.xml`) e script di riavvio. **⚠️ Nota:** i moduli `mirror.safe` e `farm.safe` sono inclusi per impostazione predefinita nel pacchetto di installazione di SafeKit. **Soluzioni SafeKit per l’alta disponibilità (HA): guide rapide all’installazione (con moduli .safe scaricabili)** Categoria dell’applicazione | Soluzioni |
