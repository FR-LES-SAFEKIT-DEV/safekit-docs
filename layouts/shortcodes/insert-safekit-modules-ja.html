SafeKit HA モジュールとクイックインストールガイド {#safekit-ha-application-modules} この表は、アプリケーションと運用環境（データベース、Web サーバー、VM、コンテナ、クラウド）別に分類された SafeKit 高可用性（HA）ソリューションを示しています。Windows または Linux 上の重要なビジネスアプリケーションのリアルタイムレプリケーション、ロードバランシング、および自動フェイルオーバーに必要な、特定の事前設定済み `.safe` モジュール（例：`mirror.safe`、`farm.safe` など）を特定してください。Windows インストールガイドへの直接リンクで、HA クラスターのセットアップを簡素化します。 SafeKit `.safe` モジュールは、特定のアプリケーションを SafeKit ソフトウェアによってどのようにクラスター化し保護するかを定義する、事前に構成された高可用性（HA）テンプレートです。実際には、構成ファイル（`userconfig.xml`）と再起動スクリプトを含む zip ファイルです。 **⚠️ 注：*** `mirror.safe` および `farm.safe` モジュールは、SafeKit のインストールパッケージにデフォルトで含まれています。 **SafeKit 高可用性 (HA) ソリューション：クイックインストールガイド (ダウンロード可能な .safe モジュール付き)** 申請カテゴリ | ソリューション | クイックインストールガイド | アプリケーションモジュール ---|---|---|--- 新規アプリケーション | 💡 [Windows mirror クラスターアーキテクチャ]( "仕組み：Windows リアルタイムレプリケーション") | 🛠️ [Windows 版クイックインストールガイド]( "HA のクイックインストールガイド Windows リアルタイムレプリケーション \(mirror.safe\)") | 📦 mirror.safe (Windows)* 新規アプリケーション | 💡 [Linux mirror クラスターアーキテクチャ]( "仕組み：Linux リアルタイムレプリケーション") | 🛠️ [Linux 向けクイックインストールガイド]( "HA クイックインストールガイド Linux リアルタイムレプリケーション \(mirror.safe\)") | 📦 mirror.safe (Linux)* 新規アプリケーション | 💡 [Windows 負荷分散アーキテクチャ]( "仕組み：Windows ネットワーク負荷分散") | 🛠️ [Windows 版クイックインストールガイド]( "HA のクイックインストールガイド Windows ネットワーク負荷分散\(farm.safe\)") | 📦 farm.safe (Windows)* 新規アプリケーション | 💡 [Linux ロードバランシングアーキテクチャ]( "仕組み：Linux ネットワーク負荷分散") | 🛠️ [Linux 向けクイックインストールガイド]( "HA のクイックインストールガイド Linux ネットワーク負荷分散\(farm.safe\)") | 📦 farm.safe (Linux)* データベース | 💡 [Microsoft SQL Server mirror クラスターアーキテクチャ]( "仕組み：SQL Server ミラーリング") | 🛠️ [Microsoft SQL Server のクイックインストールガイド]( "SQL Server クラスターの HA クイックインストールガイド") | 📦 sqlserver.safe (Windows) データベース | 💡 [PostgreSQL mirror クラスターアーキテクチャ]( "仕組み：PostgreSQL レプリケーション") | 🛠️ [PostgreSQL のクイックインストールガイド]( "PostgreSQL レプリケーションの HA クイックインストールガイド") | 📦 postgresql.safe (Windows)
