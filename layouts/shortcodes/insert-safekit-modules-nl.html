Voor elke toepassing wordt de vooraf geconfigureerde `.safe` module vermeld die real-time replicatie, taakverdeling en automatische failover op Windows of Linux biedt. Elke rij bevat een link naar een snelle installatiehandleiding om u te helpen bij het instellen van uw cluster. Een SafeKit `.safe` module is een vooraf geconfigureerde sjabloon voor hoge beschikbaarheid. Het definieert hoe SafeKit een specifieke toepassing clusterert en beschermt. In de praktijk is het een zipbestand dat een configuratiebestand, `userconfig.xml`, en herstartscripts bevat. **⚠️ Opmerking:** De modules die met een asterisk zijn gemarkeerd, `mirror.safe` en `farm.safe`, zijn inbegrepen in het SafeKit-installatiepakket. **SafeKit-oplossingen voor hoge beschikbaarheid met snelle installatiegidsen en downloadbare `.safe` modules** Categorie | Architectuur | Snelle installatiegids | Module ---|---|---|--- Nieuwe toepassingen | 💡 [Windows mirror-cluster-architectuur]( "Hoe real-time replicatie Windows werkt") | 🛠️ [Snelle installatiegids voor Windows]( "Snelle installatiegids voor realtime replicatie Windows met de mirror.safe-module") | 📦 mirror.safe (Windows)* Nieuwe toepassingen | 💡 [Architectuur Linux mirror-cluster]( "Hoe real-time replicatie Linux werkt") | 🛠️ [Snelle installatiegids voor Linux]( "Snelle installatiegids voor real-time replicatie Linux met de mirror.safe-module") | 📦 mirror.safe (Linux)* Nieuwe toepassingen | 💡 [Windows-architectuur voor taakverdeling]( "Hoe Windows netwerkbelastingvereffening werkt") | 🛠️ [Snelle installatiegids voor Windows]( "Snelle installatiegids voor Windows netwerktaakverdeling met de farm.safe-module") | 📦 farm.safe (Windows)* Nieuwe toepassingen | 💡 [Linux architectuur voor taakverdeling]( "Hoe netwerktaakverdeling Linux werkt") | 🛠️ [Snelle installatiegids voor Linux]( "Snelle installatiegids voor netwerktaakverdeling Linux met de farm.safe-module") | 📦 farm.safe (Linux)* Databases | 💡 [Architectuur Microsoft SQL Server mirror-cluster]( "Hoe SQL Server mirroring werkt") | 🛠️ [Snelle installatiegids voor Microsoft SQL Server]( "Snelle installatiegids voor een SQL Server cluster") | 📦 sqlserver.safe (Windows) Databases | 💡 [Architectuur PostgreSQL mirror-cluster]( "Hoe PostgreSQL replicatie werkt") | 🛠️ [Snelle installatiegids voor PostgreSQL]( "Snelle installatiegids voor PostgreSQL replicatie") | 📦 postgresql.safe (Windows)
