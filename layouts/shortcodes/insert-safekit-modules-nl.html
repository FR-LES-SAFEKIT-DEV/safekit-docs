{{/* Shortcode: insert-safekit-modules-nl — 1 instance in 1 file */}} {{/* Parameters: none */}} {{/* Source: content\nl\_index.md */}} ## SafeKit Applicatiemodulebibliotheek: kant-en-klare HA-oplossingen {#safekit-ha-application-modules} Deze tabel toont de SafeKit High Availability (HA)-oplossingen, geordend per applicatie en operationele omgeving (Databases, Webservers, VM’s, Containers, Cloud). Bepaal welke vooraf geconfigureerde `.safe`-module (bijv. `mirror.safe`, `farm.safe` en andere) nodig is voor realtime replicatie, load balancing en automatische failover van bedrijfskritische applicaties op Windows of Linux. Vereenvoudig de inrichting van je HA-cluster met directe links naar snelle installatiehandleidingen. Een SafeKit `.safe`-module is in essentie een vooraf geconfigureerd High Availability (HA)-sjabloon dat bepaalt hoe een specifieke applicatie geclusterd en beschermd wordt door de SafeKit-software. In de praktijk is het een zip-bestand met een configuratiebestand (`userconfig.xml`) en herstartscripts. **⚠️ Opmerking:** * De modules `mirror.safe` en `farm.safe` zijn standaard opgenomen in het SafeKit-installatiepakket. **SafeKit High Availability (HA)-oplossingen: snelle installatiehandleidingen (met downloadbare .safe-modules)** Applicatiecategorie | Oplossingen | Snelle installatiehandleiding | Applicatiemodule ---|---|---|--- Nieuwe applicaties | 💡 [Windows Mirror Cluster-architectuur]( "Hoe werkt het: Windows realtime replicatie") | 🛠️ [Snelle installatiehandleiding voor Windows]( "Snelle HA-installatiehandleiding Windows realtime replicatie \(mirror.safe\)") | 📦 mirror.safe (Windows)* Nieuwe applicaties | 💡 [Linux Mirror Cluster-architectuur]( "Hoe werkt het: Linux realtime replicatie") | 🛠️ [Snelle installatiehandleiding voor Linux]( "Snelle HA-installatiehandleiding Linux realtime replicatie \(mirror.safe\)") | 📦 mirror.safe (Linux)* Nieuwe applicaties | 💡 [Windows Load Balancing-architectuur]( "Hoe werkt het: Windows netwerk-load-balancing") | 🛠️ [Snelle installatiehandleiding voor Windows]( "Snelle HA-installatiehandleiding Windows netwerk-load-balancing \(farm.safe\)") | 📦 farm.safe (Windows)* Nieuwe applicaties | 💡 [Linux Load Balancing-architectuur]( "Hoe werkt het: Linux netwerk-load-balancing") | 🛠️ [Snelle installatiehandleiding voor Linux]( "Snelle HA-installatiehandleiding Linux netwerk-load-balancing \(farm.safe\)") | 📦 farm.safe (Linux)* Databases | 💡 [Microsoft SQL Server Mirror Cluster-architectuur]( "Hoe werkt het: SQL Server mirroring") | 🛠️ [Snelle installatiehandleiding voor Microsoft SQL Server]( "Snelle HA-installatiehandleiding SQL Server-cluster") | 📦 sqlserver.safe (Windows) Databases | 💡 [PostgreSQL Mirror Cluster-architectuur]( "Hoe werkt het: PostgreSQL replicatie") | 🛠️ [Snelle installatiehandleiding voor PostgreSQL]( "Snelle HA-installatiehandleiding PostgreSQL replicatie") | 📦 postgresql.safe (Windows)
