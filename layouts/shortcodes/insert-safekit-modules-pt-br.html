Para cada aplicativo, ela fornece o módulo `.safe` pré-configurado que oferece replicação em tempo real, balanceamento de carga e failover automático no Windows ou Linux. Cada linha tem um link para um guia de instalação rápida para ajudar você a configurar seu cluster. Um módulo `.safe` SafeKit é um modelo de alta disponibilidade pré-configurado. Ele define como SafeKit agrupa e protege um aplicativo específico. Na prática, é um arquivo zip que contém um arquivo de configuração, `userconfig.xml`, e scripts de reinicialização. **⚠️ Observação:** Os módulos marcados com um asterisco, `mirror.safe` e
