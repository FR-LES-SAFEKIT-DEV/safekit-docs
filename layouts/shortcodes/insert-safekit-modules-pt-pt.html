Para cada aplicação, indica o módulo `.safe` pré-configurado que fornece replicação em tempo real, balanceamento de carga e failover automático no Windows ou Linux. Cada linha contém um link para um guia de instalação rápida para o ajudar a configurar o seu cluster. Um módulo `.safe` SafeKit é um modelo de alta disponibilidade pré-configurado. Ele define como SafeKit agrupa e protege uma aplicação específica. Na prática, é um ficheiro zip que contém um ficheiro de configuração, `userconfig.xml`, e scripts de reinício. **⚠️ Nota:** Os módulos marcados com um asterisco, `mirror.safe` e `farm.safe`, estão
