{{/* Shortcode: insert-safekit-scada-solutions-pt-pt — 1 instance in 1 file */}} {{/* Parameters: app */}} {{/* Source: content\use-cases\scada-software-redundancy-high-availability.md */}} ## O SafeKit oferece duas soluções para redundância e alta disponibilidade de um software {{ .Get "app" }} {#safekit-brings-two-solutions-for-redundancy-and-high-availability-of-a-scada-software} ### Redundância e alta disponibilidade ao nível da aplicação {#redundancy-and-high-availability-at-the-application-level} Neste tipo de solução, apenas os dados da aplicação são replicados. E apenas a aplicação é reiniciada em caso de falha. ![Redundância ao nível da aplicação para um software {{ .Get "app" }}](/wp-content/uploads/2023/02/application-ha-4.png "w:168") Com esta solução, é necessário escrever scripts de reinício para reiniciar a aplicação. A solução é independente da plataforma e funciona com aplicações em máquinas físicas, máquinas virtuais e na nuvem. É suportado qualquer hipervisor (VMware, Hyper-V...). * Solução para uma nova aplicação (scripts de reinício a escrever): 💡 [Windows](/pt-pt/solutions/windows-high-availability-software-synchronous-replication-failover/), 💡 [Linux](/pt-pt/solutions/linux-high-availability-software-synchronous-replication-failover/) ### Redundância e alta disponibilidade ao nível da máquina virtual {#redundancy-and-high-availability-at-the-virtual-machine-level} Neste tipo de solução, o software {{ .Get "app" }} é colocado numa máquina virtual. A máquina virtual (VM) completa é replicada e reiniciada (aplicação + OS). ![Redundância ao nível da máquina virtual para um software {{ .Get "app" }}](/wp-content/uploads/2023/02/vm-ha-4.png "w:186") A vantagem desta solução é que não há scripts de reinício a escrever por aplicação. A solução é genérica para qualquer software {{ .Get "app" }}. Funciona com Windows/Hyper-V e Linux/KVM, mas não com VMware. É uma solução ativo/ativo com várias máquinas virtuais replicadas e reiniciadas entre dois nós. * Solução para uma nova aplicação (sem script de reinício a escrever): 💡 [Windows/Hyper-V](/pt-pt/solutions/hyper-v-replication-automatic-failover-load-balancing/), 💡 [Linux/KVM](/pt-pt/solutions/linux-kvm-high-availability-replication-automatic-failover-load-balancing/)
