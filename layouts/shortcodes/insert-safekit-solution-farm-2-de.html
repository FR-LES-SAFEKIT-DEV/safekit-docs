Er bietet integrierten **Lastausgleich und Failover direkt auf den Anwendungsservern** und macht dedizierte Hardware-Load-Balancer, Proxyserver oder komplexe Multicast-Konfigurationen überflüssig. ### Welche Vorteile bietet ein SafeKit-`Farm`-Cluster für {{ .Get "app" }}? {#safekit-farm-cluster-advantages} * **All-in-one-Software:** Kombiniert virtuelle IP-Adresse, Lastausgleich sowie automatisches Failover und Failback in einem Softwarepaket. * **Keine spezielle Hardware:** Ersetzt teure Hardware-Load-Balancer durch eine reine Softwarelösung für Windows oder Linux, die von Systemadministratoren statt von Netzwerkingenieuren verwaltet werden kann. * **Umfassende Überwachung und Selbstheilung:** Überwacht mit „Checkern“ auf Anwendungsebene bestimmte Anwendungsprozesse und erkennt Abstürze, auch wenn der Server noch läuft. Bei Bedarf wird anschließend ein automatischer Dienstneustart oder ein Failover ausgelöst. * **Kombination von `Farm` und Mirror:** Ermöglicht auf einzigartige Weise die Kombination eines `Farm`-Clusters (für den Lastausgleich der Frontends) mit einem Mirror-Cluster (für die synchrone Datenreplikation der Backends). * **Hochverfügbarkeit für OEMs:** Ermöglicht Softwareanbietern, natives Clustering in ihre Anwendungen einzubetten und so ohne zusätzliche Infrastruktur ein rein softwarebasiertes, „clusterfertiges“ Produkt bereitzustellen. ![SafeKit-Hochverfügbarkeits-Clusterarchitektur für {{ .Get "app" }} mit virtueller IP-Adresse, automatischem Failover, automatischem Failback und Network Load Balancing]({{ .Get "img" }} "w:512") **SafeKit-`Farm`-NLB-Cluster für {{ .Get "app" }}** ⚡ Schnellanleitung zur Cluster-Installation für {{ .Get "app" }} > ## Inhaltsverzeichnis {#toc} * [Wie implementiert die SafeKit-Software einfach einen Network-Load-Balancing-Cluster (NLB) für {{ .Get "app" }}?](#safekit-farm-ha-cluster) * [Wie funktioniert der SafeKit-`farm`-Cluster mit {{ .Get "app" }}?](#safekit-farm-cluster) * [Vergleich: SafeKit-`Farm`-Cluster für {{ .Get "app" }} und andere NLB-Clustering-Lösungen](#safekit-farm-ha-comparison) * [Videoanleitung: Konfiguration eines SafeKit-`Farm`-NLB-Clusters](#videoguide-safekit-farm-cluster) * [🔍 SafeKit-Navigationszentrum für Hochverfügbarkeit](#hub) ## Wie implementiert die SafeKit-Software einfach einen Network-Load-Balancing-Cluster (NLB) für {{ .Get "app" }}? {#safekit-farm-ha-cluster} ### Was ist die SafeKit-`Farm`-NLB-Lösung für {{ .Get "app" }}? {#safekit-farm-nlb-solution} SafeKit bietet Network Load Balancing und Hochverfügbarkeit für {{ .Get "app" }} über zwei oder mehr Server hinweg. Dieser Artikel erläutert, wie sich schnell ein {{ .Get "app" }}-Cluster ohne Hardware-Load-Balancer oder spezielle Netzwerkkenntnisse einrichten lässt. Dazu wird eine virtuelle IP-Adresse mit Lastausgleichsregeln, den Dienstnamen von {{ .Get "app" }} und Zustandsprüfungen definiert. SafeKit aktiviert anschließend **Network Load Balancing** und **automatisches Failover**, um Skalierbarkeit und kontinuierliche Dienstverfügbarkeit sicherzustellen. ### Wie vereinfacht SafeKit den Lastausgleich im Vergleich zu Hardwarelösungen? {#software-load-balancing-vs-hardware} SafeKit vereinfacht die Verwaltung, indem es herkömmliche NLB-Hardware als „Mittler“ durch eine **reine Softwarelösung** ersetzt. Anstatt ein dediziertes physisches Gerät zu benötigen, läuft SafeKit direkt auf standardmäßigen **Windows- oder Linux**-Anwendungsservern. Softwareanbieter können **OEM-Hochverfügbarkeit** bereitstellen, indem sie **SafeKit** direkt in ihren Anwendungsstack integrieren. Dadurch können sie eine eigenständige, **„clusterfertige“ reine Softwarelösung** mit nativen Lastausgleichs- und Failover-Funktionen anbieten. ### Welche Vorteile bietet der softwarebasierte Lastausgleich von SafeKit für {{ .Get "app" }}? {#software-load-balancing-benefits} SafeKit ersetzt teure Hardware durch einen schlanken Softwareansatz mit folgenden Vorteilen: * **Hohe Leistung:** Verwaltet Datenverkehr und virtuelle IP-Adresse (VIP) auf Betriebssystem-Kernel-Ebene und sorgt so ohne zusätzliche Netzwerkgeräte für hohe Geschwindigkeit. * **Einfache Bedienung:** Ermöglicht Systemadministratoren, Cluster über eine einheitliche Oberfläche zu verwalten, ohne spezielle Netzwerkzertifizierungen zu benötigen. * **Niedrigere Gesamtbetriebskosten:** Senkt Investitions- und Wartungskosten, da dedizierte Hardware-Load-Balancer entfallen. ### Wie unterscheidet sich die Anwendungsüberwachung von SafeKit von standardmäßigen NLB-Zustandsprüfungen? {#application-monitoring-vs-nlb-health-checks} Standardmäßige NLB-Hardware verlässt sich auf einfache **Pings** und Portprüfungen. SafeKit dagegen verfügt über **integrierte Checker auf Anwendungsebene**. Ein herkömmlicher Load-Balancer bestätigt lediglich, ob ein Server „aktiv“ ist; SafeKit überwacht den tatsächlichen Zustand bestimmter {{ .Get "app" }}-Prozesse. Durch diese umfassende Überwachung erkennt das System auch „Zombie“-Zustände, in denen der Server läuft, die Software jedoch abgestürzt ist. Dann kann SafeKit **Dienste automatisch neu starten** oder den Datenverkehr umleiten – Funktionen, die standardmäßige NLB-Lösungen nicht bieten. ### Lässt sich ein {{ .Get "app" }}-`farm`-Cluster ohne Clustering-Kenntnisse einrichten? {#farm-cluster-without-clustering-skills} Ja. Dieser Artikel erklärt, wie sich ein [{{ .Get "app" }}-`farm`-Cluster schnell einrichten lässt]({{ .Get "guide" }}), ohne spezielle und komplexe Netzwerkkenntnisse zu benötigen. Mit der **virtuellen IP-Adresse** von SafeKit für den Netzwerklastausgleich von **{{ .Get "app" }}** erhalten Sie eine robuste, skalierbare Lösung, die sich wesentlich einfacher als herkömmliche NLB-Lösungen bereitstellen und warten lässt. ### Welche Anwendungen und Umgebungen kann SafeKit neben {{ .Get "app" }} schützen? {#supported-applications-and-environments} SafeKit ist eine vielseitige Hochverfügbarkeitslösung **für Windows und Linux**. Sie ermöglicht Mirror-Cluster mit **synchroner Echtzeitreplikation** und automatischem Failover für eine Vielzahl geschäftskritischer Workloads, darunter: * **Virtuelle und physische Umgebungen:** Vollständige virtuelle Hyper-V- oder KVM-Maschinen. * **Container-Orchestrierung:** Docker-, Podman- und K3s- (Kubernetes-)Umgebungen. * **Daten und Dienste:** Einzelne Dateiverzeichnisse, Dienste und verschiedene Datenbanken. * **Cloud-Infrastruktur:** Hochverfügbarkeit für Cloud-Anwendungen. 💡 [Hier finden Sie die vollständige Liste der unterstützten Hochverfügbarkeitslösungen.](/de/solutions/) {{ $.Page.RenderString (printf "{{%% insert-safekit-farm-de app=%q %%}}" (.Get "app")) }} ## Vergleich: SafeKit-`Farm`-Cluster für {{ .Get "app" }} und andere NLB-Clustering-Lösungen {#safekit-farm-ha-comparison} Merkmal | SafeKit-`Farm`-Cluster (Software) | Hardware-Load-Balancer ---|---|--- Architektur | Software auf Kernel-Ebene: native Integration in Windows und Linux. | Proprietäre Hardware: dedizierte physische Geräte.
