Integra el **equilibrio de carga y la conmutación por error directamente en los servidores de aplicaciones**, por lo que no se necesitan balanceadores de carga de hardware dedicados, servidores proxy ni configuraciones complejas de multidifusión. ### ¿Qué ventajas ofrece un clúster `Farm` de SafeKit para {{ .Get "app" }}? {#safekit-farm-cluster-advantages} * **Software todo en uno:** Combina la dirección IP virtual, el equilibrio de carga y la conmutación por error y la recuperación automáticas en un único paquete de software. * **Sin hardware especial:** Sustituye los costosos balanceadores de carga de hardware por una solución exclusivamente de software para Windows o Linux, que pueden gestionar administradores de sistemas en lugar de ingenieros de redes. * **Supervisión profunda y autorrecuperación:** Utiliza «comprobadores» a nivel de aplicación para supervisar procesos concretos y detectar fallos aunque el servidor siga funcionando; después, si es necesario, activa el reinicio automático del servicio o la conmutación por error. * **Capacidad híbrida `Farm` y Mirror:** Permite combinar un clúster `Farm` (para equilibrar la carga de los front-ends) con un clúster Mirror (para replicar de forma síncrona los datos de los back-ends). * **Alta disponibilidad para OEM:** Permite a los proveedores de software integrar la agrupación en clúster nativa en sus aplicaciones y ofrecer un producto exclusivamente de software, «listo para clúster», sin infraestructura adicional. ![Arquitectura de clúster de alta disponibilidad SafeKit para {{ .Get "app" }}, con IP virtual, conmutación por error y recuperación automáticas y equilibrio de carga de red]({{ .Get "img" }} "w:512") **Clúster NLB `Farm` de SafeKit para {{ .Get "app" }}** ⚡ Guía de instalación rápida de un clúster farm para {{ .Get "app" }} > ## Índice {#toc} * [¿Cómo implementa fácilmente el software SafeKit un clúster de equilibrio de carga de red (NLB) para {{ .Get "app" }}?](#safekit-farm-ha-cluster) * [¿Cómo funciona el clúster `farm` de SafeKit con {{ .Get "app" }}?](#safekit-farm-cluster) * [Comparación: clúster `Farm` de SafeKit para {{ .Get "app" }} frente a otras soluciones de agrupación NLB](#safekit-farm-ha-comparison) * [Guía en vídeo: configuración de un clúster NLB `Farm` de SafeKit](#videoguide-safekit-farm-cluster) * [🔍 Centro de navegación de alta disponibilidad de SafeKit](#hub) ## ¿Cómo implementa fácilmente el software SafeKit un clúster de equilibrio de carga de red (NLB) para {{ .Get "app" }}? {#safekit-farm-ha-cluster} ### ¿Cuál es la solución NLB `Farm` de SafeKit para {{ .Get "app" }}? {#safekit-farm-nlb-solution} SafeKit proporciona equilibrio de carga de red y alta disponibilidad para {{ .Get "app" }} en dos o más servidores. Este artículo explica cómo implementar rápidamente un clúster de {{ .Get "app" }} sin balanceadores de carga de hardware ni conocimientos especializados de redes. La solución consiste en definir una dirección IP virtual con reglas de equilibrio de carga, los nombres de los servicios de {{ .Get "app" }} y comprobadores de estado. Después, SafeKit habilita el **equilibrio de carga de red** y la **conmutación por error automática** para garantizar la escalabilidad y la disponibilidad continua del servicio. ### ¿Cómo simplifica SafeKit el equilibrio de carga frente a las soluciones de hardware? {#software-load-balancing-vs-hardware} SafeKit simplifica la gestión al sustituir el hardware NLB tradicional que actúa de intermediario por una **solución exclusivamente de software**. En lugar de necesitar un dispositivo físico dedicado, SafeKit se ejecuta directamente en servidores de aplicaciones estándar **Windows o Linux**. Los proveedores de software pueden ofrecer **alta disponibilidad para OEM** integrando **SafeKit** directamente en su pila de aplicaciones. Así pueden proporcionar una **solución autónoma, «lista para clúster» y exclusivamente de software** que incluye funciones nativas de equilibrio de carga y conmutación por error. ### ¿Qué ventajas tiene el equilibrio de carga por software de SafeKit para {{ .Get "app" }}? {#software-load-balancing-benefits} SafeKit sustituye el costoso hardware por un enfoque de software optimizado que ofrece: * **Alto rendimiento:** Gestiona el tráfico y la IP virtual (VIP) a nivel del núcleo del sistema operativo, con rapidez y sin equipos de red adicionales. * **Simplicidad operativa:** Permite a los administradores de sistemas gestionar los clústeres desde una interfaz unificada, sin certificaciones especializadas de redes. * **Menor coste total de propiedad:** Reduce los gastos de capital y mantenimiento al eliminar la necesidad de balanceadores de carga de hardware dedicados. ### ¿En qué se diferencia la supervisión de aplicaciones de SafeKit de las comprobaciones de estado NLB estándar? {#application-monitoring-vs-nlb-health-checks} A diferencia del hardware NLB estándar, que se basa en simples **pings** y comprobaciones de puertos, SafeKit incorpora **comprobadores integrados a nivel de aplicación**. Mientras que un balanceador tradicional solo confirma si un servidor está «activo», SafeKit supervisa el estado real de procesos concretos de {{ .Get "app" }}. Esta supervisión profunda permite detectar estados «zombi» —cuando el servidor sigue activo, pero el software ha fallado— y activar **reinicios automáticos del servicio** o redirigir el tráfico, algo que las soluciones NLB estándar no pueden hacer. ### ¿Es posible configurar un clúster `farm` de {{ .Get "app" }} sin conocimientos de agrupación en clúster? {#farm-cluster-without-clustering-skills} Sí. Al utilizar la **IP virtual** de SafeKit para gestionar el equilibrio de carga de red de **{{ .Get "app" }}**, se obtiene una solución robusta y escalable, mucho más sencilla de implementar y mantener que las soluciones NLB tradicionales. ### Además de {{ .Get "app" }}, ¿qué aplicaciones y entornos puede proteger SafeKit? {#supported-applications-and-environments} SafeKit es una solución versátil de alta disponibilidad **para Windows y Linux**.
