Integra **el equilibrio de carga y la conmutación por error directamente en los servidores de aplicaciones**, sin balanceadores de hardware dedicados, servidores proxy ni configuraciones multicast complejas. ### ¿Qué ventajas ofrece un clúster SafeKit Farm para {{ .Get "app" }}? {#safekit-farm-cluster-advantages} * **Software integral:** IP virtual, equilibrio de carga, conmutación por error y retorno automáticos en un único paquete. * **Sin hardware especial:** solución para Windows o Linux que sustituye balanceadores costosos y pueden gestionar administradores de sistemas. * **Supervisión profunda y recuperación automática:** los verificadores de aplicación detectan fallos de procesos aunque el servidor siga activo y reinician servicios o inician la conmutación. * **Capacidad híbrida Farm y Mirror:** combina clústeres Farm para distribuir la carga de los front-end y Mirror para replicar de forma síncrona los datos del back-end. * **Alta disponibilidad OEM:** los proveedores pueden integrar clustering nativo y ofrecer productos de software preparados para clúster, sin infraestructura adicional. ![Arquitectura del clúster SafeKit HA para {{ .Get "app" }} con IP virtual, conmutación por error y retorno automáticos y equilibrio de carga de red]({{ .Get "img" }} "w:512") **Clúster SafeKit Farm NLB para {{ .Get "app" }}** ⚡ Guía de instalación rápida de un clúster Farm para {{ .Get "app" }} > ## Índice {#toc} * [¿Cómo implementa SafeKit un clúster NLB para {{ .Get "app" }}?](#safekit-farm-ha-cluster) * [¿Cómo funciona el clúster SafeKit Farm con {{ .Get "app" }}?](#safekit-farm-cluster) * [Comparación con otras soluciones de clustering NLB](#safekit-farm-ha-comparison) * [Vídeo: configurar un clúster SafeKit Farm NLB](#videoguide-safekit-farm-cluster) * [🔍 Centro de navegación de alta disponibilidad SafeKit](#hub) ## ¿Cómo implementa SafeKit un clúster NLB para {{ .Get "app" }}? {#safekit-farm-ha-cluster} ### ¿Qué es la solución SafeKit Farm NLB para {{ .Get "app" }}? {#safekit-farm-nlb-solution} SafeKit proporciona equilibrio de carga de red y alta disponibilidad para {{ .Get "app" }} en dos o más servidores. Configure una IP virtual con reglas de distribución, los servicios de {{ .Get "app" }} y verificadores de estado. SafeKit habilita el **equilibrio de carga de red** y la **conmutación automática por error** para ofrecer escalabilidad y disponibilidad continua. ### ¿Cómo simplifica SafeKit el equilibrio de carga frente al hardware? {#software-load-balancing-vs-hardware} SafeKit sustituye los dispositivos NLB intermedios por una **solución totalmente de software** que se ejecuta directamente en servidores de aplicaciones **Windows o Linux** estándar. Los proveedores también pueden integrar SafeKit en sus aplicaciones y ofrecer una solución autónoma preparada para clúster. ### ¿Qué ventajas ofrece el equilibrio de carga por software? {#software-load-balancing-benefits} * **Alto rendimiento:** gestiona el tráfico y la IP virtual (VIP) en el kernel del sistema operativo, sin equipos de red adicionales. * **Sencillez operativa:** los administradores gestionan los clústeres desde una interfaz unificada, sin certificaciones de redes especializadas. * **Menor TCO:** reduce la inversión y el mantenimiento al eliminar balanceadores dedicados. ### ¿En qué se diferencia la supervisión de SafeKit de las comprobaciones NLB habituales? {#application-monitoring-vs-nlb-health-checks} Los balanceadores tradicionales suelen comprobar solo **pings** y puertos. SafeKit integra **verificadores a nivel de aplicación** que supervisan procesos concretos de {{ .Get "app" }}. Detecta incluso estados «zombi», cuando el servidor está activo pero el software ha fallado, y reinicia los servicios o redirige el tráfico. ### ¿Se puede configurar un clúster Farm de {{ .Get "app" }} sin experiencia en clustering? {#farm-cluster-without-clustering-skills} Sí. La **IP virtual** de SafeKit gestiona el equilibrio de carga de red de **{{ .Get "app" }}** sin configuraciones de red complejas.
