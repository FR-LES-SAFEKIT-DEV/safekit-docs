クラスターの利点は何ですか？ {#safekit-farm-cluster-advantages} * **オールインワンのソフトウェア：** 仮想 IP、負荷分散、自動フェイルオーバー／フェイルバックを単一のソフトウェアパッケージに統合します。 * **専用ハードウェア不要：** 高価なハードウェアロードバランサーを Windows または Linux 向けの純粋なソフトウェアソリューションに置き換えます。ネットワークエンジニアではなく、システム管理者が管理できます。 * **詳細な監視と自己修復：** アプリケーションレベルの「チェッカー」で特定のアプリケーションプロセスを監視し、サーバーが稼働中でもプロセスのクラッシュを検出します。必要に応じてサービスの自動再起動またはフェイルオーバーを実行します。 * **`Farm` と Mirror のハイブリッド構成：** フロントエンドの負荷分散に使う `Farm` クラスターと、バックエンドのデータを同期レプリケーションする Mirror クラスターを組み合わせられます。 * **OEM 向け高可用性：** ソフトウェアベンダーがネイティブのクラスタリング機能をアプリケーションに組み込み、追加のインフラストラクチャなしで「クラスター対応」のソフトウェア製品を提供できます。 ![仮想 SafeKit `Farm` NLB ソリューションとは何ですか？ {#safekit-farm-nlb-solution} SafeKit は、2 台以上のサーバー間で {{ .Get "app" }} のネットワーク負荷分散と高可用性を実現します。 この記事では、ハードウェアロードバランサーや専門的なネットワーク知識を必要とせずに、{{ .Get "app" }} クラスターをすばやく実装する方法を説明します。 このソリューションでは、負荷分散ルール、{{ .Get "app" }} のサービス名、ヘルスチェッカーを設定した仮想 IP を定義します。 SafeKit は **ネットワーク負荷分散** と **自動フェイルオーバー** を有効にし、拡張性と継続的なサービス可用性を確保します。 ### SafeKit はハードウェアソリューションと比べて、負荷分散をどのように簡素化しますか？ {#software-load-balancing-vs-hardware} SafeKit は、従来の「中間装置」となる NLB ハードウェアを **純粋なソフトウェアソリューション**に置き換え、管理を簡素化します。 専用の物理アプライアンスは不要です。SafeKit は標準的な **Windows または Linux** のアプリケーションサーバー上で直接動作します。 ソフトウェアベンダーは、**SafeKit** をアプリケーションスタックに直接統合することで、**OEM 向け高可用性**を提供できます。これにより、ネイティブの負荷分散機能とフェイルオーバー機能を備えた、自己完結型の**「クラスター対応」ソフトウェアソリューション**を提供できます。 ### SafeKit のソフトウェアベースの負荷分散が {{ .Get "app" }} にもたらす利点は何ですか？ {#software-load-balancing-benefits} SafeKit は高価なハードウェアを、次の利点を備えた効率的なソフトウェア方式に置き換えます。 * **高性能：** OS カーネルレベルでトラフィックと仮想 IP（VIP）を管理し、追加のネットワーク機器なしで高速な処理を実現します。 * **運用の簡素化：** 特別なネットワーク認定資格がなくても、システム管理者が統一されたインターフェースからクラスターを管理できます。 * **TCO の削減：** 専用ハードウェアロードバランサーを不要にし、設備投資と保守コストを削減します。 ### SafeKit のアプリケーション監視は、標準的な NLB ヘルスチェックとどう違いますか？ {#application-monitoring-vs-nlb-health-checks} 標準的な NLB ハードウェアが単純な **ping** とポートチェックに依存するのに対し、SafeKit は **アプリケーションレベルのチェッカーを統合**しています。従来のロードバランサーはサーバーが「稼働中」かどうかだけを確認しますが、SafeKit は特定の {{ .Get "app" }} プロセスの実際の状態を監視します。 この詳細な監視により、サーバーは稼働しているもののソフトウェアがクラッシュしている「ゾンビ」状態を検出し、**サービスを自動的に再起動**したり、標準的な NLB ソリューションではできないトラフィックのリダイレクトを行ったりできます。 ### クラスタリングの知識がなくても {{ .Get "app" }} の `farm` クラスターを設定できますか？ {#farm-cluster-without-clustering-skills} はい。この記事では、専門的で複雑なネットワーク知識がなくても、[{{ .Get "app" }} の `farm` クラスターをすばやく実装する方法]({{ .Get "guide" }})を説明します。SafeKit の **仮想 IP** で **{{ .Get "app" }}** のネットワーク負荷分散を行うことで、従来の NLB ソリューションよりもはるかに簡単に導入・保守できる、堅牢で拡張性の高いソリューションを利用できます。 ### {{ .Get "app" }} 以外に、SafeKit が保護できるアプリケーションや環境は何ですか？ {#supported-applications-and-environments} SafeKit は、**Windows と Linux の両方**に対応する多用途の高可用性ソリューションです。**同期リアルタイムレプリケーション**を備えた Mirror クラスターと自動フェイルオーバーにより、次のような幅広い重要なワークロードを保護できます。 * **仮想環境と物理環境：** Hyper-V または KVM の完全な仮想マシン。 * **コンテナーオーケストレーション：** Docker、Podman、K3s（Kubernetes）環境。 * **データとサービス：** 個別のファイルディレクトリ、サービス、各種データベース。 * **クラウドインフラストラクチャ：** クラウドアプリケーションの高可用性。 💡 [サポート対象の高可用性ソリューション一覧はこちらをご覧ください。](/ja/solutions/) {{ $.Page.RenderString
