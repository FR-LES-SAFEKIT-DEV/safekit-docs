SafeKit で {{ .Get "app" }} NLB クラスターを実装する方法 {#safekit-farm-ha-cluster} ### {{ .Get "app" }} 向け SafeKit Farm NLB ソリューションとは？ {#safekit-farm-nlb-solution} SafeKit は2台以上のサーバーで {{ .Get "app" }} のネットワーク負荷分散と高可用性を実現します。負荷分散ルールを持つ仮想 IP、{{ .Get "app" }} サービス、ヘルスチェッカーを定義すると、SafeKit が**ネットワーク負荷分散**と**自動フェイルオーバー**を有効にし、拡張性と継続的なサービス可用性を確保します。 ### ハードウェアソリューションと比べて SafeKit が負荷分散を簡素化する方法 {#software-load-balancing-vs-hardware} SafeKit は従来の中継型 NLB 機器を**純粋なソフトウェアソリューション**に置き換え、標準の **Windows／Linux アプリケーションサーバー**上で直接動作します。ベンダーは SafeKit をアプリケーションに組み込み、自己完結型のクラスタ対応製品を提供することもできます。 ### ソフトウェアベースの負荷分散の利点 {#software-load-balancing-benefits} * **高性能：** OS カーネルレベルでトラフィックと仮想 IP (VIP) を処理し、追加のネットワーク機器を不要にします。 * **運用の簡素化：** 専門的なネットワーク資格なしで、管理者が統合インターフェースからクラスターを運用できます。 * **低い TCO：** 専用ハードウェアの購入費と保守費を削減します。 ### SafeKit のアプリケーション監視と標準 NLB のヘルスチェックの違い {#application-monitoring-vs-nlb-health-checks} 従来の NLB は通常 **ping** やポートのみを確認します。SafeKit は**アプリケーションレベルのチェッカー**で {{ .Get "app" }} のプロセスを監視し、サーバーは稼働していてもソフトウェアが停止している「ゾンビ状態」を検出して、サービスを再起動するかトラフィックを切り替えます。 ### クラスタリングの専門知識なしで {{ .Get "app" }} Farm クラスターを設定できますか？ {#farm-cluster-without-clustering-skills} はい。SafeKit の**仮想 IP**が **{{ .Get "app" }}** のネットワーク負荷分散を処理するため、複雑なネットワーク設定は不要です。[{{ .Get "app" }} Farm クラスターをすばやく構成する]({{ .Get "guide" }})。 ### SafeKit は {{ .Get "app" }} 以外にどのようなアプリケーションや環境を保護できますか？ {#supported-applications-and-environments} SafeKit は **Windows と Linux の高可用性**を提供します。Mirror クラスターは同期レプリケーションと自動フェイルオーバーで重要なワークロードを保護します。 * **仮想／物理環境：** Hyper-V または KVM の VM 全体。 * **コンテナー：** Docker、Podman、K3s (Kubernetes)。 * **データとサービス：** ファイルディレクトリ、サービス、データベース。 * **クラウド：** クラウドアプリケーション。 💡 [対応する HA ソリューション一覧](/ja/solutions/) {{ $.Page.RenderString (printf "{{%% insert-safekit-farm-ja app=%q %%}}" (.Get "app")) }} ##
