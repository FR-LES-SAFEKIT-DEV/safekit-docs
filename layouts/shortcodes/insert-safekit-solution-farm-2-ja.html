は、スケーラブルなアプリケーション環境向けに設計されたソフトウェア定義のネットワーク負荷分散（NLB）ソリューションです。**アプリケーションサーバー上で直接統合された負荷分散とフェイルオーバー**を提供し、専用のハードウェアロードバランサー、プロキシサーバー、または複雑なマルチキャスト構成の必要性を排除します。 ### SafeKit farm クラスターを {{ .Get "app" }} に利用するメリットは何ですか？ {#safekit-farm-cluster-advantages} * **オールインワンソフトウェア：** 仮想 IP、ロードバランシング、自動フェイルオーバー/フェイルバックを単一のソフトウェアパッケージに統合。 * **特別なハードウェアは不要：** 高価なハードウェアロードバランサーを、Windows または Linux **ハイブリッド Farm と Mirror 機能：**farm クラスター(フロントエンドの負荷分散用)と mirror クラスター(バックエンドの同期データレプリケーション用)を独自に混合できます。 * **OEM 高可用性：** ソフトウェアベンダーがネイティブクラスタリングをアプリケーションに組み込むことを可能にし、追加のインフラストラクチャなしで「クラスター対応」のソフトウェアのみの製品を提供します。 ![SafeKit 高可用性 {{ .Get "app" }} クラスターアーキテクチャ仮想 IP、自動フェイルオーバー、自動フェイルバックバック、およびネットワーク負荷分散を提供します]({{ .Get "img" }}ネットワーク負荷分散（NLB）クラスターを実装するのでしょうか？ {#safekit-farm-ha-cluster} ### SafeKit Farm NLB の {{ .Get "app" }} ソリューションとは何ですか？ {#safekit-farm-nlb-solution} SafeKit は、2 台以上のサーバーにまたがる {{ .Get "app" }} にネットワーク負荷分散と高可用性を提供します。 この記事では、ハードウェアロードバランサーや専門的なネットワークスキルがなくても、{{ .Get "app" }} クラスターを迅速に実装する方法を説明します。 このソリューションは、ロードバランシングルール、{{ .Get "app" }} サービス名、およびヘルスチェッカーで仮想 IP を定義することで機能します。 SafeKit は、**ネットワーク負荷分散**と**自動フェイルオーバー**を可能にし、スケーラビリティと継続的なサービス可用性を保証します。 ### SafeKit は、ハードウェアソリューションと比較して、どのようにロードバランシングを簡素化しますか？ {#software-load-balancing-vs-hardware} SafeKit は、従来の「仲介役」である NLB ハードウェアを**純粋なソフトウェアソリューション**に置き換えることで、管理を簡素化します。 SafeKit は、専用の物理アプライアンスを必要とせず、標準的な **Windows または Linux** アプリケーションサーバー上で直接動作します。 ソフトウェアベンダーは、**SafeKit** アプリケーションスタックに直接統合することで、**OEM 高可用性**を提供できます。**このパートナーシップにより、ベンダーは、ネイティブなロードバランシングとフェイルオーバー機能を備えた、自己完結型の「クラスター対応」ソフトウェアのみのソリューション**を提供できます。 ### SafeKit のソフトウェアベースのロードバランシングを {{ .Get "app" }} に導入するメリットは何ですか？ {#software-load-balancing-benefits} SafeKit は、高価なハードウェアに代わる合理化されたソフトウェアアプローチを提供します * **高性能：** OS カーネルレベルでトラフィックと仮想 IP（VIP）を管理し、追加のネットワーク機器なしで高速性を確保します。 * **運用の簡素化：** システム管理者は、専門的なネットワーク認定資格がなくても、統合されたインターフェースを介してクラスターを管理できます。 * **TCO の削減：** 専用のハードウェアロードバランサーが不要になるため、設備投資やメンテナンスコストを削減できます。 ### SafeKit アプリケーションモニタリングは、標準的な NLB ヘルスチェックとどのように異なりますか？ {#application-monitoring-vs-nlb-health-checks} 単純な **ping** やポートチェックに依存する標準的な NLB ハードウェアとは異なり、SafeKit **統合されたアプリケーションレベルのチェッカーを**備えています。従来のバランサーはサーバーが「稼働中」であるかを確認するだけですが、SafeKit 特定の {{ .Get "app" }} プロセスの実際の健全性を監視します。 この詳細な監視により、システムは「ゾンビ」状態（サーバーは稼働しているがソフトウェアがクラッシュしている状態）を検出できます。これにより、標準的な NLB ソリューションでは実行できない**自動サービス再起動**やトラフィックのリダイレクトがトリガーされます。 ### クラスタリングのスキルがなくても、{{ .Get "app" }} farm クラスターを構築することは可能ですか？ {#farm-cluster-without-clustering-skills} はい。この記事では SafeKit 専門的で複雑なネットワークスキルを必要とせずに[、{{ .Get "app" }} farm クラスターを迅速に実装する]({{ .Get "guide" }})方法を説明します。SafeKit の**仮想 IP** を使用して **{{ .Get "app" }}** のネットワーク負荷分散を処理することで、従来の NLB ソリューションよりも展開と保守が大幅に簡素化された、堅牢でスケーラブルなソリューションが得られます。 ### SafeKit は、{{ .Get "app" }} 以外にどのようなアプリケーションや環境を保護できますか？ {#supported-applications-and-environments} SafeKit は、**Windows と Linux 両方に対応した**汎用性の高い高可用性ソリューションです。**同期リアルタイムレプリケーション**と自動フェイルオーバーを備えた mirror クラスターを可能にし、以下を含む幅広い重要なワークロードに対応します * **仮想環境と物理環境：** 完全な Hyper-V または KVM 仮想マシン。 * **コンテナオーケストレーション：** Docker、Podman、K3s (Kubernetes) 環境。 * **データとサービス：** 個別のファイルディレクトリ、サービス、および各種データベース。 * **クラウドインフラストラクチャ：** クラウドアプリケーションの可用性を高めます。 💡 [サポートされている HA ソリューションの全リストはこちらでご確認ください。](/ja/solutions/) {{
