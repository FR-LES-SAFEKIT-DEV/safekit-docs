{{/* Shortcode: insert-safekit-solution-farm-2-pt-br */}} {{/* Parameters: app, guide, img */}} ## Cluster SafeKit Farm: NLB somente por software e failover automático para {{ .Get "app" }} {#safekit-farm-cluster-overview} Um cluster SafeKit Farm para {{ .Get "app" }} é uma solução de balanceamento de carga de rede (NLB) definida por software para ambientes escaláveis. Ele oferece **balanceamento de carga e failover diretamente nos servidores de aplicação**, sem balanceadores de hardware dedicados, servidores proxy ou configurações multicast complexas. ### Quais são as vantagens de um cluster SafeKit Farm para {{ .Get "app" }}? {#safekit-farm-cluster-advantages} * **Software completo:** IP virtual, balanceamento de carga, failover e failback automáticos em um único pacote. * **Sem hardware especial:** solução de software para Windows ou Linux no lugar de balanceadores caros, gerenciada por administradores de sistemas. * **Monitoramento detalhado e autorrecuperação:** verificadores de aplicação detectam falhas de processos mesmo com o servidor ativo e reiniciam serviços ou acionam failover. * **Capacidade híbrida Farm e Mirror:** combina clusters Farm para balancear front-ends e clusters Mirror para replicação síncrona dos dados de back-end. * **Alta disponibilidade OEM:** fornecedores podem integrar clustering nativo e entregar software pronto para cluster sem infraestrutura adicional. ![Arquitetura do cluster SafeKit HA para {{ .Get "app" }} com IP virtual, failover e failback automáticos e balanceamento de carga de rede]({{ .Get "img" }} "w:512") **Cluster SafeKit Farm NLB para {{ .Get "app" }}** ⚡ Guia de instalação rápida de um cluster Farm para {{ .Get "app" }} > ## Índice {#toc} * [Como o SafeKit implementa um cluster NLB para {{ .Get "app" }}?](#safekit-farm-ha-cluster) * [Como funciona o cluster SafeKit Farm com {{ .Get "app" }}?](#safekit-farm-cluster) * [Comparação com outras soluções de clustering NLB](#safekit-farm-ha-comparison) * [Vídeo: configurar um cluster SafeKit Farm NLB](#videoguide-safekit-farm-cluster) * [🔍 Central de navegação de alta disponibilidade SafeKit](#hub) ## Como o SafeKit implementa um cluster NLB para {{ .Get "app" }}? {#safekit-farm-ha-cluster} ### O que é a solução SafeKit Farm NLB para {{ .Get "app" }}? {#safekit-farm-nlb-solution} O SafeKit oferece balanceamento de carga de rede e alta disponibilidade para {{ .Get "app" }} em dois ou mais servidores. Configure um IP virtual com regras de distribuição, os serviços de {{ .Get "app" }} e verificadores de integridade. O SafeKit ativa o **balanceamento de carga de rede** e o **failover automático** para garantir escalabilidade e disponibilidade contínua. ### Como o SafeKit simplifica o balanceamento em comparação com soluções de hardware? {#software-load-balancing-vs-hardware} O SafeKit substitui equipamentos NLB intermediários por uma **solução totalmente de software**, executada diretamente em servidores de aplicação **Windows ou Linux** padrão. Fornecedores também podem integrar o SafeKit ao aplicativo e oferecer uma solução autônoma pronta para cluster. ### Quais são os benefícios do balanceamento de carga por software? {#software-load-balancing-benefits} * **Alto desempenho:** gerencia tráfego e IP virtual (VIP) no kernel do sistema operacional, sem equipamentos de rede adicionais. * **Operação simples:** administradores gerenciam clusters por uma interface unificada, sem certificações especializadas de rede. * **TCO menor:** reduz investimento e manutenção ao eliminar balanceadores dedicados. ### Como o monitoramento do SafeKit difere das verificações NLB padrão? {#application-monitoring-vs-nlb-health-checks} Balanceadores tradicionais normalmente verificam apenas **pings** e portas. O SafeKit inclui **verificadores em nível de aplicação** para monitorar processos específicos de {{ .Get "app" }}. Assim, detecta estados "zumbis", quando o servidor está ativo mas o software parou, e reinicia serviços ou redireciona o tráfego. ### É possível configurar um cluster Farm de {{ .Get "app" }} sem experiência em clustering? {#farm-cluster-without-clustering-skills} Sim. O **IP virtual** do SafeKit gerencia o balanceamento de rede de **{{ .Get "app" }}** sem configurações complexas. [Implemente rapidamente um cluster Farm para {{ .Get "app" }}]({{ .Get "guide" }}). ### Além de {{ .Get "app" }}, quais aplicações e ambientes o SafeKit pode proteger? {#supported-applications-and-environments} O SafeKit oferece **alta disponibilidade para Windows e Linux**.
