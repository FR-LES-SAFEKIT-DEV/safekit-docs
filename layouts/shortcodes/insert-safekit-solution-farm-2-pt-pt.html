Disponibiliza **balanceamento de carga e failover directamente nos servidores de aplicações**, sem balanceadores de hardware dedicados, servidores proxy ou configurações multicast complexas. ### Quais são as vantagens de um cluster SafeKit Farm para {{ .Get "app" }}? {#safekit-farm-cluster-advantages} * **Software integrado:** IP virtual, balanceamento de carga, failover e failback automáticos num único pacote. * **Sem hardware especial:** solução de software para Windows ou Linux em substituição de balanceadores dispendiosos, gerida por administradores de sistemas. * **Monitorização aprofundada e recuperação automática:** os verificadores aplicacionais detectam falhas de processos mesmo com o servidor activo e reiniciam serviços ou accionam o failover. * **Capacidade híbrida Farm e Mirror:** combina Farm para distribuir carga nos front-ends e Mirror para replicar sincronamente os dados dos back-ends. * **Alta disponibilidade OEM:** os fornecedores podem integrar clustering nativo e disponibilizar software pronto para cluster sem infraestrutura adicional. ![Arquitectura do cluster SafeKit HA para {{ .Get "app" }} com IP virtual, failover e failback automáticos e balanceamento de carga de rede]({{ .Get "img" }} "w:512") **Cluster SafeKit Farm NLB para {{ .Get "app" }}** ⚡ Guia de instalação rápida de um cluster Farm para {{ .Get "app" }} > ## Índice {#toc} * [Como implementa o SafeKit um cluster NLB para {{ .Get "app" }}?](#safekit-farm-ha-cluster) * [Como funciona o cluster SafeKit Farm com {{ .Get "app" }}?](#safekit-farm-cluster) * [Comparação com outras soluções de clustering NLB](#safekit-farm-ha-comparison) * [Vídeo: configurar um cluster SafeKit Farm NLB](#videoguide-safekit-farm-cluster) * [🔍 Centro de navegação de alta disponibilidade SafeKit](#hub) ## Como implementa o SafeKit um cluster NLB para {{ .Get "app" }}? {#safekit-farm-ha-cluster} ### O que é a solução SafeKit Farm NLB para {{ .Get "app" }}? {#safekit-farm-nlb-solution} O SafeKit proporciona balanceamento de carga de rede e alta disponibilidade para {{ .Get "app" }} em dois ou mais servidores. Configure um IP virtual com regras de distribuição, serviços de {{ .Get "app" }} e verificações de estado. O SafeKit activa o **balanceamento de carga de rede** e o **failover automático**, garantindo escalabilidade e disponibilidade contínua. ### Como simplifica o SafeKit o balanceamento face às soluções de hardware? {#software-load-balancing-vs-hardware} O SafeKit substitui os equipamentos NLB intermédios por uma **solução exclusivamente de software**, executada directamente em servidores de aplicações **Windows ou Linux** padrão. Os fornecedores também podem integrar o SafeKit nas aplicações e disponibilizar uma solução autónoma pronta para cluster. ### Quais são as vantagens do balanceamento de carga por software? {#software-load-balancing-benefits} * **Elevado desempenho:** gere tráfego e IP virtual (VIP) ao nível do kernel do sistema operativo, sem equipamentos de rede adicionais. * **Operação simples:** os administradores gerem clusters numa interface unificada, sem certificações de rede especializadas. * **TCO reduzido:** elimina o investimento e a manutenção de balanceadores de hardware dedicados. ### Em que difere a monitorização SafeKit das verificações NLB habituais? {#application-monitoring-vs-nlb-health-checks} Os balanceadores tradicionais verificam normalmente apenas **pings** e portas. O SafeKit inclui **verificadores ao nível da aplicação** para monitorizar processos específicos de {{ .Get "app" }}. Detecta também estados «zombie», em que o servidor está activo mas o software parou, e reinicia serviços ou redirecciona o tráfego. ### É possível configurar um cluster Farm {{ .Get "app" }} sem experiência em clustering? {#farm-cluster-without-clustering-skills} Sim. O **IP virtual** SafeKit gere o balanceamento de rede de **{{ .Get "app" }}** sem configurações de rede complexas.
