SafeKit farm 集群：仅软件的 NLB 和 {{ .Get "app" }} 的自动故障转移 {#safekit-farm-cluster-overview} SafeKit farm 集群（适用于 {{ .Get "app" }}） 是一种软件定义网络负载均衡(NLB) 解决方案，专为可扩展的应用程序环境而设计。它**直接在应用程序服务器上提供集成负载均衡和故障转移**，无需专用硬件负载均衡器、代理服务器或复杂的多播配置。 ### SafeKit farm 集群为 {{ .Get "app" }} 带来的优势是什么？ {#safekit-farm-cluster-advantages} * **一体化软件：** 将虚拟 IP、负载均衡和自动故障转移/故障恢复功能整合到单个软件包中。 * **无需专用硬件：** 使用纯软件解决方案取代昂贵的硬件负载均衡器，适用于 Windows 或 Linux，可由系统管理员而非网络工程师进行管理。 * **深度监控和自我修复：** 使用应用程序级别的“检查器”来监控特定的应用程序进程，即使服务器仍在运行，也能检测到崩溃；然后，它会在必要时触发自动服务重启或故障转移。 * **混合 Farm 和 Mirror 功能：** 独特地允许 farm 集群（用于前端的负载平衡）与 mirror 集群（用于后端的数据同步复制）混合使用。 * **OEM 高可用性：** 使软件供应商能够将原生集群嵌入到其应用程序中，提供“集群就绪”的纯软件产品，而无需额外的基础设施。 ![SafeKit 高可用性 {{ .Get "app" }} 集群架构提供虚拟 IP、自动故障转移、自动回切和网络负载均衡]({{ .Get "img" }} "w:512") **适用于 {{ .Get "app" }} SafeKit farm NLB 集群** ⚡ {{ .Get "app" }} 集群快速安装指南 > ## SafeKit 软件如何简单地实现 {{ .Get "app" }}网络负载均衡(NLB) 集群？ {#safekit-farm-ha-cluster} ### SafeKit Farm NLB {{ .Get "app" }} 解决方案是什么？ {#safekit-farm-nlb-solution} SafeKit 为跨两台或多台服务器的 {{ .Get "app" }} 提供网络负载均衡和高可用性。 本文介绍了如何在没有硬件负载均衡器或专业网络技能的情况下快速实施 {{ .Get "app" }} 集群。 该解决方案通过定义具有负载均衡规则、{{ .Get "app" }} 服务名称和运行状况检查器的虚拟 IP 来工作。 SafeKit 随后启用**网络负载均衡**和**自动故障转移**，以确保可扩展性和服务的持续可用性。 ### 与硬件解决方案相比，SafeKit 如何简化负载均衡？ {#software-load-balancing-vs-hardware} SafeKit 通过用**纯软件解决方案**取代传统的“中间人”NLB 硬件来简化管理。 SafeKit 无需专用物理设备，可直接在标准 **Windows 或 Linux** 应用服务器上运行。 软件供应商可以通过将 **SafeKit** 直接集成到其应用程序堆栈中，提供 **OEM 高可用性**。这种合作关系使供应商能够提供一个独立的 **“集群就绪”的纯软件解决方案**，其中包括原生负载平衡和故障转移功能。 ### SafeKit 的软件负载均衡技术为 {{ .Get "app" }} 带来了哪些优势？ {#software-load-balancing-benefits} SafeKit 以简化的软件方法取代了昂贵的硬件，提供： * **高性能：** 在操作系统内核级别管理流量和虚拟 IP (VIP)，确保速度，无需额外的网络设备。 * **操作简便：** 允许系统管理员通过统一界面管理集群，而无需专业的网络认证。 * **降低总拥有成本：** 无需专用硬件负载均衡器，从而减少资本支出和维护成本。 ### SafeKit 应用程序监控与标准 NLB 健康检查有何不同？ {#application-monitoring-vs-nlb-health-checks} 与依赖简单 **ping** 和端口检查的标准 NLB 硬件不同，SafeKit 具有**集成的应用程序级检查器**。传统负载均衡器仅确认服务器是否“存活”，而 SafeKit 监控特定 {{ .Get "app" }} 进程的实际运行状况。 这种深度监控使系统能够检测到“僵尸”状态（即服务器正常运行但软件崩溃），从而触发**自动服务重启**或流量重定向，而标准 NLB 解决方案无法执行这些操作。 ### 是否可以在没有集群技能的情况下建立 {{ .Get "app" }} farm 集群？ {#farm-cluster-without-clustering-skills} 是的。本文介绍了如何在不需要专业和复杂网络技能的情况下[快速实现 {{ .Get "app" }} farm 集群]({{ .Get "guide" }})。通过使用 SafeKit 的**虚拟 IP** 来处理 **{{ .Get "app" }}** 的网络负载均衡，您可以获得一个强大且可扩展的解决方案，其部署和维护比传统的 NLB 解决方案简单得多。 ### 除了 {{ .Get "app" }}，SafeKit 还能保护哪些应用和环境？ {#supported-applications-and-environments} SafeKit 是一款**适用于 Windows 和 Linux** 多功能高可用性解决方案。**它支持 mirror 集群，具有同步实时复制**和自动故障转移功能，适用于各种关键工作负载，包括： * **虚拟和物理环境：** 完整的 Hyper-V 或 KVM 虚拟机。 * **容器编排：** Docker、Podman 和 K3s (Kubernetes) 环境。 * **数据与服务：** 单个文件目录、服务和各种数据库。 * **云基础设施：** 为云应用程序提供高可用性。 💡 [在此处查看支持的 HA 解决方案的完整列表。](/zh-hans/solutions/) {{ $.Page.RenderString (printf "{{%% insert-safekit-farm-zh-hans app=%q %%}}" (.Get "app")) }} ##
