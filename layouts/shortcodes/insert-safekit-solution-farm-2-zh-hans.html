SafeKit Farm 集群：面向 {{ .Get "app" }} 的纯软件 NLB 与自动故障转移 {#safekit-farm-cluster-overview} 面向 {{ .Get "app" }} 的 SafeKit Farm 集群是一种软件定义的网络负载均衡（NLB）解决方案，专为可扩展的应用环境设计。它可在**应用服务器上直接实现负载均衡和故障转移**，因此无需专用硬件负载均衡器、代理服务器或复杂的组播配置。 ### 面向 {{ .Get "app" }} 的 SafeKit Farm 集群有哪些优势？ {#safekit-farm-cluster-advantages} * **一体化软件：** 在一个软件包中集成虚拟 IP、负载均衡以及自动故障转移和故障恢复功能。 * **无需特殊硬件：** 以适用于 Windows 或 Linux 的纯软件解决方案取代昂贵的硬件负载均衡器，可由系统管理员而非网络工程师管理。 * **深度监控与自我修复：** 使用应用程序级“检查器”监控特定应用进程，即使服务器仍在运行也能检测到进程崩溃；必要时自动重启服务或触发故障转移。 * **Farm 与 Mirror 混合功能：** 可将用于前端负载均衡的 Farm 集群与用于后端同步数据复制的 Mirror 集群组合使用。 * **OEM 高可用性：** 使软件供应商能够在应用中嵌入原生集群功能，无需额外基础设施即可提供“支持集群”的纯软件产品。 ![SafeKit 高可用性集群架构，为 {{ .Get "app" }} 提供虚拟 IP、自动故障转移、自动故障恢复和网络负载均衡]({{ .Get "img" }} "w:512") **面向 {{ .Get "app" }} 的 SafeKit Farm NLB 集群** ⚡ 面向 {{ .Get "app" }} 的集群快速安装指南 > ## SafeKit 软件如何简单地实现 {{ .Get "app" }} 网络负载均衡（NLB）集群？ {#safekit-farm-ha-cluster} ### 面向 {{ .Get "app" }} 的 SafeKit Farm NLB 解决方案是什么？ {#safekit-farm-nlb-solution} SafeKit 可在两台或更多服务器之间为 {{ .Get "app" }} 提供网络负载均衡和高可用性。 本文介绍如何在无需硬件负载均衡器或专业网络技能的情况下，快速实现 {{ .Get "app" }} 集群。 该解决方案通过定义虚拟 IP、负载均衡规则、{{ .Get "app" }} 服务名称和运行状况检查器来实现。 随后，SafeKit 启用**网络负载均衡**和**自动故障转移**，确保可扩展性和服务持续可用。 ### 与硬件解决方案相比，SafeKit 如何简化负载均衡？ {#software-load-balancing-vs-hardware} SafeKit 以**纯软件解决方案**取代传统充当“中间环节”的 NLB 硬件，从而简化管理。 SafeKit 无需专用物理设备，可直接运行在标准 **Windows 或 Linux** 应用服务器上。 软件供应商可通过将 **SafeKit** 直接集成到应用程序栈中，提供 **OEM 高可用性**。借助这种合作模式，供应商能够交付自包含的**“支持集群”的纯软件解决方案**，并具备原生负载均衡和故障转移功能。 ### SafeKit 的软件负载均衡为 {{ .Get "app" }} 带来哪些好处？ {#software-load-balancing-benefits} SafeKit 以精简的软件方案取代昂贵硬件，并提供以下优势： * **高性能：** 在操作系统内核级别管理流量和虚拟 IP（VIP），无需额外网络设备即可实现快速处理。 * **运维简便：** 系统管理员可通过统一界面管理集群，无需专门的网络认证资质。 * **降低总体拥有成本：** 无需专用硬件负载均衡器，从而降低资本支出和维护成本。 ### SafeKit 应用监控与标准 NLB 运行状况检查有何不同？ {#application-monitoring-vs-nlb-health-checks} 标准 NLB 硬件依赖简单的 **ping** 和端口检查，而 SafeKit 则提供**集成式应用程序级检查器**。传统负载均衡器只能确认服务器是否“存活”，SafeKit 则会监控特定 {{ .Get "app" }} 进程的实际运行状态。 这种深度监控能够检测“僵尸”状态——服务器仍在运行，但软件已经崩溃——并触发**自动重启服务**或重定向流量，而标准 NLB 解决方案无法执行这些操作。 ### 没有集群技术经验也能设置 {{ .Get "app" }} farm 集群吗？ {#farm-cluster-without-clustering-skills} 可以。本文介绍如何在无需专业复杂网络技能的情况下，[快速实现 {{ .Get "app" }} farm 集群]({{ .Get "guide" }})。使用 SafeKit 的**虚拟 IP**为 **{{ .Get "app" }}** 实现网络负载均衡，即可获得可靠且可扩展的解决方案，其部署和维护都比传统 NLB 方案简单得多。 ### 除了 {{ .Get "app" }}，SafeKit 还能保护哪些应用和环境？ {#supported-applications-and-environments} SafeKit 是适用于 **Windows 和 Linux** 的多用途高可用性解决方案。它可通过支持**同步实时复制**的 Mirror 集群和自动故障转移，保护各类关键工作负载，包括： * **虚拟和物理环境：** 完整的 Hyper-V 或 KVM 虚拟机。 * **容器编排：** Docker、Podman 和 K3s（Kubernetes）环境。 * **数据和服务：** 单个文件目录、服务及各种数据库。 * **云基础设施：** 为云应用提供高可用性。 💡 [在此查看支持的高可用性解决方案完整列表。](/zh-hans/solutions/) {{ $.Page.RenderString (printf "{{%% insert-safekit-farm-zh-hans app=%q %%}}" (.Get "app")) }} ##
