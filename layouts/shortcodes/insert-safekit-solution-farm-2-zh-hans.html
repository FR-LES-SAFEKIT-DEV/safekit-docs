SafeKit 如何为 {{ .Get "app" }} 实现 NLB 集群？ {#safekit-farm-ha-cluster} ### 什么是适用于 {{ .Get "app" }} 的 SafeKit Farm NLB 方案？ {#safekit-farm-nlb-solution} SafeKit 可在两台或更多服务器上为 {{ .Get "app" }} 提供网络负载均衡和高可用性。配置包含负载分配规则的虚拟 IP、{{ .Get "app" }} 服务和运行状况检查器后，SafeKit 即可启用**网络负载均衡**和**自动故障转移**，确保可扩展性与服务持续可用。 ### 与硬件方案相比，SafeKit 如何简化负载均衡？ {#software-load-balancing-vs-hardware} SafeKit 以**纯软件方案**取代传统的中间式 NLB 设备，直接运行在标准 **Windows 或 Linux 应用服务器**上。软件供应商也可将 SafeKit 集成到应用中，交付独立的集群就绪方案。 ### 软件负载均衡有哪些优势？ {#software-load-balancing-benefits} * **高性能：** 在操作系统内核级处理流量和虚拟 IP (VIP)，无需额外网络设备。 * **运维简单：** 系统管理员可通过统一界面管理集群，无需网络专业认证。 * **更低 TCO：** 无需专用硬件负载均衡器，减少资本投入和维护成本。 ### SafeKit 的应用监控与标准 NLB 健康检查有何不同？ {#application-monitoring-vs-nlb-health-checks} 传统 NLB 通常只检查 **ping** 和端口。SafeKit 提供**应用级检查器**，可监控 {{ .Get "app" }} 的具体进程。即使服务器仍在线、软件已停止的“僵尸”状态也能被检测，并触发服务重启或流量重定向。 ### 没有集群经验也能设置 {{ .Get "app" }} Farm 集群吗？ {#farm-cluster-without-clustering-skills} 可以。SafeKit 的**虚拟 IP**可处理 **{{ .Get "app" }}** 的网络负载均衡，无需复杂网络配置。[快速部署 {{ .Get "app" }} Farm 集群]({{ .Get "guide" }})。 ### 除了 {{ .Get "app" }}，SafeKit 还能保护哪些应用和环境？ {#supported-applications-and-environments} SafeKit 为 **Windows 和 Linux 提供高可用性**。Mirror 集群通过同步实时复制和自动故障转移保护关键工作负载： * **虚拟和物理环境：** 完整的 Hyper-V 或 KVM 虚拟机。 * **容器：** Docker、Podman 和 K3s（Kubernetes）。 * **数据和服务：** 文件目录、服务和数据库。 * **云基础设施：** 云应用程序。 💡 [查看所有受支持的 HA 解决方案。](/zh-hans/solutions/) {{ $.Page.RenderString (printf "{{%% insert-safekit-farm-zh-hans app=%q %%}}" (.Get "app")) }} ##
