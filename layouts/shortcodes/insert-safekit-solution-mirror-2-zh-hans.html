以对应用透明的主机级方式复制数据库及相关文件夹，也支持**系统磁盘**。 * **简化部署（无需 AD/LDAP）：** 无需配置 AD/LDAP 目录，也不依赖相关基础设施。 * **HA 无需投资 SAN：** 采用无共享架构和标准本地磁盘，无需昂贵的 SAN 硬件或专门存储维护。 * **真正的双节点效率：** 无需第三个 witness 节点来防止 镜像集群](#videoguide-safekit-mirror-cluster) * [🔍 SafeKit 高可用导航中心](#hub) ## SafeKit 如何为 {{ .Get "app" }} 实现无 SAN 的 HA 集群？ {#safekit-mirror-ha-cluster} ### 什么是适用于 {{ .Get "app" }} 的 SafeKit Mirror HA 解决方案？ {#safekit-mirror-ha-solution} SafeKit 可在任意品牌的两台服务器之间为 {{ .Get "app" }} 提供高可用性。只需定义**{{ .Get "app" }} 应用程序**的数据文件夹、服务、虚拟 IP 和检查器，即可在无需共享 SAN 存储或专门技能的情况下构建集群。SafeKit 负责**实时复制**和**自动故障转移**。 ### 为什么选择一体化 HA 方案，而不是分散的工具？ {#why-choose-a-unified-all-in-one-ha-solution-over-fragmented-tools} **SafeKit** 将虚拟 IP、自动故障转移与恢复、实时文件复制集成到单一引擎中，避免不同产品之间脆弱的连接，集中管理并减少人为错误。 ### 应选择应用级还是虚拟机（VM）级高可用性？ {#application-vs-vm-high-availability} **VM 级冗余**（Hyper-V 或 KVM）复制整个虚拟机，无需了解应用内部机制。**应用级冗余**仅复制指定数据文件夹，并重启应用服务而非整个操作系统。它不依赖虚拟机监控程序，可用于物理、虚拟或云环境。 ### 与其他 {{ .Get "app" }} 集群相比，SafeKit 有哪些优势？ {#safekit-mirror-ha-advantages} SafeKit 将**无共享架构**与简化部署相结合： * **同步复制，零数据丢失：** 事务型应用达到 RPO=0；除数据库外，还可复制日志、配置等文件夹。 * **简化的双节点集群：** 两台冗余服务器即可，无需 witness 维持仲裁。[了解 heartbeat 和 quorum](/zh-hans/best-practises/heartbeat-failover-quorum-windows-linux-cluster/)。 * **统一管理：** 通过一个 SafeKit 控制台管理故障转移、数据复制和监控。 * **自定义检查器：** 使用 checker 监控 {{ .Get "app" }} 进程状态。 ### SafeKit 如何降低 {{ .Get "app" }} 的 TCO？ {#safekit-mirror-ha-tco} * **无存储成本：** 使用本地磁盘，无需昂贵 SAN、iSCSI 网络或复杂的 vSAN 配置。 * **无需 Enterprise 版本：** 可使用 Standard 版本，甚至免费版本。 * **仅需两台服务器：** 无需第三个 witness 维持仲裁。 * **无强制订阅：** 永久许可避免持续费用和不可预测的涨价。 * **低运维成本：** 即插即用，无需专门维护培训或昂贵的外部咨询。 * **许可与 CPU 无关：** 两个许可即可保护两个节点，不受处理器或核心数影响。 ### 没有集群专业技能也能设置 {{ .Get "app" }} 镜像集群吗？ {#mirror-cluster-without-clustering-skills} 可以。SafeKit 的**自动故障转移脚本**负责 **{{ .Get "app" }}** 的复制和重启，无需专门的 SAN 管理。[快速部署 {{ .Get "app" }} 镜像集群]({{ .Get "guide" }})。 ### 除了 {{ .Get "app" }}，SafeKit 还能保护哪些应用和环境？ {#supported-applications-and-environments} SafeKit 为 **Windows 和 Linux 提供高可用性**，通过同步实时复制和自动故障转移保护： * **虚拟和物理环境：** 完整的 Hyper-V 或 KVM 虚拟机。 * **容器：** Docker、Podman 和 K3s（Kubernetes）。 * **数据和服务：** 文件目录、服务和各类数据库。 * **云基础设施：** 云应用程序。 SafeKit 还提供 **Farm 集群**，通过网络负载均衡和故障转移保护**Web 服务器**等无状态应用。 💡 [查看所有受支持的 HA 解决方案。](/zh-hans/solutions/) {{ $.Page.RenderString (printf "{{%% insert-safekit-mirror-zh-hans app=%q %%}}" (.Get "app")) }} {{
