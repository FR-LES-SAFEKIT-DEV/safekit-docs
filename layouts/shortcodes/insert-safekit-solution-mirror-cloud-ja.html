{#safekit-mirror-ha-cluster} ### {{ .Get "app" }} 向けの SafeKit Mirror HA ソリューションとは何ですか？ {#what-is-the-safekit-mirror-ha-solution-for--get-app-} SafeKit は、2 つのアベイラビリティーゾーン（AZ）にある 2 台の仮想マシン間で、{{ .Get "app" }} に高可用性をもたらします。 この記事では、クラウド共有ディスクや特別なスキルがなくても、{{ .Get "app" }} クラスターを迅速に実装する方法を説明します。 このソリューションの原則は、{{ .Get "app" }} アプリケーションデータ、そのサービス、仮想 IP、およびチェッカーが存在するフォルダーを定義することです。 SafeKit は、**リアルタイムレプリケーション**と**自動フェイルオーバー**を実装し、継続的なサービス可用性を確保します。 ### 断片的なツールではなく、統合されたオールインワンの HA ソリューションを選択する理由とは？ {#why-choose-a-unified-all-in-one-ha-solution-over-fragmented-tools} **SafeKit** は、レプリケーションとクラスタリングのために別々の製品を組み合わせる「ボルトオン」ソリューションとは異なり、**仮想 IP、自動フェイルオーバー、自動フェイルバックフェイルバック、および同期リアルタイムファイルレプリケーションを**単一のエンジンに統合します。 これにより、更新によって異なるツール間の脆弱なリンクが壊れる「砂上の楼閣」のリスクが排除され、HA スタック全体にわたる単一の責任の所在が提供され、**{{ .Get "app" }}アプリケーション HA** の単一インターフェースを提供することで人的ミスが軽減されます。 ### SafeKit は、ユニフォームデプロイメントとクラウド仮想 IP をどのように処理しますか？ {#how-does-safekit-handle-uniform-deployment-and-the-cloud-virtual-ip} SafeKit はクラウドに依存しないソリューションであり、オンプレミスサーバーとすべての主要なクラウドプロバイダーで、デプロイプロセスとアーキテクチャ同じです。唯一のアーキテクチャの違いは **[、仮想 IP](/ja/best-practises/how-a-virtual-ip-address-works/)** がネットワークに提示される方法にあります * **オンプレミス：** SafeKit、**GARP（Gratuitous ARP）** パケットをローカルスイッチに送信し、ノード間で IP を瞬時に移動させることで、VIP を直接管理します。 * **クラウド環境：** クラウドネットワークは GARP をサポートしていないため、仮想 IP は**クラウドロードバランサー**によってホストされます。**SafeKit は、どのノードがプライマリであるかを判断するためのヘルスプローブを提供します**。これにより、ロードバランサーはアクティブなノードをリアルタイムで検出し、トラフィックを自動的にルーティングして、アベイラビリティゾーン全体でシームレスなフェイルオーバーを保証します。 ### 競合他社と比較して、SafeKit（{{ .Get "app" }} 向け） の高可用性にはどのような独自の利点がありますか？ {#what-are-the-distinctive-advantages-of-safekit-for--get-app--high-availability-compared-to-competitors} SafeKit は、**共有なしアーキテクチャ**と簡素化された展開により、従来の {{ .Get "app" }} クラスターと差別化されています。ほとんどのエンタープライズソリューションでは、クラウド共有ディスクの複雑な管理が必要ですが、SafeKit 以下を提供します * **ゼロデータロスでの同期レプリケーション：** SafeKit 100% の同期レプリケーションを実装し、トランザクションアプリケーションの完全なデータ整合性を保証します。**障害発生時には、データ損失はゼロです（RPO プロセスの健全性を監視するための**チェッカーを提供します**。このシステムは拡張性が高く、お客様の環境に合わせてカスタムチェッカーを追加できます。 ### SafeKit は、標準的なクラスタリングと比較して、{{ .Get "app" }} の TCO（総所有コスト）をどのように削減しますか？
