{{ .Get "app" }}에서 SafeKit 공유 없음 HA: 공유 디스크 없이 데이터 손실 제로 구현 {#cloud-ha-limitation} 주요 **클라우드 공급자**는 기본 중복성을 제공하지만, 데이터 복제와 진정한 고가용성 사이에는 여전히 큰 간극이 있습니다. 현재 클라우드 사용자는 수동 장애 조치가 필요하고 데이터 손실 위험이 있는 기본 **비동기 복제**와 원활한 비즈니스 연속성에 필요한 자동 장애 조치 기능이 없는 **클라우드 공유 디스크** 중 하나를 선택해야 합니다. ### SafeKit: 복잡한 {{ .Get "app" }} 클러스터를 위한 경량 올인원 대안 {#safekit-cloud-mirror} * **올인원 2노드 {{ .Get "app" }} 클러스터:** SafeKit은 기본 Multi-AZ(가용 영역) 기능, 가상 IP, 자동 장애 조치 및 복귀, 실시간 동기 파일 복제를 하나의 통합 소프트웨어 패키지로 제공하는 완전한 솔루션입니다. * **데이터 손실 제로(RPO=0):** DR(재해 복구)용 기본 클라우드 VM 복제와 달리 SafeKit은 **파일 수준 동기 복제**를 사용하여 트랜잭션 애플리케이션의 데이터 무결성을 보장하고 장애 시 데이터 손실을 방지합니다. * **공유 없음 아키텍처:** SafeKit은 클라우드 공유 디스크와 관련된 '디스크 잠금' 문제를 없앱니다. **로컬 디스크를 사용해 속도는 최대화하고 비용은 최소화합니다.** 기존 클러스터는 장애 노드의 스토리지 잠금이 해제되기를 기다리느라 멈출 수 있지만, SafeKit은 각 노드의 로컬 디스크에 독립적으로 동기화된 폴더를 사용하여 즉각적인 장애 조치를 보장합니다. * **애플리케이션 재구성 불필요:** SafeKit은 파일 수준에서 투명하게 복제하므로 전용 클라우드 공유 디스크로 데이터를 옮길 필요 없이 시스템 디스크를 포함한 현재 위치의 애플리케이션과 데이터를 보호합니다. * **Kubernetes 대안:** SafeKit은 Kubernetes용으로 설계되지 않은 레거시 및 컨테이너화된 애플리케이션에 Kubernetes 오케스트레이션의 운영 부담과 복잡성 없이 고가용성을 제공합니다. * **일관된 배포(온프레미스 또는 클라우드):** [클라우드 로드 밸런서의 가상 IP](/ko/best-practises/how-a-virtual-ip-address-works/) 구성을 제외하면 SafeKit 배포 절차는 온프레미스와 클라우드 환경에서 동일합니다. **고가용성**을 경량 소프트웨어 계층에 통합해 SafeKit은 기존 클러스터링 제품군 비용의 일부만으로 클라우드에서 엔터프라이즈급 중복성과 비즈니스 연속성을 제공합니다. ![가상 IP, 자동 장애 조치, 자동 복귀, 실시간 동기 파일 복제를 제공하는 {{ .Get "app" }}용 SafeKit 고가용성 클러스터 아키텍처]({{ .Get "img" }} "w:512") **{{ .Get "app" }}용 SafeKit HA Mirror 클러스터** ⚡ {{ .Get "app" }} Mirror 클러스터 빠른 설치 가이드 > ## SafeKit 소프트웨어는 공유 스토리지가 없는 {{ .Get "app" }} 고가용성 클러스터를 어떻게 간단히 구현하나요? {#safekit-mirror-ha-cluster} ### {{ .Get "app" }}용 SafeKit Mirror HA 솔루션이란? SafeKit은 두 가용 영역(AZ)에 있는 두 가상 머신 간에 {{ .Get "app" }} 고가용성을 제공합니다. 이 문서에서는 클라우드 공유 디스크나 특별한 기술 없이 {{ .Get "app" }} 클러스터를 빠르게 구현하는 방법을 설명합니다. 원리는 {{ .Get "app" }} 애플리케이션 데이터 폴더, 서비스, 가상 IP 및 검사기를 정의하는 것입니다. SafeKit은 **실시간 복제**와 **자동 장애 조치**를 수행하여 서비스 가용성을 지속적으로 보장합니다. ### 분리된 도구 대신 통합 올인원 HA 솔루션을 선택하는 이유 복제와 클러스터링을 위해 별도 제품을 결합하는 임시방편 솔루션과 달리 **SafeKit**은 **가상 IP, 자동 장애 조치, 자동 복귀, 실시간 동기 파일 복제**를 하나의 엔진에 통합합니다. 이 방식은 업데이트가 서로 다른 도구 간의 취약한 연결을 끊는 '모래성' 위험을 줄이고, 전체 HA 스택의 책임 창구를 단일화하며, 하나의 인터페이스에서 **{{ .Get "app" }} 애플리케이션 HA**를 관리해 사람의 실수를 줄입니다. ### SafeKit은 일관된 배포와 클라우드 가상 IP를 어떻게 처리하나요? SafeKit은 클라우드에 구애받지 않습니다. 온프레미스 서버와 주요 클라우드 공급자에서 배포 절차와 아키텍처가 동일합니다. 유일한 아키텍처 차이는 네트워크에 **[가상 IP](/ko/best-practises/how-a-virtual-ip-address-works/)**를 제공하는 방식입니다. * **온프레미스:** SafeKit은 로컬 스위치에 **GARP(Gratuitous ARP)** 패킷을 전송해 VIP를 직접 관리하고 IP를 노드 간에 즉시 이동합니다. * **클라우드:** 클라우드 네트워크는 GARP를 지원하지 않으므로 **클라우드 로드 밸런서**가 가상 IP를 호스팅합니다. **SafeKit은 상태 검사를 제공**하여 기본 노드를 식별합니다. 이를 통해 로드 밸런서가 활성 노드를 실시간으로 감지하고 트래픽을 자동으로 전달하여 가용 영역 간 원활한 장애 조치를 수행합니다. ### 경쟁 제품과 비교해 {{ .Get "app" }} 고가용성에서 SafeKit이 제공하는 차별점은? SafeKit은 **공유 없음 아키텍처**와 간편한 배포를 통해 기존 {{ .Get "app" }} 클러스터와 차별화됩니다. 대부분의 엔터프라이즈 솔루션은 클라우드 공유 디스크를 복잡하게 관리해야 하지만 SafeKit은 다음을 제공합니다. * **데이터 손실 없는 동기 복제:** SafeKit은 100% 동기 복제를 수행하여 트랜잭션 애플리케이션의 데이터 무결성을 보장합니다. 장애가 발생해도 **데이터 손실은 제로(RPO=0)**입니다. {{ .Get "app" }} 데이터베이스뿐 아니라 로그, 구성 파일 등 **다른 데이터 폴더도 모두** 복제해 전체 환경을 미러링합니다. * **간소화된 2노드 클러스터링:** 표준 클러스터는 쿼럼 유지를 위해 '증인'(세 번째 노드, 디스크, 파일 공유)이 필요한 경우가 많습니다. SafeKit은 두 개의 이중화 서버만으로 완전한 고가용성을 제공해 비용과 복잡성을 줄입니다. [하트비트 및 쿼럼 메커니즘 알아보기](/best-practises/heartbeat-failover-quorum-windows-linux-cluster/). * **통합 관리:** 관리자는 단일 SafeKit 콘솔에서 {{ .Get "app" }} 애플리케이션 장애 조치, 데이터 복제, 모니터링을 관리할 수 있습니다. 클러스터 전문 지식이 없는 팀도 고가용성을 사용할 수 있습니다. * **사용자 지정 검사기:** SafeKit은 기본 서비스 모니터링을 넘어 {{ .Get "app" }} 애플리케이션 프로세스 상태를 감시하는 **검사기를 제공**합니다. 시스템을 확장해 환경에 맞는 검사기를 추가할 수 있습니다. ### 표준 클러스터링과 비교해 SafeKit은 {{ .Get "app" }}의 총 소유 비용(TCO)을 어떻게 줄이나요? SafeKit은 신뢰성을 저해하지 않으면서 **인프라 오버헤드를 최소화**하도록 설계되었습니다. 기존 장애 조치 클러스터 대비 주요 절감 항목은 다음과 같습니다. * **클라우드 공유 디스크 비용 없음:** SafeKit은 로컬 디스크를 사용하는 공유 없음 아키텍처입니다. * **Enterprise 에디션 불필요:** 기본 데이터베이스 복제에는 고가의 Enterprise 라이선스가 필요할 수 있습니다. SafeKit은 **Enterprise 에디션이 필요 없으며** 표준 에디션과 **무료 에디션**에서도 작동해 훨씬 낮은 비용으로 고가용성을 제공합니다. * **진정한 2노드 효율성:** 일반 클러스터에는 쿼럼용 '증인'(세 번째 노드, 디스크, 파일 공유)이 필요한 경우가 많지만 SafeKit은 **두 개의 이중화 서버**만으로 완전한 고가용성을 제공합니다. * **강제 구독 없음:** SafeKit은 **영구 라이선스**를 제공합니다. 소프트웨어를 소유하므로 구독 종속과 예측하기 어려운 연간 가격 인상을 피할 수 있습니다. * **낮은 운영 비용(OPEX):** 바로 사용할 수 있는 솔루션으로, 복잡한 오픈 소스 클러스터링 도구와 달리 전문 교육이나 값비싼 외부 유지보수 컨설팅이 필요하지 않습니다. * **CPU 독립 가격:** 라이선스는 CPU 또는 코어 수와 무관합니다. 두 노드에 라이선스 두 개를 사용해 {{ .Get "app" }} 애플리케이션을 장애로부터 보호할 수 있습니다. ### 클러스터링 기술 없이 {{ .Get "app" }} Mirror 클러스터를 설정할 수 있나요? 예. 이 문서에서는 복잡한 HA 클러스터링 기술 없이 {{ .Get "app" }} Mirror 클러스터를 [빠르게 구현하는 방법]({{ .Get "guide" }})을 설명합니다. SafeKit의 **자동 장애 조치 스크립트**가 복제와 **{{ .Get "app" }} 애플리케이션** 재시작을 처리하므로 기존 클러스터링보다 배포와 유지 관리가 훨씬 쉬운 견고한 이중화 솔루션을 사용할 수 있습니다. ### {{ .Get "app" }} 외에 SafeKit은 어떤 애플리케이션과 환경을 보호할 수 있나요? SafeKit은 **Windows와 Linux 모두를 위한** 다목적 고가용성 솔루션으로 {{ .Get "app" }} Mirror 클러스터를 넘어 다양한 중요 워크로드에 **실시간 동기 복제**와 자동 장애 조치를 제공합니다. * **가상 및 물리 환경:** 전체 Hyper-V 또는 KVM 가상 머신. * **컨테이너 오케스트레이션:** Docker, Podman, K3s(Kubernetes) 환경. * **데이터 및 서비스:** 개별 파일 디렉터리, 서비스, 다양한 데이터베이스. * **클라우드 인프라:** 클라우드 애플리케이션 고가용성. 또한 SafeKit은 **웹 서버**와 같은 상태 비저장 애플리케이션에 네이티브 **네트워크 부하 분산 및 장애 조치**를 제공하는 `Farm` 클러스터도 지원합니다. 💡 [지원되는 HA 솔루션의 전체 목록을 확인하세요.](/ko/solutions/) {{ $.Page.RenderString (printf "{{%% insert-safekit-mirror-ko app=%q %%}}" (.Get "app")) }} {{ $.Page.RenderString "{{% insert-safekit-usage-ko %}}" }} ## 비교: {{ .Get "app" }}용 SafeKit과 클라우드 기본 HA/DR 솔루션 {#safekit-mirror-ha-comparison} 기능 | {{ .Get "app" }}용 SafeKit | 기본 클라우드 공유 디스크 | DR용 기본 클라우드 VM 복제 ---|---|---|--- 아키텍처 | 공유 없음: 속도와 비용을 최적화하는 로컬 디스크. | 공유 스토리지: 클라우드 관리 디스크에 종속. | 블록 수준: 전체 VM 디스크를 대기 지역에 복제. 데이터 무결성(RPO) | 제로(RPO=0): 파일 수준 동기 복제. | 제로: 공유 디스크에 동기 쓰기. | 0이 아님: 비동기 복제로 데이터 지연 발생. 장애 조치/복귀 로직 | 완전 자동: 모니터링과 재시작 통합. | 클라우드 공유 디스크를 지원하는 타사 장애 조치 도구 필요. | 수동: 재해 복구 계획 활성화 필요. 애플리케이션 설정 | 재구성 불필요: 현재 설치 위치에서 애플리케이션 보호. | 재구성: 애플리케이션 데이터를 특정 공유 디스크로 이전해야 함. | 없음: OS와 애플리케이션을 현재 상태 그대로 캡처. 복제 범위 | 전체: 애플리케이션 데이터 폴더(DB, 구성, 로그). | 부분: 공유 볼륨에 저장된 데이터만. | 전체: 가상 머신 전체 복제.
